# Java 핵심 개념 — 나만의 한두 줄 정리

## 1. Java란?

Java는 객체지향 프로그래밍 언어이고, JVM을 이용해서 여러 운영체제에서 실행할 수 있는 크로스 플랫폼 언어다.

## 2. 플랫폼에 독립적이라는 것은?

Java 프로그램이 Windows, Mac, Linux 같은 특정 OS용 실행 파일에 직접 종속되지 않는다는 뜻이다. Java 코드는 바이트코드로 컴파일되고, 각 OS에 설치된 JVM이 그 바이트코드를 실행한다.

## 3. Java 코드가 실행되는 과정

사람이 작성한 .java 소스코드는 컴파일을 통해 .class 바이트코드로 변환되고 JVM이 읽어 실행한다.

소스코드(.java) → 컴파일 → 바이트코드(.class) → JVM 실행

## 4. Type이란?

Type은 어떤 종류의 데이터를 저장하고 사용할 것인지 정하는 것이다. Java의 타입은 크게 기본 타입과 참조 타입으로 나뉜다.

## 5. 기본 타입 Primitive Type

기본 타입은 변수 안에 값 자체를 직접 저장하는 타입이다. 예: int, double, char, boolean

## 6. 리터럴 Literal

리터럴은 코드에 직접 작성한 값 그 자체다. 기본 타입 자체를 리터럴 타입이라고 부르는 것은 아니다.

## 7. 참조 타입 Reference Type

참조 타입 변수는 객체 자체가 아니라 객체를 찾아갈 수 있는 참조값을 저장한다. class, String, array, interface 타입 등이 해당한다.

## 8. String

String은 기본 타입처럼 편하게 사용하지만 실제로는 클래스로 만들어진 참조 타입이다.

## 9. Class란?

클래스는 상태와 동작을 하나로 묶어서 만든 사용자 정의 자료형이며 객체를 만들기 위한 설계도다.

## 10. 클래스로 무엇을 하는가?

클래스를 정의한 뒤 new를 사용해서 실제로 사용할 객체를 생성한다.

## 11. Object와 Instance

객체는 클래스를 기반으로 실제로 만들어진 대상이다. 인스턴스는 그 객체가 어떤 클래스에서 만들어졌는지를 강조하는 표현이다.

## 12. 배열 Array

배열은 같은 타입의 여러 값을 하나의 이름으로 묶어서 관리하는 자료구조다.

## 13. 정적 메서드 Static Method

정적 메서드는 객체를 만들지 않고 클래스 이름으로 호출할 수 있는 메서드다.

## 14. 인스턴스 메서드 Instance Method

인스턴스 메서드는 객체가 가진 기능이므로 객체를 만든 뒤 참조 변수로 호출한다.

## 15. Stack과 스택 프레임

메서드가 실행될 때마다 해당 메서드의 작업 공간인 스택 프레임이 Stack에 만들어진다.

## 16. Stack이 후입선출인 이유

나중에 호출된 메서드가 먼저 종료되어야 이전 메서드로 돌아갈 수 있으므로 나중에 쌓인 스택 프레임이 먼저 제거된다.

## 17. 인터페이스 Interface

인터페이스는 이 기능은 반드시 가져야 한다는 규칙이나 계약을 정의한다. 실제 상태와 기능 구현은 구현 클래스가 담당한다.

## 18. 인터페이스에 생성자가 없는 이유

생성자는 객체를 만들 때 필요한데 인터페이스는 직접 객체를 생성할 수 없으므로 생성자를 가질 수 없다.

## 19. 캡슐화 Encapsulation

캡슐화는 객체 내부 데이터를 함부로 직접 건드리지 못하게 숨기고 정해진 메서드를 통해 안전하게 사용하게 만드는 것이다.

## 20. 상속 Inheritance

상속은 부모 클래스의 접근 가능한 필드와 메서드를 자식 클래스가 이어받아 사용하고 확장할 수 있게 하는 것이다.

## 21. 추상화 Abstraction

추상화는 복잡한 것들에서 공통되고 중요한 특징만 뽑아서 하나의 개념으로 표현하는 것이다.

## 22. 다형성 Polymorphism

다형성은 하나의 부모 타입으로 여러 종류의 자식 객체를 다루며 실제 객체에 따라 서로 다른 동작을 실행할 수 있는 것이다.

## 23. Condition

Condition은 조건에 따라 실행할 코드를 선택하는 것이며 대표적으로 if와 switch를 사용한다.

## 24. Loop

Loop는 같은 작업을 조건에 따라 반복 실행하는 것이며 대표적으로 for와 while을 사용한다.
