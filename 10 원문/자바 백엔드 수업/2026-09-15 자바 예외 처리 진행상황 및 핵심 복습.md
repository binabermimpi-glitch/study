# 자바 예외 처리 진행상황 및 핵심 복습

## 학습 범위

- Throwable, Error, Exception, RuntimeException의 계층
- try-catch-finally 실행 흐름
- 여러 catch의 검사 순서
- throw와 throws의 차이
- Exception을 상속한 사용자 정의 예외
- `super(message)`와 `getMessage()`의 연결
- 예외 전파와 `throw e`를 이용한 재던지기

## 핵심 코드

```java
class AgeException extends Exception {
    public AgeException(String message) {
        super(message);
    }
}

static void checkAge(int age) throws AgeException {
    if (age < 0) {
        throw new AgeException("나이 오류");
    }
    System.out.println("정상 나이");
}

try {
    checkAge(-3);
} catch (AgeException e) {
    System.out.println("예외 발생");
    System.out.println(e.getMessage());
}
```
