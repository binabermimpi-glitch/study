# 1. RARP 🔥 빈출

## 문제

물리주소(MAC Address)를 IP주소로 변화하는 프로토콜을 작성하시오.

## 정답

**RARP**

## RARP

**Reverse Address Resolution Protocol**

MAC 주소를 이용하여 IP 주소를 알아내는 프로토콜이다.

```text
MAC → IP
= RARP
```

## 같이 알아둘 것

### ARP

**Address Resolution Protocol**

```text
IP → MAC
```

### RARP

```text
MAC → IP
```

## 암기

```text
ARP
IP → MAC

RARP
MAC → IP
```

# 4. EAI 🔥 빈출

## 문제

기업 내부에서 운영되는 각종 플랫폼 및 애플리케이션 간의 정보전달, 연계, 통합을 가능하게 하는 솔루션이다.

Point-to-Point, Hub & Spoke, Message Bus, Hybrid 형태로 구성된다.

## 정답

**EAI**

## EAI

**Enterprise Application Integration**

기업 내부의 서로 다른 애플리케이션과 시스템을 연결하여 데이터와 업무 프로세스를 통합하는 기술이다.

---

## EAI 유형

### ① Point-to-Point

시스템끼리 직접 연결한다.

```text
직접 연결
→ Point-to-Point
```

특징:

* 구조 단순
* 초기 비용 낮음
* 시스템 증가 시 복잡
* 변경 및 재사용 어려움

---

### ② Hub & Spoke

중앙 허브를 통해 각 시스템을 연결한다.

```text
중앙 허브
→ Hub & Spoke
```

특징:

* 중앙 집중 관리
* 유지보수 용이
* 확장 용이
* 허브 장애 시 전체 영향

---

### ③ Message Bus

미들웨어 버스를 이용하여 각 시스템을 연결한다.

```text
미들웨어 버스
→ Message Bus
```

특징:

* 확장성 높음
* 대용량 처리에 유리

---

### ④ Hybrid

여러 EAI 방식을 혼합한 형태이다.

```text
혼합
→ Hybrid
```

---

# 6. 블랙박스 테스트 🔥🔥 매우 빈출

## 문제

다음은 블랙박스 테스트의 예시이다. (1), (2)에 알맞은 테스트를 작성하시오.

(1) `0 <= X <= 10`일 때, `-1, 0, 10, 11`인 경우 사용하는 테스트

(2) 유효값과 그렇지 않은 범위를 나눠야 할 경우 사용하는 테스트

## 정답

(1) **경계값 분석(Boundary Value Analysis)**

(2) **동등 분할 / 동치 분할(Equivalence Partitioning)**

---

## ① 경계값 분석

입력값의 경계 부근에서 오류가 발생할 가능성이 높다는 점을 이용한다.

예:

```text
유효 범위
0 ~ 10
```

대표 테스트:

```text
-1
0
1
9
10
11
```

문제에서는 대표적으로:

```text
-1, 0, 10, 11
```

---

## ② 동등 분할

입력값을 동일한 결과가 예상되는 유효/무효 그룹으로 나누고 각 그룹에서 대표값을 선택한다.

예:

```text
X < 0
→ 무효 그룹

0 ≤ X ≤ 10
→ 유효 그룹

X > 10
→ 무효 그룹
```

---

# 블랙박스 테스트 기법

```text
동등 분할
경계값 분석
원인-효과 그래프
오류 
예측
비교 검사
```

### 시험 암기

```text
경계 근처
→ 경계값 분석

유효/무효 영역 분할
→ 동등 분할
```

# 7. 세션 하이재킹 🔥 빈출

## 문제

괄호 안에 공통적으로 들어갈 공격 기법을 쓰시오.

(      )은 시스템 간 연결이 활성화된 상태, 즉 로그인 된 상태를 가로채는 것을 뜻한다.

(     )은 TCP의 고유한 취약점을 이용해 정상적인 접속을 빼앗는 방법이다. 서버와 클라이언트 통신 시 TCP의 시퀀스 넘버를 제어하는 데 발생하는 문제를 공격한다.

TCP는 클라이언트와 서버 간 통신을 할 때 패킷의 연속성을 보장하기 위해 각각 시퀀스 넘버를 사용한다. 이 시퀀스 넘버가 잘못되면 이를 바로잡기 위한 작업을 하는데, (        )은 서버와 클라이언트에 각각 잘못된 시퀀스 넘버를 위조해서 연결된 세션에 잠시 혼란을 준 뒤 자신이 끼어들어 가는 방식이다.

## 정답

**세션 하이재킹(Session Hijacking)**

## 개념

이미 인증되어 연결 중인 사용자의 세션을 공격자가 탈취하여 해당 사용자인 것처럼 통신하는 공격이다.

## 핵심 키워드

```text
로그인된 세션 탈취
TCP Sequence Number
정상 연결 가로채기
→ Session Hijacking
```

## 같이 알아둘 것

### 스니핑

네트워크 패킷을 엿보는 공격

### 스푸핑

IP, ARP, DNS 등의 정보를 위조하는 공격

### 세션 하이재킹

이미 연결된 세션 자체를 빼앗는 공격

# 8. IPv4 / IPv6 🔥🔥 매우 빈출

## 문제

다음 (1), (2)에 알맞은 답안을 작성하시오.

IPv6는 (1)비트의 길이를 가진다.

IPv4는 길이가 32비트이며, (2)비트씩 4분할 한다.

IPv6 : 유니, 멀티, 애니

IPv4 : 유니, 멀티, 브로드캐스트

## 정답

(1) **128**

(2) **8**

---

# IPv4

```text
32bit
```

8비트씩 4개로 나눈다.

```text
8bit . 8bit . 8bit . 8bit
```

예:

```text
192.168.0.1
```

### 주소 방식

* Unicast
* Multicast
* Broadcast

---

# IPv6

```text
128bit
```

16비트씩 8개로 표현한다.

예:

```text
2001:0db8:85a3:0000:0000:8a2e:0370:7334
```

### 주소 방식

* Unicast
* Multicast
* Anycast

### 중요

IPv6에는 **Broadcast가 없다.**

```text
IPv4
유니 / 멀티 / 브로드캐스트

IPv6
유니 / 멀티 / 애니캐스트
```

---

# IPv4 vs IPv6

| 구분        | IPv4  | IPv6   |
| --------- | ----- | ------ |
| 주소 길이     | 32bit | 128bit |
| 표기        | 10진수  | 16진수   |
| 구분        | `.`   | `:`    |
| Broadcast | O     | X      |
| Anycast   | 일반적 X | O      |

# 11. DAC 🔥 빈출

## 문제

시스템 객체의 접근을 개인 또는 그룹의 식별자에 기반한 방법으로 어떤 종류의 접근 권한을 가진 사용자가 다른 사용자에게 자신의 판단에 따라 권한을 허용하는 접근제어 방식은?

## 정답

**DAC(Discretionary Access Control)**
**임의적 접근 통제**

## 개념

자원의 소유자가 자신의 판단에 따라 다른 사용자에게 접근 권한을 부여하거나 회수할 수 있는 방식이다.

```text
소유자가 권한 결정
→ DAC
```

---

# 접근 통제 방식 같이 알아두기 🔥

## DAC

**Discretionary Access Control**

```text
소유자 판단
→ 권한 부여
```

예:
Linux 파일의 소유자가 다른 사용자에게 권한을 부여

---

## MAC

**Mandatory Access Control**

사용자가 임의로 권한을 바꿀 수 없고 **보안 등급과 정책**에 따라 시스템이 접근을 통제한다.

```text
보안 등급
보안 정책
→ MAC
```

---

## RBAC

**Role Based Access Control**

사용자의 역할(Role)에 따라 권한을 부여한다.

```text
관리자
회원
게스트
```

```text
역할
→ 권한
→ RBAC
```

# Bell-LaPadula 모델 🔥 중요

**기밀성(Confidentiality)을 보호하기 위한 접근 통제 모델**이다.

군사 보안 등급처럼 보안 레벨이 있는 환경에서 사용한다.

## 핵심 규칙

### No Read Up

**상위 등급의 정보를 읽을 수 없다.**

```text
낮은 등급 사용자
↓
높은 등급 정보 읽기 X
```

쉽게:

```text
위는 읽지 마
```

---

### No Write Down

**하위 등급으로 정보를 기록할 수 없다.**

```text
높은 등급 사용자
↓
낮은 등급 영역에 쓰기 X
```

왜?

높은 보안 정보가 낮은 등급으로 유출될 수 있기 때문이다.

쉽게:

```text
아래로 쓰지 마
```

---

## Bell-LaPadula 초암기

```text
기밀성 모델

No Read Up
→ 위 읽기 금지

No Write Down
→ 아래 쓰기 금지
```

---

# Biba 모델도 같이 알아두기 ⭐

Bell-LaPadula가 **기밀성**이라면 Biba는 **무결성(Integrity)**을 보호한다.

### Biba

```text
No Read Down
No Write Up
```

### 비교

```text
Bell-LaPadula
→ 기밀성
→ 위 읽기 X
→ 아래 쓰기 X

Biba
→ 무결성
```

# 12. WSDL 🔥 빈출

## 문제

웹 서비스의 구체적 내용이 기술되어 있어 서비스 제공 장소, 서비스 메시지 포맷, 프로토콜 등이 기술되어 있는 언어는?

## 정답

**WSDL**

## WSDL

**Web Services Description Language**

# 13. 단위 테스트 / 통합 테스트 🔥🔥 매우 중요

## 문제

`<보기>`에 해당하는 용어를 쓰시오.

(1) 개발자가 원시 코드를 대상으로 다른 부분과 연계되는 부분은 고려하지 않고, 각각의 단위 자체에만 집중하여 테스트한다.

(2) 인터페이스 간 시스템이 정상적으로 실행되는지 확인하는 테스트이다.

## 정답

(1) **단위 테스트(Unit Test)**

(2) **통합 테스트(Integration Test)**

---

# 테스트 단계

```text
단위 테스트
→ 통합 테스트
→ 시스템 테스트
→ 인수 테스트
```

---

# ① 단위 테스트

프로그램의 가장 작은 단위인 모듈, 클래스, 함수 등을 독립적으로 테스트한다.

```text
하나의 모듈 자체
→ 단위 테스트
```

> 정적 테스트와 동적 테스트는 `단위 테스트의 하위 분류`라기보다는 **프로그램 실행 여부에 따른 테스트 분류**이므로 별도로 구분해 기억하는 것이 더 정확하다.

---

# ② 통합 테스트

단위 테스트가 끝난 여러 모듈을 결합하여 **인터페이스와 상호작용이 정상적인지** 테스트한다.

## 통합 테스트 방법

### 하향식(Top-Down)

상위 모듈부터 아래로 내려가며 통합한다.

부족한 하위 모듈 대신:

**Stub** 사용

```text
Top-Down
→ Stub
```

---

### 상향식(Bottom-Up)

하위 모듈부터 위로 올라가며 통합한다.

상위 모듈 역할 대신:

**Driver** 사용

```text
Bottom-Up
→ Driver
```

---

### Big Bang

모든 모듈을 한 번에 통합하여 테스트한다.

### 샌드위치 / 혼합식

상향식과 하향식을 결합한다.

> 네 필기의 `백도어 테스트`는 통합 테스트의 표준 분류로 보기 어렵고, 보통 시험에서는 **하향식 / 상향식 / 빅뱅 / 샌드위치**를 중심으로 공부하는 게 안전하다.

---

# ③ 시스템 테스트

완성된 시스템 전체가 요구사항을 만족하는지 테스트한다.

### 종류

* 기능 테스트
* 비기능 테스트

---

# ④ 인수 테스트

사용자나 고객 관점에서 실제 사용이 가능한지 최종적으로 테스트한다.

### 종류

#### 알파 테스트

개발자 환경에서 사용자와 개발자가 함께 수행

#### 베타 테스트

실제 사용자 환경에서 사용자가 수행

```text
Alpha
→ 개발자 환경

Beta
→ 실제 사용
자 환경
```

# 14. 반정규화 🔥🔥 매우 빈출

## 문제

시스템의 성능 향상, 개발 과정의 편의성 등을 위해 정규화된 데이터 모델을 분할, 통합, 추가하는 과정으로, 의도적으로 정규화에 위배되는 행위이다.

무엇을 설명하는 것인지 쓰시오.

## 정답

**반정규화(Denormalization)**

또는

**비정규화 / 역정규화**

## 시험용 답안

> 정규화된 데이터베이스에서 성능 향상이나 개발 편의성을 위해 의도적으로 중복을 허용하거나 테이블을 통합·분할하는 기법이다.

## 핵심

```text
정규화 이후
+
성능 향상
+
정규화 원칙 일부 위배
→ 반정규화
```

### 매우 중요

**성능 향상**이라는 표현을 꼭 기억.

# 15. IPC 🔥 빈출

## 문제

실행 프로세스 간에 통신을 가능하게 하는 기술로, 종류에는 파이프, 메시지 큐, 공유메모리, 세마포어, 소켓 등이 있다.

## 정답

**IPC(Inter-Process Communication)**

## 개념

서로 독립적으로 실행되는 프로세스들이 데이터를 주고받거나 동기화하기 위한 통신 기법이다.

## IPC 종류

```text
Pipe
Message Queue
Shared Memory
Semaphore
Socket
```

---

# ① Pipe

프로세스 사이에서 데이터를 한 방향 또는 양방향으로 전달한다.

# ② Message Queue

메시지를 큐에 저장하여 프로세스끼리 전달한다.

# ③ Shared Memory

여러 프로세스가 동일한 메모리 공간을 공유한다.

### 특징

```text
매우 빠름
```

하지만 동시 접근 문제 때문에 동기화가 필요하다.

# ④ Semaphore

공유 자원에 접근할 수 있는 프로세스 수를 제어한다.

# ⑤ Socket

네트워크 또는 로컬 환경에서 프로세스 간 통신에 사용한다.

---

# IPC 초압축

```text
프로세스끼리 통신
→ IPC

Pipe
Message Queue
Shared Memory
Semaphore
Socket
```
