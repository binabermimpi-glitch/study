# C언어 핵심 개념 및 코드 문제 정리

## 1. 반복문과 printf() 출력 위치

### 1-1. 문제

```c
#include <stdio.h>

int main() {
    int i = 0, c = 0;

    while (i < 10) {
        i++;
        c *= i;
    }

    printf("%d", c);

    return 0;
}
```

### 정답

```text
0
```

### 실행 과정

`c *= i`는 `c = c * i`와 같다.

| 반복 | i | 계산 | c |
|---|---|---|---|
| 1 | 1 | 0 × 1 | 0 |
| 2 | 2 | 0 × 2 | 0 |
| 3 | 3 | 0 × 3 | 0 |
| 4 | 4 | 0 × 4 | 0 |
| 5 | 5 | 0 × 5 | 0 |
| 6 | 6 | 0 × 6 | 0 |
| 7 | 7 | 0 × 7 | 0 |
| 8 | 8 | 0 × 8 | 0 |
| 9 | 9 | 0 × 9 | 0 |
| 10 | 10 | 0 × 10 | 0 |

반복문은 10번 실행되지만 `printf()`는 반복문 밖에 있으므로 한 번만 실행된다.

따라서 `0000000000`이 아니라 `0`이 출력된다.

### 1-2. printf() 위치 비교

**반복문 밖**

```c
while (i < 10) {
    i++;
    c *= i;
}

printf("%d", c);
```

출력:

```text
0
```

**반복문 안**

```c
while (i < 10) {
    i++;
    c *= i;
    printf("%d", c);
}
```

출력:

```text
0000000000
```

### 핵심 정리

- 반복문이 실행되는 횟수와 출력 횟수는 다를 수 있다.
- 변수에 값을 저장하는 것과 화면에 출력하는 것은 별개의 동작이다.
- `printf()`가 반복문 안에 있으면 반복할 때마다 출력한다.
- `printf()`가 반복문 밖에 있으면 반복문 종료 후 한 번 출력한다.
- `c *= i`는 기존 c에 i를 곱한 결과를 다시 c에 저장한다.

## 2. printf() 출력 형식 지정자

### 2-1. 주요 형식 지정자

| 형식 | 의미 | 설명 | 예시 | 출력 |
|---|---|---|---|---|
| `%d` | decimal | 부호 있는 10진수 정수 | `printf("%d", 42);` | 42 |
| `%c` | character | 문자 한 개 | `printf("%c", 'A');` | A |
| `%s` | string | 문자열 | `printf("%s", "Hi");` | Hi |
| `%f` | floating-point | 실수 출력, 기본 소수점 6자리 | `printf("%f", 3.14);` | 3.140000 |
| `%x` | hexadecimal | 16진수 소문자 | `printf("%x", 255);` | ff |
| `%X` | hexadecimal | 16진수 대문자 | `printf("%X", 255);` | FF |
| `%o` | octal | 8진수 | `printf("%o", 8);` | 10 |
| `%e` | exponential | 지수 표기 | `printf("%e", 12345.0);` | 1.234500e+04 |

### 2-2. 16진수에서 255가 ff가 되는 이유

```c
int n = 255;

printf("%d\n", n);
printf("%x\n", n);
printf("%X\n", n);
printf("%o\n", n);
```

출력:

```text
255
ff
FF
377
```

10진수는 0~9까지 사용한다.

16진수는 0~9와 A~F까지 사용한다.

| 10진수 | 16진수 |
|---|---|
| 10 | A |
| 11 | B |
| 12 | C |
| 13 | D |
| 14 | E |
| 15 | F |
| 16 | 10 |

255를 16진수로 변환하면 다음과 같다.

```text
255 ÷ 16 = 15 ... 나머지 15
 15 ÷ 16 =  0 ... 나머지 15
```

나머지를 아래에서 위로 읽는다.

```text
15 → F
15 → F

255(10진수) = FF(16진수)
```

수식:

```text
255 = 15 × 16¹ + 15 × 16⁰
    = 240 + 15
```

### 핵심 정리

- `%d` : 10진수
- `%x` : 16진수 소문자
- `%X` : 16진수 대문자
- `%o` : 8진수
- 진법이 달라져도 실제 숫자의 값은 변하지 않는다.
- `%x`, `%X`, `%o`는 대응하는 `unsigned int` 형식의 인수를 기대하므로 엄밀하게는 해당 형식에 맞춰 전달한다.

## 3. 실수 출력과 소수점 자리수

### 예제

```c
double v = 12345.6789;

printf("%f\n", v);
printf("%.2f\n", v);
printf("%e\n", v);
printf("%.2e\n", v);
```

출력:

```text
12345.678900
12345.68
1.234568e+04
1.23e+04
```

### 설명

**%f**

```c
printf("%f", v);
```

기본적으로 소수점 이하 6자리까지 출력한다.

**%.2f**

```c
printf("%.2f", v);
```

소수점 이하 2자리까지 출력한다.

일반적인 반올림 결과가 나오지만, 정확한 결과는 저장된 부동소수점 값과 반올림 규칙에 영향을 받을 수 있다.

**%e**

```c
printf("%e", v);
```

지수 형식으로 출력한다.

```text
1.234568e+04
```

이는 다음 의미다.

```text
1.234568 × 10⁴
```

### 핵심 정리

- `%f` : 일반 소수 표현
- `%.2f` : 소수점 이하 2자리
- `%e` : 지수 표현
- `%.2e` : 지수 표현에서 소수점 이하 2자리
- `double`을 `printf()`로 출력할 때 `%f`를 사용한다.

## 4. scanf()와 주소 연산자 &

### 4-1. scanf()란?

`scanf()`는 키보드 등 표준 입력에서 값을 읽어 변수에 저장하는 함수다.

```c
#include <stdio.h>

int main() {
    int a;

    scanf("%d", &a);

    printf("%d", a);

    return 0;
}
```

입력:

```text
5
```

출력:

```text
5
```

### 4-2. printf()와 scanf() 차이

| 함수 | 역할 |
|---|---|
| `printf()` | 값을 화면에 출력 |
| `scanf()` | 입력받은 값을 변수에 저장 |

### 4-3. 왜 &a를 사용할까?

```c
int a;

scanf("%d", &a);
```

- `a` : 변수 a에 저장된 값
- `&a` : 변수 a의 메모리 주소

`scanf()`는 입력된 값을 변수에 저장해야 하므로 변수의 주소를 전달받는다.

예를 들어 변수 a의 주소가 100번지라고 가정하면 다음과 같다.

```text
변수 a
주소 : 100
값   : 초기화되지 않음

scanf("%d", &a);

사용자가 42 입력

주소 : 100
값   : 42
```

C언어의 일반적인 함수 인수 전달은 값에 의한 전달이다.

따라서 함수에 변수의 값을 전달하면 복사된 값이 전달된다.

반면 주소를 전달하면 함수는 그 주소를 통해 원본 변수의 값을 수정할 수 있다.

### 4-4. 문자열 입력

```c
char str[50];

scanf("%49s", str);
```

입력:

```text
Hello World
```

저장:

```text
Hello
```

`%s`는 앞쪽 공백을 건너뛰고, 이후 공백 문자가 나오기 전까지 문자열을 읽는다.

문자 배열의 이름 `str`은 이 문맥에서 첫 번째 요소의 주소로 변환되므로 `&str`을 사용할 필요가 없다.

`%49s`는 최대 49개의 문자를 읽고 마지막에 널 문자 `\0`을 저장한다.

### 4-5. 공백이 포함된 문자열 입력

```c
char str[50];

fgets(str, sizeof(str), stdin);
```

입력:

```text
Hello World
```

저장:

```text
Hello World\n
```

입력 길이에 여유가 있다면 줄바꿈 문자도 함께 저장된다.

### 주의사항

```c
gets(str);
```

`gets()`는 입력 길이를 제한하지 못해 버퍼 오버플로가 발생할 수 있는 위험한 함수다.

C11 표준부터 제거되었으므로 사용하지 않는다.

문자열 한 줄을 입력받을 때는 `fgets()`를 사용하는 것이 좋다.

## 5. C언어 정수 나눗셈과 형변환

### 예제

```c
int a = 5;
int b = 2;

int r1 = a / b;
double r2 = a / b;
double r3 = a / 2.0;
double r4 = (double)a / b;
```

### 정답

| 변수 | 계산 | 결과 |
|---|---|---|
| r1 | 5 / 2 | 2 |
| r2 | 5 / 2 → double 변환 | 2.0 |
| r3 | 5 / 2.0 | 2.5 |
| r4 | (double)5 / 2 | 2.5 |

### 5-1. 정수끼리 나누면?

```c
int a = 5;
int b = 2;

double result = a / b;
```

계산 순서:

```text
1. a / b 계산
2. 5 / 2 = 2
3. 정수 2를 double로 변환
4. 2.0 저장
```

따라서 결과는 2.0이다.

### 5-2. 실수 나눗셈

```c
double result = a / 2.0;
```

`2.0`이 실수이므로 `a`도 실수형으로 변환된 후 계산된다.

```text
5.0 / 2.0 = 2.5
```

### 5-3. 명시적 형변환

```c
double result = (double)a / b;
```

`(double)a`를 통해 a를 실수형으로 변환한 다음 계산한다.

```text
5.0 / 2.0 = 2.5
```

### 핵심 정리

- 정수 / 정수 → 정수 나눗셈
- 정수 / 실수 → 실수 나눗셈
- `(double)` → 명시적 형변환
- 대입할 변수의 자료형은 오른쪽 나눗셈의 계산 방식을 바꾸지 않는다.
- 이미 정수 나눗셈으로 버려진 소수 부분은 대입 과정에서 복구되지 않는다.

## 6. 배열의 초기화

### 6-1. 배열 선언

```c
int arr[3] = {10, 20, 30};

int arr2[] = {1, 2, 3};

int arr3[5] = {1, 2};

int arr4[3] = {0};
```

### 배열의 값

```text
arr  = {10, 20, 30}

arr2 = {1, 2, 3}

arr3 = {1, 2, 0, 0, 0}

arr4 = {0, 0, 0}
```

초기화 목록을 사용하면서 요소 일부만 지정하면 나머지 요소는 0으로 초기화된다.

### 6-2. 문제

```c
#include <stdio.h>

int main() {
    int a[4] = {2};

    printf("%d %d %d", a[0], a[1], a[3]);

    return 0;
}
```

### 정답

```text
2 0 0
```

### 실행 과정

```c
int a[4] = {2};
```

실제 배열:

| 인덱스 | 값 |
|---|---|
| a[0] | 2 |
| a[1] | 0 |
| a[2] | 0 |
| a[3] | 0 |

따라서 다음 코드에서

```c
printf("%d %d %d", a[0], a[1], a[3]);
```

출력 결과는 다음과 같다.

```text
2 0 0
```

### 공백도 출력 결과에 포함될까?

그렇다.

```c
printf("%d%d%d", 2, 0, 0);
```

출력:

```text
200
```

반면

```c
printf("%d %d %d", 2, 0, 0);
```

출력:

```text
2 0 0
```

### 핵심 정리

- 배열 인덱스는 0부터 시작한다.
- 배열 크기가 4이면 인덱스는 0~3이다.
- 부분 초기화를 하면 나머지 요소는 0으로 초기화된다.
- `printf()`의 서식 문자열에 있는 공백도 출력된다.

## 7. 논리 NOT 연산자 !와 비트 NOT 연산자 ~

### 7-1. 논리 NOT (!)

```c
int a = 0;

int result = !!a;
```

실행 과정:

```text
a = 0

!a = 1

!!a = !1

결과 = 0
```

논리 NOT은 다음 규칙을 따른다.

| 값 | ! 연산 결과 |
|---|---|
| 0 | 1 |
| 0이 아닌 값 | 0 |

예제:

```c
!0  // 1
!1  // 0
!5  // 0
!!5 // 1
```

### 7-2. 비트 NOT (~)

```c
int b = 5;

int result = ~~b;
```

비트 NOT은 각 비트를 반전한다.

```text
0 → 1
1 → 0
```

일반적인 2의 보수 표현에서는 다음 공식이 성립한다.

```text
~x = -x - 1
```

따라서

```text
~5 = -5 - 1
   = -6
```

그리고

```text
~~5 = ~(-6)
    = -(-6) - 1
    = 6 - 1
    = 5
```

### 7-3. 2진수로 확인

8비트 2의 보수 표현을 예로 들면 다음과 같다.

```text
5

00000101
```

비트를 반전하면

```text
11111010
```

2의 보수에서 이 값은 -6이다.

다시 반전하면

```text
00000101
```

다시 5가 된다.

### 핵심 정리

| 연산자 | 의미 | 예시 |
|---|---|---|
| `!` | 논리 부정 | `!5 = 0` |
| `!!` | 논리 부정 두 번 | `!!5 = 1` |
| `~` | 비트 반전 | `~5 = -6` |
| `~~` | 비트 반전 두 번 | `~~5 = 5` |

`!`와 `~`는 전혀 다른 연산자다.

## 8. 삼항 연산자와 결합 방향

### 8-1. 기본 구조

```c
조건식 ? 참일 때 값 : 거짓일 때 값;
```

예제:

```c
int a = 5;

int result = a > 3 ? 10 : 20;
```

계산:

```text
5 > 3 → 참

result = 10
```

### 8-2. 중첩 삼항 연산자

```c
int a = 0, b = 1;

int result = a ? 1 : b ? 2 : 3;
```

삼항 연산자는 오른쪽에서 왼쪽으로 결합한다.

따라서 괄호를 넣으면 다음과 같다.

```c
int result = a ? 1 : (b ? 2 : 3);
```

### 실행 과정

**1단계**

```text
a = 0
```

C언어에서 0은 거짓이다.

따라서 첫 번째 삼항 연산자의 거짓 부분으로 이동한다.

```c
b ? 2 : 3
```

**2단계**

```text
b = 1
```

0이 아닌 값은 참이다.

따라서 2를 선택한다.

**3단계**

```text
result = 2
```

### 핵심 정리

- 삼항 연산자는 조건식부터 평가한다.
- 조건에 따라 두 번째 또는 세 번째 피연산자 중 하나만 평가한다.
- 중첩 삼항 연산자는 오른쪽에서 왼쪽으로 결합한다.
- 결합 방향과 실제 실행 순서는 구분해야 한다.

## 9. 비트 연산자와 비교 연산자의 우선순위

### 9-1. 문제

```c
int a = 3 & 2 == 2;

int b = (3 & 2) == 2;
```

### 정답

```text
a = 1
b = 1
```

두 결과는 같지만 계산 과정은 다르다.

### 9-2. a의 계산 과정

```c
int a = 3 & 2 == 2;
```

`==`는 비트 AND `&`보다 우선순위가 높다.

따라서 다음과 같다.

```c
int a = 3 & (2 == 2);
```

계산:

```text
2 == 2 → 1

3 & 1
```

2진수:

```text
3 = 0011
1 = 0001
---------
& = 0001
```

결과:

```text
a = 1
```

### 9-3. b의 계산 과정

```c
int b = (3 & 2) == 2;
```

괄호 안을 먼저 계산한다.

```text
3 = 0011
2 = 0010
---------
& = 0010
```

따라서

```text
3 & 2 = 2

2 == 2 → 1
```

결과:

```text
b = 1
```

### 핵심 정리

- `==`는 비트 AND `&`보다 우선순위가 높다.
- 비트 AND는 같은 위치의 비트가 모두 1일 때만 1이다.
- 비트 연산을 먼저 하려면 괄호를 사용한다.

## 10. 연산자 우선순위 종합 문제

### 문제

```c
#include <stdio.h>

int main() {
    int x = 7, y = 5, z;

    z = y % 3 < 2 ? 3 : 6;

    z = z & z >> 1;

    z = x > 5 && z <= 3 ? z * x : x / z;

    printf("%d", z);

    return 0;
}
```

### 정답

```text
14
```

### 10-1. 첫 번째 연산

```c
z = y % 3 < 2 ? 3 : 6;
```

괄호를 넣으면

```c
z = ((y % 3) < 2) ? 3 : 6;
```

계산:

```text
y = 5

5 % 3 = 2

2 < 2 → 거짓

z = 6
```

### 10-2. 두 번째 연산

```c
z = z & z >> 1;
```

시프트 연산자 `>>`가 비트 AND `&`보다 먼저 계산된다.

따라서

```c
z = z & (z >> 1);
```

현재 z는 6이다.

```text
6 = 00000110
```

오른쪽으로 1비트 이동하면

```text
6 >> 1

00000110
↓
00000011

결과 = 3
```

이제 비트 AND 연산을 수행한다.

```text
  00000110 (6)
& 00000011 (3)
-----------
  00000010 (2)
```

따라서

```text
z = 2
```

### 10-3. 세 번째 연산

```c
z = x > 5 && z <= 3 ? z * x : x / z;
```

괄호를 넣으면

```c
z = ((x > 5) && (z <= 3)) ? (z * x) : (x / z);
```

현재 값:

```text
x = 7
z = 2
```

조건 계산:

```text
7 > 5 → 참

2 <= 3 → 참

1 && 1 → 참
```

조건이 참이므로

```text
z = z * x

z = 2 * 7

z = 14
```

### 최종 실행 결과

| 단계 | 계산 | z |
|---|---|---|
| 1 | `5 % 3 < 2 ? 3 : 6` | 6 |
| 2 | `6 & (6 >> 1)` | 2 |
| 3 | `2 * 7` | 14 |

최종 출력:

```text
14
```

## 11. 재귀함수 기본 개념

재귀함수는 함수 내부에서 자기 자신을 다시 호출하는 함수다.

### 기본 구조

```c
int fn(int n) {
    if (n <= 1) {
        return 1;
    }

    return n * fn(n - 1);
}
```

### 예제

```c
#include <stdio.h>

int fn(int a) {
    if (a <= 1) {
        return 1;
    }

    return a * fn(a - 1);
}

int main() {
    int a;

    scanf("%d", &a);

    printf("%d", fn(a));

    return 0;
}
```

입력:

```text
5
```

출력:

```text
120
```

### 실행 과정

```text
fn(5)
= 5 * fn(4)
= 5 * 4 * fn(3)
= 5 * 4 * 3 * fn(2)
= 5 * 4 * 3 * 2 * fn(1)
= 5 * 4 * 3 * 2 * 1
= 120
```

### 재귀함수의 중요 구성 요소

**1. 종료 조건**

```c
if (n <= 1) {
    return 1;
}
```

재귀호출을 멈추는 조건이다.

**2. 재귀 호출**

```c
return n * fn(n - 1);
```

자기 자신을 다시 호출한다.

**3. 반환 과정**

가장 깊은 호출에서 반환된 값을 이용해 이전 함수의 계산을 완료한다.

### 핵심 정리

- 재귀함수는 자기 자신을 호출한다.
- 종료 조건이 중요하다.
- 각 함수 호출은 자신의 매개변수와 지역변수를 가진다.
- 함수가 반환되면 호출한 위치로 돌아간다.
- 같은 함수가 여러 번 호출될 수 있다.

## 12. 재귀함수 변형 문제 (1) — gamja(n-1) + gamja(n-2)

### 문제

```c
#include <stdio.h>

int gamja(int n) {
    if (n <= 2) {
        return n;
    }
    else {
        return gamja(n - 1) + gamja(n - 2);
    }
}

int main() {
    printf("%d", gamja(6));

    return 0;
}
```

### 정답

```text
13
```

### 실행 과정

종료 조건:

```c
if (n <= 2) {
    return n;
}
```

따라서

```text
gamja(1) = 1
gamja(2) = 2
```

이후 작은 값부터 계산한다.

| 함수 | 계산 과정 | 반환값 |
|---|---|---|
| gamja(1) | 종료 조건 | 1 |
| gamja(2) | 종료 조건 | 2 |
| gamja(3) | gamja(2) + gamja(1) | 3 |
| gamja(4) | gamja(3) + gamja(2) | 5 |
| gamja(5) | gamja(4) + gamja(3) | 8 |
| gamja(6) | gamja(5) + gamja(4) | 13 |

최종 계산:

```text
gamja(6)
= gamja(5) + gamja(4)
= 8 + 5
= 13
```

## 13. 재귀함수 변형 문제 (2) — gamja(n-2) + gamja(n-3)

### 문제

```c
#include <stdio.h>

int gamja(int n) {
    if (n <= 1) {
        return 1;
    }
    else {
        return gamja(n - 2) + gamja(n - 3);
    }
}

int main() {
    printf("%d", gamja(7));

    return 0;
}
```

### 정답

```text
7
```

### 13-1. 종료 조건 확인

```c
if (n <= 1) {
    return 1;
}
```

n이 1 이하라면 무조건 1을 반환한다.

따라서

```text
gamja(-1) = 1
gamja(0)  = 1
gamja(1)  = 1
```

### 13-2. 작은 값부터 계산

| 함수 | 계산 과정 | 반환값 |
|---|---|---|
| gamja(-1) | 종료 조건 | 1 |
| gamja(0) | 종료 조건 | 1 |
| gamja(1) | 종료 조건 | 1 |
| gamja(2) | gamja(0) + gamja(-1) | 2 |
| gamja(3) | gamja(1) + gamja(0) | 2 |
| gamja(4) | gamja(2) + gamja(1) | 3 |
| gamja(5) | gamja(3) + gamja(2) | 4 |
| gamja(6) | gamja(4) + gamja(3) | 5 |
| gamja(7) | gamja(5) + gamja(4) | 7 |

### 13-3. gamja(7) 계산 과정

```text
gamja(7)
= gamja(5) + gamja(4)
```

먼저 gamja(5)를 계산한다.

```text
gamja(5)
= gamja(3) + gamja(2)
= 2 + 2
= 4
```

다음으로 gamja(4)를 계산한다.

```text
gamja(4)
= gamja(2) + gamja(1)
= 2 + 1
= 3
```

최종 계산:

```text
gamja(7)
= gamja(5) + gamja(4)
= 4 + 3
= 7
```

### 핵심 정리

- `n <= 1`이면 음수도 종료 조건에 포함된다.
- `gamja(n-2)`와 `gamja(n-3)`는 서로 다른 인수로 호출된다.
- 작은 인수에 대한 반환값부터 계산하면 문제를 쉽게 해결할 수 있다.
- 동일한 인수의 함수가 여러 번 호출될 수 있다.
- 계산표에 같은 값을 한 번만 적는 것은 풀이를 간단하게 하기 위한 방법이며 실제 호출 횟수와는 다르다.

## 14. C언어 연산자 우선순위 정리

이번에 공부한 연산자들을 중심으로 우선순위를 정리한다.

위에 있을수록 우선순위가 높다.

| 우선순위 | 연산자 | 의미 |
|---|---|---|
| 1 | `()` | 괄호 |
| 2 | `!`, `~`, `(자료형)` | 단항 연산, 형변환 |
| 3 | `*`, `/`, `%` | 곱셈, 나눗셈, 나머지 |
| 4 | `+`, `-` | 덧셈, 뺄셈 |
| 5 | `<<`, `>>` | 비트 시프트 |
| 6 | `<`, `<=`, `>`, `>=` | 대소 비교 |
| 7 | `==`, `!=` | 동등 비교 |
| 8 | `&` | 비트 AND |
| 9 | `^` | 비트 XOR |
| 10 | `|` | 비트 OR |
| 11 | `&&` | 논리 AND |
| 12 | `||` | 논리 OR |
| 13 | `?:` | 삼항 연산자 |
| 14 | `=`, `+=`, `-=`, `*=`, `/=` 등 | 대입 연산 |

※ 위 표는 학습한 연산자 중심의 요약이며, 모든 C 연산자를 나열한 것은 아니다.

### 반드시 기억할 우선순위 관계

```text
산술 연산 > 비교 연산 > 비트 AND > 논리 AND > 삼항 연산 > 대입 연산
```

예를 들어

```c
3 & 2 == 2
```

는 다음과 같다.

```c
3 & (2 == 2)
```

그리고

```c
z & z >> 1
```

은 다음과 같다.

```c
z & (z >> 1)
```

### 주의사항

연산자 우선순위는 수식을 어떻게 묶는지 결정한다.

실제 피연산자가 평가되는 순서까지 모두 결정하는 것은 아니다.

괄호를 사용하면 계산 의도를 더 명확하게 나타낼 수 있다.

# 최종 핵심 복습

1. `printf()`의 위치에 따라 반복문의 출력 횟수가 달라진다.
2. `%d`, `%x`, `%X`, `%o`는 서로 다른 진법으로 값을 출력한다.
3. `%f`는 기본적으로 소수점 이하 6자리까지 출력한다.
4. `scanf("%d", &a)`는 a의 주소를 전달하여 입력값을 저장한다.
5. 문자열 입력에는 길이 제한을 적용하고, 한 줄 입력에는 `fgets()`를 사용한다.
6. 정수끼리 나누면 정수 나눗셈이 먼저 수행된다.
7. 배열을 부분 초기화하면 나머지 요소는 0으로 초기화된다.
8. `!`는 논리 부정이고 `~`는 비트 반전이다.
9. 일반적인 2의 보수 정수 표현에서 `~x = -x - 1`이다.
10. 삼항 연산자는 오른쪽에서 왼쪽으로 결합한다.
11. `==`는 비트 AND `&`보다 우선순위가 높다.
12. `>>`는 비트 AND `&`보다 우선순위가 높다.
13. 재귀함수는 종료 조건을 확인하고 작은 값부터 계산하면 쉽다.
14. 같은 재귀함수가 여러 번 호출될 수 있다.
15. 최종 정답에서는 출력 공백까지 확인해야 한다.
