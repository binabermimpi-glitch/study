# 정보처리기사 실기 앱 추가 정리 ②

## 학습 문제 목록

1. DFD — 데이터가 프로세스를 따라 흐르고 변환되는 모습을 나타내는 자료 흐름도
2. 일관성 검사 오라클 — 애플리케이션 변경 전후 결과 비교
3. 동등 분할 테스트 — 동일한 결과가 예상되는 입력 영역별 대표값 테스트
4. 객체 다이어그램 — 특정 시점 인스턴스와 관계 표현
5. 배치 다이어그램 — 물리 노드에 소프트웨어가 배치되는 위치 표현
6. SSH — 암호화 원격 로그인·명령·파일 전송, 기본 포트 22
7. Adapter Pattern — 호환되지 않는 인터페이스 연결
8. LRU — 가장 오랫동안 사용하지 않은 페이지 교체
9. UML static 표기 — 멤버에 밑줄, static은 접근제어자가 아님
10. EAI Workflow — 프로세스 자동화·감시·최적화
11. Checkstyle — Java 코딩 규칙 정적 검사
12. Facade Pattern — 복잡한 서브시스템을 단순한 통합 창구로 제공
13. Clearing House — DRM 라이선스·권한·사용량 관리
14. Tamper Proofing — 불법 변조 감지 시 정상 실행 방지
15. Spoofing — 신원이나 주소 정보를 위조해 승인된 대상으로 가장

## 구별해서 기억할 내용

- 동등 분할은 입력 영역을 나누고, 경계값 분석은 경계 근처 값을 검사한다.
- 컴포넌트 다이어그램은 구조와 의존관계, 배치 다이어그램은 하드웨어 노드의 물리적 배치를 표현한다.
- Telnet은 평문 23번, SSH는 암호화 22번 포트를 기본으로 한다.
- Adapter는 인터페이스 호환, Facade는 복잡한 시스템에 단순한 창구를 제공한다.
- Checkstyle은 코딩 규칙, PMD는 코드 결함, SonarQube는 품질·보안·복잡도 종합 분석이다.
- Spoofing은 위조·가장, Sniffing은 패킷 엿보기, Session Hijacking은 세션 탈취다.
