# 개발 공부 LLM Wiki

자바 백엔드 개발자로 출발하기 위해 국비수업과 자격증 공부에서 얻은 지식을 함께 축적하는 개인 위키입니다.

## 시작하는 법

1. 정리하지 않은 메모는 `00 인박스/`에 넣습니다.
2. 보존할 수업자료와 원문은 `10 원문/`에 넣습니다.
3. Codex에게 아래처럼 요청합니다.

> `00 인박스/파일명.md`를 원문으로 보존하고 위키에 반영해줘. 초보자가 이해하기 쉽게 설명하고, 기초 배경·실무 핵심·제한적 활용 중 어디에 해당하는지도 이유와 함께 표시해줘.

4. 전체 목차는 [[20 위키/index|위키 인덱스]]에서 확인합니다.
5. 처리 기록은 [[20 위키/log|위키 작업 로그]]에서 확인합니다.

자격증 공부는 [[20 위키/04 자격증/README|자격증 학습 허브]]에서 시작합니다. 정보처리기사, SQLD, 리눅스마스터 2급에서 배운 개념은 국비수업의 Java·Database·Web·Linux 문서와 연결합니다.

국비수업 문제는 [[20 위키/05 문제 풀이/README|문제 풀이 허브]]에서 관리합니다. 문제, 첫 풀이, 막힌 과정, 정답과 재풀이를 한 문서에 누적합니다.

## 추천 질문

- 오늘 배운 내용에서 반드시 이해해야 할 핵심 세 가지만 알려줘.
- 이 개념을 배우기 전에 무엇을 알아야 해?
- 이 내용은 실무에서 언제 사용해?
- 비슷한 개념끼리 비교표를 만들어 위키에 저장해줘.
- 이번 주 수업 내용을 복습 순서대로 연결해줘.
- 위키를 점검해서 빠진 선행지식과 출처 없는 설명을 찾아줘.
