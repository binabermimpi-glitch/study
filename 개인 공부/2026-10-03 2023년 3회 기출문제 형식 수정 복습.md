# 2023년 3회 기출문제 형식 수정 복습

이 문서는 홈페이지에 배포되지 않는 개인 복습용 문서다.

## 무엇이 문제였나

2023년 3회 문서는 내용이 누락된 것이 아니라 Markdown 문법이 이전 회차와 달랐다. `=` 문자와 대괄호 표기는 화면에서 문서 구조로 인식되지 않아 문제 번호와 문제·정답 구분이 작고 평평하게 표시됐다.

## 문제 번호 형식

### Before

```markdown
==================================================
1. OAuth
==================================================
```

`=` 문자열은 장식 문자일 뿐이라 VitePress의 제목이나 구분선으로 처리되지 않는다.

### After

```markdown
---

# 1. OAuth
```

`---`는 구분선, `#`은 가장 큰 제목을 의미한다. 따라서 문제 하나의 시작점이 이전 회차와 동일하게 표시된다.

## 문제·정답·해설 형식

### Before

```markdown
[문제]
문제 내용

[정답]
OAuth

[핵심]
토큰을 사용한 접근 권한 위임
```

대괄호만 사용한 문장은 일반 본문이므로 목차와 제목 구조에 포함되지 않는다.

### After

```markdown
## 문제

문제 내용

## 정답

OAuth

## 핵심

토큰을 사용한 접근 권한 위임
```

`##`를 사용하면 각 문제 아래의 하위 제목이 되어 문제·정답·핵심을 빠르게 구분할 수 있다.

## 보기 형식

### Before

```markdown
<보기>
Privacy
OAuth
```

꺾쇠괄호는 HTML 태그처럼 해석될 여지가 있어 제목 용도로 적합하지 않다.

### After

```markdown
## 보기

Privacy
OAuth
```

## 적용한 변환 규칙

```text
==== + 문제 번호 + ====  →  --- + # 문제 번호
[문제]                  →  ## 문제
[정답]                  →  ## 정답
[개념]                  →  ## 개념
[핵심]                  →  ## 핵심
<보기>                  →  ## 보기
```

## 기억할 점

- `#`은 큰 제목, `##`는 그 아래 제목이다.
- `---`는 내용을 나누는 구분선이다.
- `[문제]`는 눈으로는 제목처럼 보여도 Markdown에서는 일반 텍스트다.
- 문서의 내용과 문서의 표시 형식은 별개다. 이번 수정은 원문 내용을 바꾸지 않고 표시 구조만 변경한 것이다.
