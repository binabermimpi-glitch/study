# 정규화와 이상 현상

## 목적

정규화는 함수적 종속성을 바탕으로 릴레이션을 바람직하게 분해해 중복과 삽입·갱신·삭제 이상을 줄이는 과정이다.

## 이상 현상

- 삽입 이상: 필요한 사실을 넣기 위해 무관한 값도 넣어야 함
- 갱신 이상: 중복된 일부 값만 바뀌어 불일치 발생
- 삭제 이상: 한 사실을 삭제하면서 다른 필요한 사실도 소실

## 정규형 요약

| 정규형 | 제거하거나 만족할 것 |
|---|---|
| 1NF | 속성 값의 원자성 |
| 2NF | 후보키의 일부에만 종속되는 부분 함수 종속 제거 |
| 3NF | 키가 아닌 속성 사이의 이행 함수 종속 제거 |
| BCNF | 모든 결정자가 후보키 |
| 4NF | 비자명한 다치 종속 문제 제거 |
| 5NF | 조인 종속 문제 제거 |

복합키가 없는 테이블에서는 부분 함수 종속이 발생하지 않으므로 2NF 판단 시 키 구성을 먼저 본다.

## 국비수업 연결

게시판·쇼핑몰 테이블을 설계할 때 데이터가 한 곳에서만 변경되도록 구조를 만들고, 실제 SQL로 이상 현상을 재현해 본다.
