# 연산자와 우선순위

## 한 문장 설명

연산자는 값에 계산이나 비교를 수행하는 기호이며, 여러 연산자가 섞이면 우선순위와 결합 방향에 따라 평가된다.

## 피연산자 수에 따른 분류

| 종류 | 예시 |
|---|---|
| 단항 | `++x`, `!flag`, `-value` |
| 이항 | `a + b`, `a > b`, `a && b` |
| 삼항 | `condition ? a : b` |

## 전위와 후위 증감

```java
int x = 5;
int y = x++; // y는 5, 그 후 x는 6

int a = 5;
int b = ++a; // a와 b 모두 6
```

단독 문장에서는 `x++`와 `++x` 모두 결과적으로 1을 증가시킨다. 다른 식과 섞이면 사용 시점이 달라지므로 초보 단계에서는 복합 사용을 피하는 편이 읽기 쉽다.

## 논리 연산자

- `&&`: 양쪽 모두 참일 때 참. 왼쪽이 거짓이면 오른쪽을 평가하지 않는다.
- `||`: 한쪽이라도 참이면 참. 왼쪽이 참이면 오른쪽을 평가하지 않는다.
- `!`: 논리값 반전

## 비트와 시프트

- `&`, `|`, `^`, `~`는 정수 값을 비트 단위로 계산한다.
- `<<`는 왼쪽 시프트다.
- `>>`는 부호를 유지하는 오른쪽 시프트다.
- `>>>`는 0으로 채우는 오른쪽 시프트다.

시프트를 단순히 곱셈과 나눗셈의 대체물로 외우지 않는다. 오버플로, 음수, 부호 확장과 버려지는 비트 때문에 결과를 따로 확인해야 한다.

## 우선순위 원칙

모든 순서를 암기하는 것보다 의도가 분명하도록 괄호를 사용한다. `a + b * c`처럼 간단한 식도 유지보수할 때 혼동될 가능성이 있다면 `(a + b) * c` 또는 `a + (b * c)`로 명시한다.

## 실무에서는 어떻게 쓰이나

산술·비교·논리 연산자는 항상 사용한다. 직접적인 비트 연산은 일반적인 비즈니스 코드에서 사용 빈도가 상대적으로 낮지만 권한 플래그, 프로토콜, 저수준 데이터 처리에서 필요할 수 있다.

## 지식 분류

- 산술·비교·논리 연산: 기초 배경이면서 실무에서 상시 사용
- 비트·시프트 연산: 기초 배경이지만 일반 백엔드 업무에서는 제한적으로 직접 사용
