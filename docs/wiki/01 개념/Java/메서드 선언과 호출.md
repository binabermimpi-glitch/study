# 메서드 선언과 호출

## 한 문장 설명

메서드는 입력을 받아 정해진 작업을 수행하고, 필요하면 결과를 호출자에게 돌려주는 이름 있는 코드 단위다.

## 선언 구조

```java
public static int add(int left, int right) {
    return left + right;
}
```

```text
접근 제한자 + 기타 제어자 + 반환형 + 메서드명 + 매개변수 목록 + 본문
```

`void`는 반환할 값이 없다는 뜻이다. `void` 메서드도 작업을 마치면 호출한 위치 다음으로 실행 제어가 돌아간다.

## 호출 예제

```java
int result = Calculator.add(2, 3);
```

반환값이 있는 메서드는 결과를 변수에 저장하거나 다른 식에 사용할 수 있다. `void` 메서드의 실행 결과는 변수에 대입할 수 없다.

## 실무에서는 어떻게 쓰이나

Controller의 요청 처리, Service의 업무 로직, Repository의 데이터 접근 모두 메서드로 표현된다. 메서드 이름과 입력·출력이 역할을 잘 드러내게 만드는 것이 중요하다.

## 흔한 실수

- 메서드 선언과 호출을 구분하지 않는다.
- 반환형과 실제 `return` 값의 타입을 맞추지 않는다.
- 하나의 메서드에 너무 많은 역할을 넣는다.
- 반환값이 있는데도 사용하지 않거나, `void` 결과를 저장하려 한다.
