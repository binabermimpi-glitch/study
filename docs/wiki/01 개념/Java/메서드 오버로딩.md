# 메서드 오버로딩

## 한 문장 설명

오버로딩은 한 클래스 안에 같은 이름이지만 매개변수 목록이 다른 메서드를 여러 개 선언하는 것이다.

```java
static void display(int value) {}
static void display(String value) {}
static void display(String first, String second) {}
```

## 구분 기준

오버로딩을 구분하는 것은 메서드 이름과 매개변수의 타입·개수·순서다. 반환형이나 매개변수 이름만 다르게 하는 것으로는 오버로딩할 수 없다.

```java
int parse(String value) { return 0; }
// double parse(String value) { return 0; } // 반환형만 달라 컴파일 오류
```

## 왜 필요한가

기능의 의미는 같지만 입력의 형태가 다를 때 일관된 이름을 사용할 수 있다. `println()`이 여러 타입의 값을 받는 것이 대표적인 예다.

## 흔한 실수

- 반환형만 다르면 된다고 생각한다.
- 자동 형변환이 가능한 여러 후보 때문에 어떤 오버로드가 선택될지 혼동한다.
- 오버로딩과 상속에서 메서드를 재정의하는 오버라이딩을 혼동한다.
