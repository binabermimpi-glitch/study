# 배열 복사와 방어적 복사

## 자바 배열과 객체지향 핵심

### 객체 배열의 복사 방식

> 객체 배열을 `clone()`으로 복사하면 배열 컨테이너는 새로 생성되지만, 내부 객체 참조는 공유될 수 있으므로 얕은 복사가 발생할 수 있습니다.

배열 자체를 복사하면 원본 배열과 복사 배열은 서로 다른 배열 객체가 됩니다. 그러나 배열의 요소가 `Person`처럼 객체 참조라면, 단순 복사는 내부 객체까지 새로 생성하지 않을 수 있습니다.

```java
Person[] original = {
    new Person("홍길동", 10),
    new Person("김선달", 24)
};

Person[] copy = original.clone();
```

위 코드에서 `original`과 `copy`는 서로 다른 배열 객체입니다. 하지만 `original[0]`과 `copy[0]`은 동일한 `Person` 객체를 참조할 수 있으므로, 한 배열을 통해 객체 상태를 변경하면 다른 배열에서도 변경 결과가 보입니다.

| 구분 | 배열 객체 | 배열 내부 객체 |
|---|---|---|
| 얕은 복사 | 새로운 배열 객체를 생성합니다. | 기존 객체의 주소를 공유합니다. |
| 깊은 복사 | 새로운 배열 객체를 생성합니다. | 각 요소 객체도 새로 생성합니다. |
| 방어적 복사 | 외부 변경을 막기 위한 복사본을 사용합니다. | 객체 상태 보호가 목적입니다. |

깊은 복사는 배열을 새로 만든 뒤, 각 인덱스의 객체도 생성자를 통해 다시 만드는 방식으로 구현할 수 있습니다. 이때 원본 객체의 필드값을 사용해 새 객체를 구성하므로, 원본과 복사본의 내부 객체가 분리됩니다.

```java
Person[] copy = new Person[original.length];

for (int i = 0; i < original.length; i++) {
    copy[i] = new Person(
        original[i].getName(),
        original[i].getAge()
    );
}
```

방어적 복사는 얕은 복사와 깊은 복사처럼 단순한 복사 결과의 분류가 아니라 객체 설계 전략입니다. 외부 코드가 내부 배열이나 가변 객체를 직접 변경하지 못하도록 복사본을 저장하거나 반환하여 객체의 상태를 보호합니다.


## 자바 상속과 객체 설계

### 가변 배열과 참조 복사

> 가변 배열은 행의 개수는 고정한 뒤 각 행의 열 길이를 서로 다르게 생성할 수 있는 2차원 배열 구조입니다. 배열 복사는 동일 객체를 함께 참조하는 얕은 복사와 새로운 배열 객체를 생성하는 독립 복사로 구분할 수 있습니다.

가변 배열은 외부 배열의 각 요소가 서로 다른 길이의 내부 배열 객체를 참조하는 구조입니다.

```java
int[][] scores = new int[3][];

scores[0] = new int[2];
scores[1] = new int[3];
scores[2] = new int[1];
```

`new int[3][]`처럼 외부 배열만 생성하면 각 행의 초기값은 `null`입니다.

따라서 아직 생성하지 않은 내부 배열에 접근하면 `NullPointerException`이 발생할 수 있습니다.

```java
int[][] scores = new int[3][];

System.out.println(scores[0]);      // null
// System.out.println(scores[0][0]); // NullPointerException
```

외부 배열 자체의 범위를 초과하면 `ArrayIndexOutOfBoundsException`이 발생합니다.

| 구분       | 메모리 상태                  | 변경 영향                             |
| -------- | ----------------------- | --------------------------------- |
| 얕은 복사    | 여러 참조 변수가 동일한 배열 객체를 참조 | 한 곳에서 요소를 변경하면 다른 참조에서도 변경 결과가 보임 |
| 별도 배열 복사 | 새로운 배열 객체를 생성           | 배열 자체는 원본과 독립적으로 변경 가능            |

예를 들어 다음은 얕은 복사입니다.

```java
int[] original = {10, 20, 30};
int[] copy = original;

copy[0] = 100;

System.out.println(original[0]); // 100
```

반면 `Arrays.copyOf()`는 새로운 배열 객체를 생성합니다.

```java
int[] original = {10, 20, 30};
int[] copy = Arrays.copyOf(original, original.length);

copy[0] = 100;

System.out.println(original[0]); // 10
```

단, 객체 배열의 경우에는 배열 객체만 새로 생성될 뿐 내부 객체까지 자동으로 복제되는 것은 아닙니다.
