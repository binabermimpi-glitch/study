# 가변 객체와 불변 객체

## 2026-08-26 Java 객체 생성자 캡슐화 복습

### 6. Mutable과 String(Immutable)의 차이

#### Mutable 객체

```java
Human hong = new Human("hong-gd", 100);
hong.setName("홍길동");
```

새 Human 객체를 만든 것이 아니라 기존 Human 객체 내부의 `name` 값을 변경한 것이다.

#### String은 참조형이지만 Immutable

```java
String original = "hello";
original = "bye";
```

- `String`은 클래스이므로 참조형이다.
- 문자열 리터럴을 이용해 `new` 없이 간편하게 사용할 수 있다.
- `String` 객체의 내용 자체는 수정되지 않는다.
- 대입은 기존 문자열 내용을 바꾸는 것이 아니라 다른 String 객체를 가리키도록 참조를 바꾼다.
- 문자열 리터럴은 String Pool의 영향을 받으므로 참조를 놓았다고 즉시 GC에 수거된다고 단정할 수 없다.
