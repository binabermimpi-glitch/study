# 중첩 클래스

## 한 문장 설명

중첩 클래스는 다른 클래스나 메서드 안에 선언된 클래스이며 선언 위치와 static 여부에 따라 외부 객체와의 관계가 달라진다.

| 종류 | 특징 |
|---|---|
| 정적 중첩 클래스 | 외부 객체 없이 생성 가능 |
| 내부 클래스 | 외부 클래스 객체가 필요 |
| 로컬 클래스 | 선언된 메서드나 블록 안에서만 사용 |
| 익명 클래스 | 이름 없이 선언과 동시에 객체 생성 |

익명 클래스는 일회성 구현에 적합하지만 함수형 인터페이스라면 람다가 더 간결할 수 있다. 구현이 길거나 재사용된다면 이름 있는 클래스로 분리한다.

## 흔한 실수

- 내부 클래스도 외부 객체 없이 바로 만들 수 있다고 생각한다.
- 정적 중첩 클래스와 내부 클래스를 모두 같은 의미의 inner class라고 부른다.
