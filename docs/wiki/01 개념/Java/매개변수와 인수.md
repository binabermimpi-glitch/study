# 매개변수와 인수

## 한 문장 설명

매개변수는 메서드 선언부에서 값을 받을 변수이고, 인수는 호출할 때 실제로 전달하는 값이다.

```java
static void display(int value) { // value: 매개변수
    System.out.println(value);
}

display(10); // 10: 인수
```

## 핵심 원리

- 호출 시 인수의 값이 매개변수로 전달된다.
- 매개변수는 해당 메서드 안에서 사용하는 지역 변수다.
- 인수는 매개변수 타입과 호환되어야 한다.
- Java는 항상 값을 전달한다. 참조형도 객체 자체가 아니라 참조값이 복사되어 전달된다.

## 흔한 실수

- 참조형을 전달하면 호출된 메서드가 호출자의 변수 자체를 받는다고 생각한다.
- 인수의 순서와 타입을 매개변수 목록에 맞추지 않는다.
- 매개변수 값을 변경한 것과 그 매개변수가 가리키는 객체의 상태를 변경한 것을 혼동한다.
