# 매개변수와 인수

## 2026-08-24 자바 메서드와 연산자 기초

### 매개변수와 오버로딩
매개변수는 호출 시 전달된 값을 메서드 내부에서 사용할 수 있도록 받는 지역 변수이며, 오버로딩은 이름이 같은 메서드를 매개변수 구성으로 구분하는 방식입니다.

매개변수가 있는 메서드는 호출자가 전달한 값을 받아 기능을 수행합니다. 호출 위치에서 전달하는 값을 인수라고 하며, 메서드 선언부에서 이를 받는 변수를 매개변수라고 합니다.

public static void display(int value) {
    System.out.println(value);
}

public static void main(String[] args) {
    Example.display(10);
}
display(10)이 호출되면 value라는 정수형 매개변수가 생성되고, 전달된 10으로 초기화됩니다. 매개변수는 메서드 내부에서만 유효한 지역 변수이므로 메서드 실행이 끝나면 사용할 수 없습니다.

매개변수의 자료형은 호출 시 전달하는 값의 자료형과 호환되어야 합니다.
매개변수는 호출 시 전달된 값으로 초기화되므로 별도의 초기화 값을 작성할 필요가 없습니다.
메서드 내부에서 선언한 변수와 매개변수는 모두 해당 메서드의 지역 변수입니다.
서로 다른 메서드에 같은 이름의 지역 변수가 있어도 각각 별도의 저장 공간을 사용합니다.
오버로딩은 하나의 클래스 안에서 같은 이름의 메서드를 여러 개 선언하는 기능입니다. 메서드명은 같아도 매개변수의 자료형 또는 개수가 다르면 서로 다른 메서드로 인식됩니다.

public static void display(int value) {
    System.out.println(value);
}

public static void display(String value) {
    System.out.println(value);
}

public static void display(String first, String second) {
    System.out.println(first + second);
}
오버로딩의 목적은 메서드 이름이 전달하는 의미를 유지하는 것입니다. 예를 들어 print, sum, format처럼 기능의 목적은 같지만 입력값의 자료형이나 개수가 다른 경우, 여러 메서드명을 만들지 않고 동일한 이름을 일관되게 사용할 수 있습니다.

구분	허용 여부	예시
메서드명만 동일	허용됩니다.	sum(...)
매개변수 자료형이 다름	허용됩니다.	sum(int)과 sum(double)
매개변수 개수가 다름	허용됩니다.	sum(int, int)과 sum(int, int, int)
이름·자료형·개수가 모두 같음	허용되지 않습니다.	동일한 선언의 중복입니다.
자바 API의 System.out.println()과 print()는 대표적인 오버로딩 사례입니다. 정수, 실수, 문자, 문자열, 객체 등 다양한 자료형을 받을 수 있도록 여러 메서드 원형이 제공됩니다.
