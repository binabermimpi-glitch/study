# 기본 자료형과 리터럴

## 한 문장 설명

기본 자료형은 Java가 값을 직접 표현하는 8가지 타입이고, 리터럴은 코드에 직접 적은 값이다.

## 기본 자료형

| 종류 | 타입 |
|---|---|
| 정수 | `byte`, `short`, `int`, `long` |
| 실수 | `float`, `double` |
| 문자 | `char` |
| 논리 | `boolean` |

```java
int count = 100;
long population = 8_000_000_000L;
double rate = 0.1;
float ratio = 0.1F;
char grade = 'A';
boolean enabled = true;
```

## 흔한 실수

- `String`을 기본 자료형으로 착각한다. `String`은 클래스다.
- `long` 리터럴의 `L`, `float` 리터럴의 `F`를 빠뜨린다.
- 정수형 범위를 넘어가는 값을 강제 변환해 오버플로가 발생한다.
- `char`의 작은따옴표와 `String`의 큰따옴표를 혼동한다.

## 실무에서는 어떻게 쓰이나

모든 Java 코드의 기반이다. 다만 실무에서는 범위를 외우는 것보다 데이터의 의미에 맞는 타입을 선택하고 손실 가능성을 확인하는 능력이 중요하다.
