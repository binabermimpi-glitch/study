# 기본 자료형과 리터럴

## 2026-08-23 자바 참조와 자료형 기초

### 자바 참조와 자료형 기초


### 리터럴과 기본 자료형

> 리터럴은 코드에 직접 작성한 실제 값이며, 자바의 기본 자료형은 값의 종류와 메모리 크기에 따라 데이터를 처리합니다.

리터럴은 변수나 상수에 저장되는 순수한 값 자체를 의미합니다. `100`, `100.0`, `'A'`, `"Hello"`, `true`와 같은 값이 리터럴입니다. 자바는 리터럴의 형태에 따라 기본 타입을 판단하고 필요한 저장 공간을 확보합니다.

| 리터럴 예시 | 기본 타입 | 설명 |
|---|---|---:|---|
| `true`, `false` | `boolean` | 논리 값을 나타냅니다. |
| `'A'` | `char` | 유니코드 기반 문자 하나를 나타냅니다. |
| `100` | `int` | 정수 리터럴의 기본 타입입니다. |
| `100.0` | `double` | 실수 리터럴의 기본 타입입니다. |
| `"Hello"` | `String` | 문자열 객체를 참조합니다. |

정수형에는 `byte`, `short`, `int`, `long`이 있으며, 일반적인 정수 리터럴은 기본적으로 `int`로 처리됩니다. 실수형에는 `float`, `double`이 있으며, 일반적인 실수 리터럴은 기본적으로 `double`로 처리됩니다.

```java
int count = 100;
double rate = 100.0;
char grade = 'A';
boolean enabled = true;
String message = "Hello";
```

변수는 값을 저장한 뒤 재대입할 수 있는 공간입니다. 상수는 `final`로 선언되어 초기화 이후 값을 변경할 수 없습니다. 따라서 값의 변경 가능 여부는 변수와 상수를 구분하는 핵심 기준입니다.


### 기본 자료형 실습

> 기본 자료형 실습은 타입별 저장 범위, 정수 리터럴의 기본 타입, 오버플로우 및 연산 결과 타입을 확인하는 과정입니다.

IntelliJ IDEA에서 `type01.primitive` 패키지를 생성하고 자료형별 클래스를 분리하여 작성했습니다. 각 클래스는 `main` 메소드에서 값을 선언하고 출력하여 타입의 동작을 확인하는 구조입니다.

`byte`는 1바이트 정수형으로 `-128`부터 `127`까지 저장할 수 있습니다. 범위를 넘는 값을 강제로 저장하면 값이 순환하는 오버플로우 현상이 발생할 수 있습니다.

```java
byte b01 = 127;
byte b02 = (byte) 128;

System.out.println(b01);
System.out.println(b02); // -128
```

`byte`와 `short` 연산은 결과가 기본 정수 타입인 `int`로 승격됩니다. 따라서 연산 결과를 다시 `byte` 또는 `short` 변수에 넣으려면 명시적 캐스팅이 필요합니다.

```java
byte b01 = 127;
byte sum = (byte) (b01 - 1);

short s01 = 32767;
short sumShort = (short) (s01 + 1);
```

| 타입 | 크기 | 대표 범위 또는 특성 | 실습 확인 내용 |
|---|---:|---|---|
| `byte` | 1바이트 | `-128`부터 `127`까지 표현합니다. | 범위 초과 시 오버플로우를 확인합니다. |
| `short` | 2바이트 | `-32768`부터 `32767`까지 표현합니다. | 연산 결과가 `int`가 되는 것을 확인합니다. |
| `int` | 4바이트 | 정수 리터럴의 기본 타입입니다. | 일반적인 정수 연산을 확인합니다. |
| `long` | 8바이트 | 큰 정수를 저장합니다. | 큰 리터럴 뒤에 `L`을 사용합니다. |

정수 리터럴은 접두사를 통해 진법을 표현할 수 있습니다. `0b`는 2진수, `0`은 8진수, `0x`는 16진수를 의미하며, 출력 시에는 해당 값이 10진수로 변환되어 표시됩니다.

```java
System.out.println(0b10); // 2
System.out.println(010);  // 8
System.out.println(0x10); // 16
```


### 문자, 실수, 논리 타입 실습

> `char`는 문자 코드값과 연결되며, `float`와 `double`은 실수 리터럴의 접미사 및 기본 타입 규칙으로 구분되고, `boolean`은 참과 거짓을 표현합니다.

`char`는 하나의 문자를 저장하는 2바이트 기본 타입입니다. 문자 리터럴은 작은따옴표로 작성하며, `char` 값을 `int`로 변환하면 해당 문자의 코드값을 확인할 수 있습니다.

```java
char c01 = 'A';

System.out.println(c01);
System.out.println((int) c01);
```

ASCII는 영문자, 숫자, 제어 문자를 숫자 코드와 연결하는 문자 인코딩 체계입니다. 예를 들어 대문자 `A`와 소문자 `a`는 서로 다른 코드값을 가지며, 자바는 문자 처리에서 유니코드 체계를 사용합니다.

실수 리터럴은 기본적으로 `double`로 처리됩니다. `float`에 실수 리터럴을 저장하려면 값 뒤에 `F` 또는 `f`를 붙여 해당 값이 `float`임을 명시해야 합니다.

```java
float f01 = 0.1F;
double d01 = 100.04;

System.out.println(f01);
System.out.println(d01);
```

`boolean`은 `true`와 `false`만 저장할 수 있는 논리형입니다. 조건문, 반복문, 비교 연산의 결과와 같이 참 또는 거짓이 필요한 프로그램 흐름 제어에 사용됩니다.

```java
boolean enabled = true;
boolean completed = false;

System.out.println(enabled);
System.out.println(completed);
```
