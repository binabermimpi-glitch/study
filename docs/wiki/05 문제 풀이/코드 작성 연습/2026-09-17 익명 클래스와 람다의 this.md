# 익명 클래스와 람다에서 몰랐던 부분

람다는 익명 클래스의 코드를 단순히 짧게 줄인 문법처럼 보이지만, 두 방식은 완전히 같지 않다. 특히 `this`가 가리키는 대상과 실행 시 처리 방식에 차이가 있다.

## 1. `this`가 가리키는 대상

익명 클래스는 새로운 익명 객체를 생성한다.

따라서 익명 클래스 내부의 `this`는 생성된 익명 객체 자신을 가리킨다.

```java
Runnable task = new Runnable() {
    @Override
    public void run() {
        System.out.println(this);
    }
};
```

람다는 자신만의 새로운 `this`를 만들지 않는다.

따라서 람다 내부의 `this`는 람다가 작성된 외부 클래스의 객체를 가리킨다.

```java
Runnable task = () -> {
    System.out.println(this);
};
```

정리:

```text
익명 클래스의 this → 생성된 익명 객체
람다의 this → 람다를 감싸고 있는 외부 객체
```

## 코드 블록 정리 사항

보내준 내용에서 익명 클래스의 닫는 `};`가 마지막에 놓여 있던 부분만 각 예제가 독립적으로 끝나도록 제자리로 옮겼다. 개념 설명과 두 코드의 내용은 삭제하지 않았다.

## 실행할 때 알아둘 점

람다에서 사용하는 `this`는 외부 인스턴스가 존재하는 문맥의 `this`다. 따라서 `static` 메서드처럼 원래 `this`를 사용할 수 없는 위치에서는 람다 내부에서도 `this`를 사용할 수 없다.
