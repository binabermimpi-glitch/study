## 1. 8의 배수 판별

### 문제

정수 하나를 받아 8의 배수인지 판별하는 static boolean 메서드를 작성한다.

### 첫 시도 — 그대로 보존

```java
public static boolean isMultipleOf8(int a) {
    return a % 8 == 0
}
```

### 진단

- 오류 유형: 문법 기억
- `a % 8 == 0`을 곧바로 반환한 판단은 정확하다.
- 문장 끝의 세미콜론이 빠졌다.

### 정답

```java
public static boolean isMultipleOf8(int a) {
    return a % 8 == 0;
}
```

## 2. show 메서드 오버로딩

### 문제

String은 이름, int는 점수, double은 이해도를 출력하도록 같은 이름의 show()를 오버로딩한다. 이해도는 소수점 둘째 자리와 %를 출력한다.

### 첫 시도 — 그대로 보존

```java
show(String name) {
    System.out.println("이름 :" = name)
}

show(int score) {
    System.out.prinln("점수 :" = score)
}

show(double understand) {
    System.out.printf("이해도 : %d.2f%%", double, understand)
}
```

### 진단

- 오류 유형: 코드 조립, 문법 기억
- 반환값이 없으므로 반환형은 void다.
- 문자열과 값은 +로 연결한다.
- prinln이 아니라 println이다.
- 실수 소수점 둘째 자리는 %.2f, % 문자는 %%, 줄바꿈은 %n이다.
- printf에는 타입 이름이 아니라 실제 변수 understand를 전달한다.

### 정답

```java
public static void show(String name) {
    System.out.println("이름 : " + name);
}

public static void show(int score) {
    System.out.println("점수 : " + score);
}

public static void show(double understand) {
    System.out.printf("이해도 : %.2f%%%n", understand);
}
```

## 3. 문자열 대문자 변환

### 문제

문자열 하나를 받아 대문자로 변환한 뒤 반환하는 static 메서드를 작성한다.

### 첫 시도 — 그대로 보존

```java
public String changeUpper(String a) {
    return a.UpperCase();
}
```

### 진단

- 오류 유형: 문법 기억
- static이 빠졌다.
- String API의 정확한 메서드명은 toUpperCase()다.

### 정답

```java
public static String changeUpper(String a) {
    return a.toUpperCase();
}
```

## 4. 두 정수 중 큰 값 출력

### 문제

정수 두 개 중 큰 값을 삼항 연산자로 출력하는 non-static compare() 메서드를 작성한다.

### 첫 시도 — 그대로 보존

```java
public int compare(int a, int b) {
    return a > b ? a : b
}
```

### 진단

- 오류 유형: 문제 해석, 코드 조립
- 삼항 연산자 자체는 정확하다.
- 문제의 요구는 반환이 아니라 출력이므로 void가 알맞다.
- 계산 결과를 변수에 저장한 뒤 println으로 출력한다.

### 정답

```java
public void compare(int a, int b) {
    int result = a > b ? a : b;
    System.out.println(result);
}
```

## 반복되는 약점

1. 문제를 읽고 출력과 반환을 먼저 구분한다.
2. 메서드 머리에서 static 여부, 반환형, 이름, 매개변수를 차례로 적는다.
3. 계산식 오른쪽의 결과 타입을 먼저 말한 뒤 저장하거나 반환한다.
4. 컴파일 전에 세미콜론, 메서드명 철자와 괄호를 확인한다.
