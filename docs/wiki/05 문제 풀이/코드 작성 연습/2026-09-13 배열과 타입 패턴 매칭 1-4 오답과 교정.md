## 1. int 배열에서 짝수 출력

### 문제

Object 타입의 값이 `int[]`이면 배열 안의 짝수만 출력한다.

### 첫 시도 — 그대로 보존

```java
public static void printEven(Object obj)

if(obj instanceof int[] cr){

    for(cr : ar){

        if(ar%2==0){
```

### 진단

- 메서드 선언 뒤에 본문을 여는 `{`가 필요하다.
- `obj instanceof int[] cr`은 정확한 방향이다.
- 향상된 for문은 `for (요소타입 변수 : 배열)` 순서로 쓴다.
- `cr`은 배열 전체이고 `value`는 배열에서 꺼낸 정수 하나다.
- 나머지 계산은 배열이 아니라 `value`에 적용한다.

### 정답

```java
public static void printEven(Object obj) {
    if (obj instanceof int[] cr) {
        for (int value : cr) {
            if (value % 2 == 0) {
                System.out.println(value);
            }
        }
    }
}
```

## 2. String 배열에서 긴 문자열 출력

### 문제

Object 타입의 값이 `String[]`이면 길이가 5 이상인 문자열만 출력하고, 아니면 안내 문장을 출력한다.

### 첫 시도 — 그대로 보존

```java
public static void printLongword(Object obj){
    if (obj instanceof String[] ar){
        for(String s : ar){
            if(ar.length()>=5;
            System.out.println(ar)
        }
        else{
            System.out.print("문자열배열이 아닙니다")
        }
    }
```

### 진단

- `ar`는 배열 전체, `s`는 배열 안의 문자열 하나다.
- 배열 요소 개수는 `ar.length`, 문자열 글자 수는 `s.length()`다.
- 조건을 통과한 문자열 하나인 `s`를 출력해야 한다.
- `else`는 “String[]이 아닌 경우”이므로 바깥쪽 `if (obj instanceof String[] ar)`에 붙인다.
- if 조건은 `)`로 닫고 실행 블록을 `{`로 연다.

### 정답

```java
public static void printLongWord(Object obj) {
    if (obj instanceof String[] ar) {
        for (String s : ar) {
            if (s.length() >= 5) {
                System.out.println(s);
            }
        }
    } else {
        System.out.println("문자열 배열이 아닙니다.");
    }
}
```

## 3. Cat 타입 검사와 메서드 호출

### 문제

`Object obj = new Cat()`에서 실제 객체가 Cat이면 패턴 변수로 `sleep()`을 호출한다.

### 첫 시도 — 그대로 보존

```java
class AnimalMain{
    public static void main(String [] args){
        Object obj = new Cat();
        if (obj instanceof cat b){
            b.sleep();
        }
```

### 진단

- `instanceof` 패턴 매칭과 `b.sleep()` 호출은 정확하다.
- Java는 대소문자를 구분하므로 클래스명은 `cat`이 아니라 `Cat`이다.
- main 메서드와 클래스의 닫는 중괄호가 필요하다.

### 정답

```java
class Animal { }

class Cat extends Animal {
    public void sleep() {
        System.out.println("잡니다.");
    }
}

public class AnimalMain {
    public static void main(String[] args) {
        Object obj = new Cat();
        if (obj instanceof Cat b) {
            b.sleep();
        }
    }
}
```

## 4. switch 패턴 매칭으로 타입 구분

### 문제

Object 값을 큰 정수, 정수, 문자열, null, 기타로 구분해 출력한다.

### 첫 시도 — 그대로 보존

```java
public static checkType(Object obj({
    switch(obj){
        if(obj instanceof Integer i&&obj>=0){
            System.out.print("큰 정수")
        else(obj instance ...
```

### 진단

- 반환값이 없는 메서드이므로 `void`가 필요하다.
- switch 안에서는 if문이 아니라 `case Integer i ->` 형태를 쓴다.
- 추가 조건은 `when`으로 연결한다.
- `obj`는 Object이므로 숫자 비교 대상은 패턴으로 확보한 Integer 변수 `i`여야 한다.
- 큰 정수 조건은 문제에 맞게 `i >= 100`이다. 첫 시도의 `>= 0`과 다르다.

### 정답 — Java 21 기준

```java
public static void checkType(Object obj) {
    switch (obj) {
        case Integer i when i >= 100 -> System.out.println("큰 정수");
        case Integer i -> System.out.println("정수");
        case String s -> System.out.println("문자열");
        case null -> System.out.println("null");
        default -> System.out.println("기타");
    }
}
```

> `case ... when ...` 형태는 이 위키의 수업 기준인 Java 21 문법입니다.

## 반복되는 약점

1. 배열 전체와 반복문에서 꺼낸 요소 하나를 구분한다.
2. `배열.length`와 `문자열.length()`를 구분한다.
3. `{}`, `()`, 세미콜론을 포함해 코드 블록을 끝까지 닫는다.
4. if 패턴 매칭과 switch 패턴 매칭의 문법을 섞지 않는다.
5. 패턴 매칭 후에는 원래 Object 변수 대신 타입이 좁혀진 변수를 사용한다.
