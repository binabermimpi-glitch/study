# 문제 풀이 허브

국비수업 실습 문제와 풀이 이력을 관리합니다.

- [문제 풀이 현황](</wiki/05%20%EB%AC%B8%EC%A0%9C%20%ED%92%80%EC%9D%B4/%EA%B5%AD%EB%B9%84%EC%88%98%EC%97%85/%EB%AC%B8%EC%A0%9C%20%ED%92%80%EC%9D%B4%20%ED%98%84%ED%99%A9>)
- `Java/`: Java 문법과 객체지향 문제
- `Spring/`: Spring Boot, MVC, JPA와 테스트 문제
- `Database/`: SQL과 데이터 모델링 문제
- `Web/`: HTTP, REST와 프론트 연동 문제
- `종합 프로젝트/`: 여러 기술을 함께 사용하는 문제

첫 풀이와 틀린 과정은 삭제하지 않습니다. 정답 확인 후에는 반드시 나중에 정답 없이 다시 풉니다.
