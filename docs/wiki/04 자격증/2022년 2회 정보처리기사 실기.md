# 1. 관계 해석(Relational Calculus) 🔥

## 문제

관계 데이터 모델의 제안자인 코드(E.F. Codd)가 수학의 Predicate Calculus(술어 해석)에 기반을 두고 관계 데이터베이스를 위해 제안하였다.

(   )은 관계 데이터의 연산을 표현하는 방법으로, 원하는 정보를 정의할 때 계산 수식을 사용한다.

(   )은 원하는 정보가 무엇이라는 것만 정의하는 비절차적 특성을 갖는다.

## 정답

**관계 해석(Relational Calculus)**

## 개념

관계 해석은 원하는 결과가 **무엇인지**를 표현하는 비절차적 언어이다.

```text
관계 대수
→ 어떻게 구할 것인가
→ 절차적

관계 해석
→ 무엇을 구할 것인가
→ 비절차적
```

## 관계 대수 연산

```text
SELECT
→ σ
→ 행 선택

PROJECT
→ π
→ 열 선택

JOIN
→ ⋈
→ 릴레이션 결합

DIVISION
→ ÷
```

# 12. ALL 🔥🔥

## 문제

B 제조자의 모든 제품 단가보다 더 큰 단가를 가진 제품을 출력하시오.

```sql
SELECT *
FROM 상품
WHERE 단가 > (1)
(
    SELECT 단가
    FROM 상품
    WHERE 제조사 = 'B'
);
```

## 정답

**ALL**

```sql
SELECT *
FROM 상품
WHERE 단가 > ALL
(
    SELECT 단가
    FROM 상품
    WHERE 제조사 = 'B'
);
```

B 제조사 단가:

```text
1500
2000
```

따라서:

```text
> ALL(1500, 2000)
→ 2000보다 커야 함
```

## ALL / ANY

```text
> ALL
→ 모든 값보다 큼
→ 최댓값보다 큼

> ANY
→ 하나라도 만족
→ 최솟값보다 크면 가능
```

# 18. Java switch Fall-through 🔥🔥

## 문제

```java
public static void main(String[] args) {

    int i = 3;
    int sum = 0;

    switch(i) {

        case 0:
            sum++;

        case 1:
            sum += 3;

        case 2:
            sum -= 10;

        case 3:
            sum = 0;

        case 4:
            sum += 3;

        case 5:
            sum -= 10;

        default:
            sum--;
    }

    System.out.println(sum);
}
```

## 정답

```text
-8
```

---

# 핵심

현재:

```text
i = 3
```

이므로:

```text
case 3
```

부터 실행된다.

그리고 **break가 하나도 없기 때문에 아래 case와 default까지 계속 실행**된다.

---

## case 3

```java
sum = 0;
```

따라서:

```text
sum = 0
```

---

## case 4

```java
sum += 3;
```

따라서:

```text
sum
= 0 + 3
= 3
```

---

## case 5

```java
sum -= 10;
```

따라서:

```text
sum
= 3 - 10
= -7
```

---

## default

```java
sum--;
```

따라서:

```text
sum
= -7 - 1
= -8
```

## 최종 출력

```text
-8
```

---

# Fall-through

```text
switch에서 break 없음
→ 일치한 case부터 아래 case까지 계속 실행
```

이 문제에서는:

```text
case 3
↓
case 4
↓
case 5
↓
default
```

순서로 실행된다.

### 주의

```text
case 5:
sum -= 10;
```

이다.

`sum = 10`이 아니다.

# 19. Java 생성자 / 필드 / 반복문 🔥🔥

## 문제

```java
class Cal {

    int a;

    Cal(int a) {
        this.a = a;
    }

    int func() {

        int b = 1;

        for(int i = 1; i < a; i++)
            b = a * i + b;

        return a + b;
    }
}

public class Main {

    public static void main(String[] args) {

        Cal obj = new Cal(3);

        obj.a = 5;

        int b = obj.func();

        System.out.println(obj.a + b);
    }
}
```

## 정답

```text
61
```

## 객체 생성

```java
Cal obj = new Cal(3);
```

생성자에 의해:

```text
obj.a = 3
```

하지만 바로 다음:

```java
obj.a = 5;
```

때문에:

```text
obj.a = 5
```

가 된다.

---

# func()

초기:

```text
a = 5
b = 1
```

반복:

```text
i = 1
→ b = 5 × 1 + 1
→ 6

i = 2
→ b = 5 × 2 + 6
→ 16

i = 3
→ b = 5 × 3 + 16
→ 31

i = 4
→ b = 5 × 4 + 31
→ 51
```

return:

```text
a + b
= 5 + 51
= 56
```

main:

```text
b = 56
```

출력:

```text
obj.a + b
= 5 + 56
= 61
```

## 최종 출력

```text
61
```
