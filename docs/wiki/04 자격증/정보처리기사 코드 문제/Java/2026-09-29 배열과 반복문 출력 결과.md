# 정보처리기사 실기 연습: 배열과 반복문 출력 결과

## 문제

다음 Java 코드의 출력 결과를 구하시오.

```java
public class Main {
    public static void main(String[] args) {
        int[] data = {3, 1, 4, 2, 5};
        int result = 0;

        for (int i = 0; i < data.length; i++) {
            if (i % 2 == 0) {
                result += data[i];
            } else {
                result -= data[i];
            }

            data[i] = result;
        }

        System.out.print(result + " " + data[3]);
    }
}
```

## 정답

```text
9 4
```

## 핵심 개념: 0을 2로 나눌 수 있을까?

0을 2로 나누는 것은 가능하다.

```text
0 / 2 = 0  → 몫이 0
0 % 2 = 0  → 나머지가 0
```

`0 = 2 × 0 + 0`이므로 0을 2로 나눈 나머지는 0이다.

따라서 `i = 0`일 때:

```text
i % 2 == 0
→ 0 % 2 == 0
→ 0 == 0
→ true
```

즉, `i = 0`에서는 if문 안의 덧셈을 실행한다.

주의: `0 / 2`는 가능하지만 `2 / 0`은 불가능하다. Java에서 정수를 0으로 나누거나 0으로 나머지 연산을 하면 `ArithmeticException`이 발생한다.

## 반복문 실행 과정

시작 상태:

```text
data = {3, 1, 4, 2, 5}
result = 0
```

### ① i = 0

```text
0 % 2 == 0 → true
result += data[0] → result = 0 + 3 = 3
data[0] = result → data[0] = 3
현재 배열: {3, 1, 4, 2, 5}
```

### ② i = 1

```text
1 % 2 == 0 → false
result -= data[1] → result = 3 - 1 = 2
data[1] = result → data[1] = 2
현재 배열: {3, 2, 4, 2, 5}
```

### ③ i = 2

```text
2 % 2 == 0 → true
result += data[2] → result = 2 + 4 = 6
data[2] = result → data[2] = 6
현재 배열: {3, 2, 6, 2, 5}
```

### ④ i = 3

```text
3 % 2 == 0 → false
result -= data[3] → result = 6 - 2 = 4
data[3] = result → data[3] = 4
현재 배열: {3, 2, 6, 4, 5}
```

### ⑤ i = 4

```text
4 % 2 == 0 → true
result += data[4] → result = 4 + 5 = 9
data[4] = result → data[4] = 9
최종 배열: {3, 2, 6, 4, 9}
```

마지막 출력문:

```java
System.out.print(result + " " + data[3]);
```

```text
result = 9
data[3] = 4
```

최종 출력 결과: `9 4`

## 풀이할 때 확인할 순서

1. `i`의 값이 몇부터 몇까지 변하는지 확인한다.
2. 각 `i`에서 `i % 2 == 0`의 참·거짓을 판단한다.
3. 해당 인덱스의 `data[i]`로 `result`를 계산한다.
4. 계산한 `result`를 `data[i]`에 저장한다.
5. 반복문이 끝난 뒤 출력하는 값이 무엇인지 확인한다.
