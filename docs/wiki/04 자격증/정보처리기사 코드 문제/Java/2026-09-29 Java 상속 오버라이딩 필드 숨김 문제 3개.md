# Java 상속·오버라이딩·필드 숨김 문제 3개

※ 각 문제는 독립된 코드다. 각각 Main.java로 저장해서 실행하면 된다.

## 1번 문제

다음 코드의 출력 결과는?

```java
abstract class Animal {
    String name = "Animal";
    public String getName() { return "Animal:" + name; }
    abstract String getName(String value);
}
class Dog extends Animal {
    String name = "Dog";
    Dog(String value) { super.name = value; }
    @Override String getName(String value) { return "Dog:" + value; }
}
public class Main {
    public static void main(String[] args) {
        Animal obj = new Dog("Coco");
        System.out.print(obj.getName());
    }
}
```

정답: `Animal:Coco`

해설:

- `obj.getName()`은 인자가 없는 `getName()`을 호출한다.
- Dog는 `getName()`을 재정의하지 않았다. Dog의 `getName(String)`은 다른 메서드다.
- 따라서 `Animal.getName()`이 실행된다.
- 이 메서드 안의 `name`은 `Animal.name`이다.
- 생성자에서 `super.name = "Coco"`로 바꿨으므로 `Animal:Coco`가 출력된다.

## 2번 문제

다음 코드의 출력 결과는?

```java
abstract class Device {
    String model;
    public String info() { return "Device:" + model; }
    abstract String info(String value);
}
class Phone extends Device {
    String model;
    Phone(String value) { model = value; }
    @Override public String info() { return "Phone:" + model; }
    @Override String info(String value) { return "Phone input:" + value; }
}
public class Main {
    public static void main(String[] args) {
        Device obj = new Phone("Galaxy");
        System.out.print(obj.info());
    }
}
```

정답: `Phone:Galaxy`

해설:

- `obj.info()`는 인자가 없는 `info()`를 호출한다.
- Phone이 `info()`를 재정의했으므로 `Phone.info()`가 실행된다.
- 생성자의 `model = value`에서 `model`은 `Phone.model`을 뜻한다.
- `Phone.model`에 `"Galaxy"`가 들어 있으므로 `Phone:Galaxy`가 출력된다.
- `Device.model`은 여전히 `null`이지만 이번에 실행되는 `Phone.info()`는 그 필드를 읽지 않는다.

## 3번 문제

다음 코드의 출력 결과는?

```java
abstract class Shape {
    String name = "Shape";
    public String label() { return "Shape:" + name; }
    abstract String label(String value);
}
class Circle extends Shape {
    String name = "Circle";
    Circle(String value) {
        super.name = value;
        name = "Round";
    }
    @Override String label(String value) { return "Circle:" + value; }
    public String label(byte[] value) { return "Bytes:" + value; }
}
public class Main {
    public static void main(String[] args) {
        Shape obj = new Circle("Blue");
        System.out.print(obj.label() + ", " + obj.label("Red"));
    }
}
```

정답: `Shape:Blue, Circle:Red`

해설:

① `obj.label()`

- 인자가 없는 `label()`을 호출한다.
- Circle은 `label()`을 재정의하지 않았으므로 `Shape.label()`이 실행된다.
- `Shape.label()` 안의 `name`은 `Shape.name`이다.
- 생성자에서 `super.name = "Blue"`로 바꿨으므로 `Shape:Blue`가 된다.

② `obj.label("Red")`

- String을 받는 `label(String)`을 호출한다.
- Circle이 `label(String)`을 재정의했으므로 `Circle.label("Red")`가 실행된다.
- 반환값은 `Circle:Red`다.
- `label(byte[])`는 매개변수 타입이 다르므로 호출되지 않는다.
- 두 결과를 `", "`로 이어 붙여 `Shape:Blue, Circle:Red`가 출력된다.

## 핵심 풀이 순서

1. 인자의 개수와 타입을 보고 호출할 메서드를 찾는다. `label()`, `label(String)`, `label(byte[])`는 서로 다른 메서드다.
2. 그 메서드를 자식 클래스가 재정의했는지 확인한다. 재정의했다면 실제 객체 타입의 메서드가 실행된다.
3. 실행되는 메서드 안에서 읽는 필드가 어느 클래스의 필드인지 확인한다. 부모 메서드의 단순한 `name`은 부모 필드, 자식 메서드의 단순한 `name`은 자식 필드를 읽는다.
