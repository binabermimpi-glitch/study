# C언어 포인터, 구조체, 동적 메모리 할당 정리

## 1. 동적 메모리 할당이란?

동적 메모리 할당(Dynamic Memory Allocation)은 프로그램 실행 중 필요한 크기만큼 메모리 공간을 확보하는 방법이다.

일반적인 변수 선언:

```c
int a = 10;
```

위 코드는 정수 하나를 저장할 공간을 만든다.

배열을 선언할 수도 있다.

```c
int scores[100];
```

그러나 실제로 학생이 3명뿐이라면 100명분의 공간을 모두 사용할 필요가 없다.

이처럼 실행 중에 필요한 데이터 개수가 결정되는 상황에서 동적 메모리 할당을 사용할 수 있다.

예를 들어 학생 수를 입력받아 필요한 만큼 공간을 확보할 수 있다.

```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    int count;

    scanf("%d", &count);

    if (count <= 0) {
        return 1;
    }

    int *scores = malloc(sizeof(int) * count);

    if (scores == NULL) {
        return 1;
    }

    scores[0] = 90;

    printf("%d", scores[0]);

    free(scores);

    return 0;
}
```

핵심은 다음과 같다.

- 일반 배열: 선언할 때 지정한 크기를 사용
- 동적 할당: 프로그램 실행 중 필요한 크기를 결정하여 할당
- malloc(): 메모리 공간 확보
- free(): 확보한 메모리 해제

## 2. 스택 메모리와 힙 메모리

C언어 프로그램에서는 일반적으로 스택(Stack)과 힙(Heap)을 구분한다.

| 구분 | 스택(Stack) | 힙(Heap) |
|---|---|---|
| 주요 용도 | 지역변수, 함수 호출 정보 | 동적 할당 데이터 |
| 공간 확보 | 함수 실행 및 블록 진입 시 자동 관리 | malloc() 등으로 요청 |
| 해제 | 변수 수명 종료 시 자동 | free()로 직접 해제 |
| 크기 | 일반적으로 제한적 | 사용 가능한 메모리 범위에서 요청 |
| 예시 | int a = 10; | malloc(sizeof(int)) |

※ 실제 메모리 배치는 시스템과 컴파일러에 따라 다르며, 모든 지역변수가 반드시 물리적인 스택에 저장되는 것은 아니다.

### 예제

```c
int a = 10;

int *p = malloc(sizeof(int));
```

일반적인 메모리 구조를 단순화하면 다음과 같다.

```text
[스택 영역]

변수 a
값: 10

포인터 변수 p
값: 500
       |
       |
       v
[힙 영역]

주소: 500
값: 아직 초기화되지 않음
```

포인터 변수 p에는 동적 할당된 메모리의 주소가 저장된다.

실제 정수 데이터는 p가 가리키는 공간에 저장할 수 있다.

## 3. malloc() 함수

malloc은 Memory Allocation의 약자이다.

프로그램 실행 중 지정한 바이트 수만큼 메모리를 할당하는 함수다.

사용하려면 다음 헤더 파일이 필요하다.

```c
#include <stdlib.h>
```

### 3-1. 기본 사용법

```c
int *p = malloc(sizeof(int));
```

코드를 나누어서 해석하면 다음과 같다.

| 코드 | 의미 |
|---|---|
| int | 정수형 자료형 |
| *p | 정수형 포인터 변수 p 선언 |
| sizeof(int) | int 자료형의 크기 |
| malloc(sizeof(int)) | int 하나를 저장할 공간 확보 |
| = | 반환된 메모리 주소를 p에 저장 |

예를 들어 int가 4바이트인 환경이라면 다음과 같다.

```c
malloc(sizeof(int));
```

위 코드는 4바이트 공간을 요청한다.

malloc은 할당에 성공하면 해당 메모리의 시작 주소를 반환한다.

실패하면 NULL을 반환한다.

### 3-2. 전체 코드

```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    int *p = malloc(sizeof(int));

    if (p == NULL) {
        return 1;
    }

    *p = 100;

    printf("%d", *p);

    free(p);

    return 0;
}
```

출력:

```text
100
```

### 3-3. 실행 과정

① 메모리 확보

```c
int *p = malloc(sizeof(int));
```

malloc이 정수 하나를 저장할 공간을 확보한다.

예를 들어 반환된 주소가 500이라고 가정한다.

```text
포인터 변수 p

p = 500
```

② 값 저장

```c
*p = 100;
```

포인터가 가리키는 주소 500에 100을 저장한다.

```text
p = 500

주소 500
+-------+
|  100  |
+-------+
```

③ 값 출력

```c
printf("%d", *p);
```

`*p`는 p가 가리키는 메모리 공간의 값을 의미한다.

따라서 100이 출력된다.

④ 메모리 해제

```c
free(p);
```

사용이 끝난 동적 메모리를 해제한다.

### 3-4. p와 *p의 차이

| 표현 | 의미 | 가상의 예시 |
|---|---|---|
| p | 포인터에 저장된 주소 | 500 |
| *p | 포인터가 가리키는 값 | 100 |
| &p | 포인터 변수 p 자신의 주소 | 100 |
| malloc() | 메모리 확보 후 주소 반환 | 500 |
| free(p) | p가 가리키는 할당 공간 해제 | - |

가장 중요한 차이:

```c
p
```

는 주소를 나타내고,

```c
*p
```

는 해당 주소에 저장된 값을 나타낸다.

### 3-5. malloc()의 반환형

malloc은 void* 타입을 반환한다.

void*는 특정 자료형에 종속되지 않는 범용 객체 포인터이다.

```c
int *p = malloc(sizeof(int));
```

C언어에서는 void*를 int*로 자동 변환할 수 있다.

따라서 아래처럼 명시적 형변환을 사용해도 되지만 필수는 아니다.

```c
int *p = (int*)malloc(sizeof(int));
```

※ C++에서는 관련 규칙이 다르므로 구분해야 한다.

## 4. sizeof() 연산자

sizeof는 자료형 또는 객체의 크기를 바이트 단위로 구하는 연산자이다.

```c
sizeof(int)
sizeof(double)
sizeof(struct Student)
```

대표적인 환경에서 크기는 다음과 같다.

| 자료형 | 흔한 크기 |
|---|---|
| char | 1바이트 |
| short | 2바이트 |
| int | 4바이트 |
| float | 4바이트 |
| double | 8바이트 |
| 포인터 | 4 또는 8바이트 |

※ char가 1바이트인 것은 C언어에서 보장되지만, 나머지 크기는 환경에 따라 달라질 수 있다.

### 예제

```c
int *p = malloc(sizeof(int) * 5);
```

int가 4바이트라면:

```text
4 × 5 = 20바이트
```

정수 5개를 저장할 공간을 확보한다.

다음처럼 배열처럼 접근할 수 있다.

```c
p[0] = 10;
p[1] = 20;
p[2] = 30;
p[3] = 40;
p[4] = 50;
```

사용 후:

```c
free(p);
```

## 5. 포인터 선언 방법

다음 두 코드는 의미가 같다.

```c
char* p;
char *p;
```

모두 char형 데이터를 가리키는 포인터 p를 선언한다.

### 주의할 점

```c
char *p, q;
```

위 코드는 다음과 같다.

```c
char *p;
char q;
```

즉,

- p는 char 포인터
- q는 일반 char 변수

포인터 선언에서 `*`는 각 변수의 선언에 적용된다.

### 구조체 포인터 선언

```c
struct node *h = NULL, *n;
```

다음과 동일하다.

```c
struct node *h = NULL;
struct node *n;
```

해석:

- struct node: 구조체 자료형
- *h: 구조체를 가리키는 포인터
- NULL: 아무 객체도 가리키지 않는 널 포인터 값
- *n: 또 다른 구조체 포인터
- n은 초기화되지 않은 상태

시험에서는 쉼표 뒤에도 `*`가 있는지 반드시 확인한다.

## 6. 구조체와 구조체 포인터

### 6-1. 구조체란?

구조체는 서로 다른 자료형의 데이터를 하나로 묶는 사용자 정의 자료형이다.

```c
struct Student {
    int id;
    char name[20];
    float score;
};
```

구조체 변수 선언:

```c
struct Student s1;
```

멤버에 값 저장:

```c
s1.id = 1;
s1.score = 90.5f;
```

`.`은 구조체 멤버 접근 연산자이다.

### 6-2. 구조체 정의와 변수 선언을 동시에

```c
struct Student {
    int id;
    char name[20];
    float score;
} s1;
```

구조체를 정의하면서 s1이라는 변수까지 선언한 것이다.

### 6-3. 구조체 포인터

```c
struct Student s1;

struct Student *p = &s1;
```

해석:

- s1은 실제 구조체 변수
- &s1은 s1의 주소
- p는 s1의 주소를 저장한 포인터

포인터로 멤버에 접근할 때는 `->`를 사용한다.

```c
p->id = 1;
p->score = 90.5f;
```

### 6-4. . 과 -> 차이

| 표현 | 의미 |
|---|---|
| s1.score | 구조체 변수의 멤버 접근 |
| p->score | 포인터가 가리키는 구조체 멤버 접근 |
| (*p).score | p->score와 동일 |

```c
p->score
```

는 다음과 같다.

```c
(*p).score
```

`(*p)`는 p가 가리키는 구조체를 의미한다.

괄호가 필요한 이유는 `.` 연산자가 `*` 역참조 연산자보다 우선순위가 높기 때문이다.

## 7. typedef와 구조체 포인터 매개변수

typedef는 기존 자료형에 새로운 이름을 붙이는 기능이다.

```c
typedef struct {
    int acc;
    double bal;
} Acc;
```

이제 Acc라는 이름으로 구조체 변수를 선언할 수 있다.

```c
Acc ba;
```

### 예제

```c
#include <stdio.h>

typedef struct {
    int acc;
    double bal;
} Acc;

void init(Acc *a, int x, double y) {
    a->acc = x;
    a->bal = y;
}

void withdraw(Acc *a, double amount) {
    a->bal = a->bal - amount;
}

int main() {
    Acc ba;

    init(&ba, 9981, 2200.0);

    withdraw(&ba, 100.0);

    printf("%d, %.1f", ba.acc, ba.bal);

    return 0;
}
```

### 정답

```text
9981, 2100.0
```

### 실행 과정

① 구조체 변수 선언

```c
Acc ba;
```

② 구조체 주소 전달

```c
init(&ba, 9981, 2200.0);
```

`&ba`는 구조체 변수 ba의 주소이다.

③ 함수 내부

```c
void init(Acc *a, int x, double y)
```

- a는 ba를 가리키는 포인터
- x = 9981
- y = 2200.0

```c
a->acc = x;
a->bal = y;
```

결과:

```text
ba.acc = 9981
ba.bal = 2200.0
```

④ 출금

```c
withdraw(&ba, 100.0);
```

함수 내부 계산:

```text
2200.0 - 100.0 = 2100.0
```

⑤ 출력

```text
9981, 2100.0
```

### 핵심 정리

구조체의 주소를 함수에 전달하면 함수 내부에서 원본 구조체의 멤버를 수정할 수 있다.

## 8. 구조체 동적 메모리 할당

구조체도 malloc으로 동적으로 생성할 수 있다.

### 예제

```c
#include <stdio.h>
#include <stdlib.h>

struct Student {
    int id;
    int score;
};

int main() {
    struct Student *p = malloc(sizeof(struct Student));

    if (p == NULL) {
        return 1;
    }

    p->id = 1;
    p->score = 90;

    printf("%d %d", p->id, p->score);

    free(p);
    p = NULL;

    return 0;
}
```

### 정답

```text
1 90
```

### 실행 과정

① 구조체 크기만큼 메모리 확보

```c
struct Student *p = malloc(sizeof(struct Student));
```

② 포인터로 멤버 접근

```c
p->id = 1;
p->score = 90;
```

③ 출력

```c
printf("%d %d", p->id, p->score);
```

④ 사용 후 해제

```c
free(p);
p = NULL;
```

### 핵심 정리

구조체 동적 할당은 다음 순서로 진행한다.

```text
malloc()
   ↓
구조체 주소 반환
   ↓
포인터에 주소 저장
   ↓
-> 연산자로 멤버 접근
   ↓
free()로 메모리 해제
```

## 9. free()와 메모리 누수

free는 malloc으로 확보한 동적 메모리를 해제하는 함수이다.

```c
int *p = malloc(sizeof(int));

if (p != NULL) {
    *p = 100;

    free(p);
    p = NULL;
}
```

### free()를 하지 않으면?

동적으로 할당한 메모리를 더 이상 사용할 수 없는데도 해제하지 않으면 메모리 누수가 발생할 수 있다.

```c
void leak() {
    int *p = malloc(sizeof(int));

    if (p == NULL) {
        return;
    }

    *p = 100;

    // free(p)가 없음
}
```

함수가 종료되면 지역 포인터 p는 수명이 끝나지만, 할당된 공간은 해제되지 않는다.

해당 공간을 가리키는 다른 포인터도 없다면 메모리 누수가 된다.

### free() 이후 주의사항

```c
free(p);
```

이후에는 해제된 메모리를 역참조하면 안 된다.

```c
printf("%d", *p); // 잘못된 코드: 정의되지 않은 동작
```

안전한 습관:

```c
free(p);
p = NULL;
```

단, p를 NULL로 변경해도 같은 메모리를 가리키는 다른 포인터까지 자동으로 NULL이 되는 것은 아니다.

### 핵심 정리

- malloc으로 확보한 메모리는 사용 후 free로 해제한다.
- free를 하지 않아 접근할 방법을 잃으면 메모리 누수가 발생한다.
- free 이후 해당 메모리를 다시 사용하면 안 된다.
- free(p)는 p 변수 자체를 삭제하는 코드가 아니다.
- malloc 실패 여부를 확인하는 습관이 중요하다.

## 10. 연결 리스트란?

연결 리스트(Linked List)는 각 데이터가 다음 데이터의 주소를 저장하여 서로 연결되는 자료구조이다.

연결 리스트를 구성하는 각각의 요소를 노드(Node)라고 한다.

### 10-1. 노드 구조체

```c
struct Node {
    int data;
    struct Node *next;
};
```

각 멤버의 의미:

| 멤버 | 의미 |
|---|---|
| data | 실제 데이터 |
| next | 다음 노드의 주소 |

연결 리스트 구조:

```text
[10 | next] → [20 | next] → [30 | NULL]
```

### 10-2. 노드 동적 할당

```c
struct Node *n = malloc(sizeof(struct Node));
```

Node 구조체 하나를 저장할 메모리 공간을 확보한다.

```c
if (n != NULL) {
    n->data = 10;
    n->next = NULL;
}
```

이 코드는 다음과 같다.

```text
n
 |
 v
+------------+
| data = 10  |
| next = NULL|
+------------+
```

### 10-3. 노드 두 개 연결하기

```c
#include <stdio.h>
#include <stdlib.h>

struct Node {
    int data;
    struct Node *next;
};

int main() {
    struct Node *first = malloc(sizeof(struct Node));
    struct Node *second = malloc(sizeof(struct Node));

    if (first == NULL || second == NULL) {
        free(first);
        free(second);
        return 1;
    }

    first->data = 10;
    second->data = 20;

    first->next = second;
    second->next = NULL;

    printf("%d %d", first->data, first->next->data);

    free(second);
    free(first);

    return 0;
}
```

### 정답

```text
10 20
```

### 실행 과정

① 첫 번째 노드 생성

```c
first->data = 10;
```

② 두 번째 노드 생성

```c
second->data = 20;
```

③ 두 노드 연결

```c
first->next = second;
```

first의 next에 second의 주소를 저장한다.

```text
first
  |
  v
[10 | next] ------> [20 | NULL]
                      ^
                      |
                    second
```

④ 다음 노드의 데이터 접근

```c
first->next->data
```

순서:

```text
first
→ first->next
→ second
→ second->data
→ 20
```

따라서

```c
printf("%d %d", first->data, first->next->data);
```

출력 결과는 다음과 같다.

```text
10 20
```

### 핵심 정리

- 연결 리스트는 노드들을 포인터로 연결한다.
- 각 노드는 데이터와 다음 노드의 주소를 저장한다.
- malloc으로 새로운 노드를 동적으로 생성할 수 있다.
- `next`는 다음 노드를 가리키는 포인터다.
- 마지막 노드의 next는 일반적으로 NULL이다.
- 사용한 노드는 연결을 끊기 전에 주소를 확보하고, 적절한 순서로 free해야 한다.

## 11. 2차원 배열 동적 할당

2차원 데이터도 동적으로 할당할 수 있다.

다음 예시는 행마다 별도의 메모리를 할당하는 방식이다.

```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    int rows = 3;
    int cols = 3;

    int **arr = malloc(sizeof(int*) * rows);

    if (arr == NULL) {
        return 1;
    }

    for (int i = 0; i < rows; i++) {
        arr[i] = malloc(sizeof(int) * cols);

        if (arr[i] == NULL) {
            for (int j = 0; j < i; j++) {
                free(arr[j]);
            }

            free(arr);
            return 1;
        }
    }

    arr[0][0] = 10;
    arr[1][2] = 20;

    printf("%d %d", arr[0][0], arr[1][2]);

    for (int i = 0; i < rows; i++) {
        free(arr[i]);
    }

    free(arr);

    return 0;
}
```

### 정답

```text
10 20
```

### 11-1. 이중 포인터

```c
int **arr;
```

int**는 int*를 가리키는 포인터 자료형이다.

즉, 정수 데이터를 직접 가리키는 포인터가 아니라 정수 포인터를 가리킬 수 있는 포인터다.

### 11-2. 메모리 할당 과정

첫 번째 할당:

```c
arr = malloc(sizeof(int*) * rows);
```

행마다 사용할 포인터를 저장할 공간을 확보한다.

두 번째 할당:

```c
for (int i = 0; i < rows; i++) {
    arr[i] = malloc(sizeof(int) * cols);
}
```

각 행에 정수 데이터를 저장할 공간을 확보한다.

구조:

```text
arr
 |
 v
+--------+
| arr[0] | ------> [ int ][ int ][ int ]
+--------+
| arr[1] | ------> [ int ][ int ][ int ]
+--------+
| arr[2] | ------> [ int ][ int ][ int ]
+--------+
```

각 행의 실제 데이터는 별도로 할당된 메모리 블록에 저장된다.

### 11-3. 메모리 해제

```c
for (int i = 0; i < rows; i++) {
    free(arr[i]);
}

free(arr);
```

각 행의 데이터를 먼저 해제하고 마지막에 행 포인터 배열을 해제한다.

왜 이렇게 해야 할까?

```c
free(arr);
```

를 먼저 호출하면 arr을 통해 arr[i]에 접근할 수 없게 된다.

따라서 각 행의 주소를 다른 곳에 보관하지 않았다면 메모리 누수가 발생할 수 있다.

### 핵심 정리

- `int *p` : 정수 포인터
- `int **p` : 정수 포인터를 가리키는 포인터
- 행 포인터 배열을 먼저 확보한다.
- 각 행에 필요한 공간을 따로 확보한다.
- 해제할 때는 각 행부터 free하고 마지막에 바깥쪽 포인터 배열을 free한다.

## 12. 정적 2차원 배열과 동적 할당 방식의 차이

### 정적 크기 배열

```c
int a[3][3];
```

이 배열은 연속된 하나의 배열 객체이다.

```text
[0][0] [0][1] [0][2]
[1][0] [1][1] [1][2]
[2][0] [2][1] [2][2]
```

모든 요소가 연속된 메모리에 배치된다.

### 행별 동적 할당

```c
int **arr = malloc(sizeof(int*) * 3);
```

이후 각 행을 별도로 할당한다.

```c
arr[0] = malloc(sizeof(int) * 3);
arr[1] = malloc(sizeof(int) * 3);
arr[2] = malloc(sizeof(int) * 3);
```

각 행은 별도 메모리 블록이므로 서로 연속되어 있다는 보장이 없다.

### 차이

| 구분 | int a[3][3] | int **arr 방식 |
|---|---|---|
| 데이터 배치 | 하나의 연속된 배열 | 행별로 별도 할당 가능 |
| 행 개수 | 선언한 크기 | 실행 중 결정 가능 |
| 메모리 확보 | 배열 선언 | malloc |
| 메모리 해제 | 자동 수명에 따라 관리 가능 | 할당한 블록을 free |
| 자료형 | 2차원 배열 | 이중 포인터 |

주의할 점:

`int a[3][3]`의 배열 이름 a는 일반적인 수식에서 `int (*)[3]` 타입으로 변환된다.

`int **`와 동일한 타입이 아니다.

따라서 일반적인 2차원 배열을 int** 매개변수에 그대로 전달하면 안 된다.

## 13. 정보처리기사 실기 문제 풀이 연습

### 문제 1. 동적 할당과 포인터

```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    int *p = malloc(sizeof(int));

    if (p == NULL) {
        return 1;
    }

    *p = 10;
    *p = *p + 5;

    printf("%d", *p);

    free(p);

    return 0;
}
```

```text
15
```

```c
*p = 10;
```

할당받은 공간에 10을 저장한다.

```c
*p = *p + 5;
```

현재 값 10에 5를 더한다.

```text
10 + 5 = 15
```

따라서 15가 출력된다.

## 14. 헷갈리지 말아야 할 포인트

### 1. p와 *p의 차이

```c
int *p;
```

p는 주소를 저장하는 포인터이다.

```c
*p
```

는 그 주소에 저장된 값에 접근하는 표현이다.

### 2. malloc()은 값을 초기화하지 않는다

```c
int *p = malloc(sizeof(int));
```

malloc으로 할당받은 공간의 기존 내용은 초기화되지 않는다.

따라서 값을 저장하기 전에는 읽지 않아야 한다.

```c
*p = 100;
```

처럼 직접 초기화한 후 사용해야 한다.

### 3. malloc()은 NULL을 반환할 수 있다

```c
int *p = malloc(sizeof(int));

if (p == NULL) {
    return 1;
}
```

동적 할당에 실패할 수 있으므로 반환값을 확인한다.

### 4. 구조체 변수와 구조체 포인터를 구분한다

```c
struct Student s1;
```

멤버 접근:

```c
s1.score
```

포인터라면:

```c
struct Student *p = &s1;
```

멤버 접근:

```c
p->score
```

### 5. -> 와 (*p). 는 동일하다

```c
p->score
```

는 다음과 같다.

```c
(*p).score
```

### 6. free(p)는 p 자체를 삭제하지 않는다

```c
free(p);
```

p가 가리키는 동적 할당 메모리를 해제한다.

포인터 변수 p 자체는 여전히 존재할 수 있다.

다만 해제된 공간에 접근하면 안 된다.

### 7. free() 이후 포인터 사용 금지

```c
free(p);
p = NULL;
```

해제된 공간을 다시 역참조하면 정의되지 않은 동작이 발생한다.

### 8. 이중 포인터는 포인터의 주소를 다룬다

```c
int *p;
int **pp;
```

- p는 int를 가리키는 포인터
- pp는 int*를 가리키는 포인터

### 9. 연결 리스트의 next는 다음 노드의 주소

```c
struct Node {
    int data;
    struct Node *next;
};
```

next는 다음 노드의 데이터를 저장하는 변수가 아니다.

다음 노드를 가리키는 포인터이다.
