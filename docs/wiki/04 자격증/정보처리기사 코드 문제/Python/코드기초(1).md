# 1. extend(), append(), pop()

## 문제

```python
a = ['a', 'b', 'c', 'd']
a.extend(['e', 'f'])
a.append(['e', 'f'])

print(a)
print(a.pop())
```

## 정답

```text
['a', 'b', 'c', 'd', 'e', 'f', ['e', 'f']]
['e', 'f']
```

## 설명

- `extend()` : 리스트의 요소를 하나씩 추가한다.
- `append()` : 전달한 리스트 자체를 하나의 요소로 추가한다.
- `pop()` : 마지막 요소를 제거하고 반환한다.
- `pop()` 실행 시 리스트 안의 `['e', 'f']`가 제거되어 출력된다.

# 2. sort(), append(), reverse(), index()

## 문제

```python
test = [2, 5, 3, 4]
test.sort()
test.append(1)
test.reverse()

print(test)
print(test.index(4))
```

## 정답

```text
[1, 5, 4, 3, 2]
2
```

## 설명

1. `sort()` → `[2, 3, 4, 5]`
2. `append(1)` → `[2, 3, 4, 5, 1]`
3. `reverse()` → `[1, 5, 4, 3, 2]`
4. `index(4)` → 값 4의 인덱스인 `2` 반환

`index()`는 값의 위치를 반환하며, 인덱스는 0부터 시작한다.

# 3. 가변 인자(*args)와 set()

## 문제

```python
def calc(check, *value):
    num = 0

    for i in value:
        num = num + i

    if check:
        return num, set(value), check
    else:
        return set(value)

k = calc(1, 1, 2, 3, 4, 1, 2)
print(k)
```

## 정답

```text
(13, {1, 2, 3, 4}, 1)
```

※ 집합의 출력 순서는 일반적으로 보장되지 않는다.

## 설명

- `check = 1`
- `value = (1, 2, 3, 4, 1, 2)`
- `*value` : 전달받은 여러 인자를 튜플로 저장한다.
- `num` : 1 + 2 + 3 + 4 + 1 + 2 = 13
- `set(value)` : 중복 제거 → `{1, 2, 3, 4}`
- `check`가 1이므로 참(True)으로 판단한다.
- 쉼표로 구분한 여러 값을 반환하면 튜플이 된다.

# 4. 리스트 슬라이싱과 요소 변경

## 문제

```python
t = [1, 2, '1', '2', '3', '4']

t[2:] = 'abc'
t[0] = [1, 2]
t[1:2] = [5, 6]

print(t)
print(t.index(6))
```

## 정답

```text
[[1, 2], 5, 6, 'a', 'b', 'c']
2
```

## 설명

1. `t[2:] = 'abc'` : 2번 인덱스부터 끝까지를 `'a', 'b', 'c'`로 변경
2. `t[0] = [1, 2]` : 0번 인덱스에 리스트 하나를 저장
3. `t[1:2] = [5, 6]` : 슬라이스 영역을 두 요소로 교체
4. `t.index(6)` : 숫자 6의 인덱스인 2 반환

` t[0] = [1, 2]`는 중첩 리스트를 만들지만, 슬라이스 대입은 요소들을 펼쳐 넣는다.

# 6. zip(), tuple(), dict()

## 문제

```python
alpa = ['A', 'B', 'C', 'D']
num = (1, 2, 3)

tupList = list(zip(alpa, num))
dicList = dict(zip(num, alpa))

print(tupList)
print(dicList)
```

## 정답

```text
[('A', 1), ('B', 2), ('C', 3)]
{1: 'A', 2: 'B', 3: 'C'}
```

## 설명

- `zip()` : 여러 반복 가능 객체의 요소를 순서대로 묶는다.
- 묶는 대상의 길이가 다르면 짧은 쪽을 기준으로 종료된다.
- `list(zip(...))` : 튜플을 요소로 갖는 리스트 생성
- `dict(zip(...))` : 앞의 요소를 키, 뒤의 요소를 값으로 사용하는 딕셔너리 생성

```python
        print("I am Lion")

def main():
    tiger = Tiger()

    speak(tiger)
    speak(lion)

main()
```

```text
I am Tiger
I am Lion
```

`speak(tiger)`와 `tiger.speak()`는 호출 대상이 다르다.

서로 다른 객체를 같은 함수로 처리하는 다형성의 예시이다.

# 8. map()과 사용자 정의 함수

## 문제

```python
def add(x, y):
    return x + y

def sub(a, b):

number1 = [1, 2, 3, 4]
number2 = [5, 6, 7, 8]

result2 = map(sub, number2, number1)

print(list(result1))
print(list(result2))
```

```text
[6, 8, 10, 12]
```

# 9. 클래스 변수와 인스턴스 변수

## 문제

```python
class Calc:
    result = 0

    def setdata(self, fir, sec):
        self.fir = fir
        self.sec = sec

    def add(self):
        Calc.result += 1
        self.result = self.fir + self.sec

    def getdata(self):
        print(self.result, end=" ")
        print(Calc.result)

a = Calc()
b = Calc()

b.setdata(5, 10)
a.setdata(3, 2)

a.add()
a.getdata()

b.add()
b.getdata()
```

## 정답

```text
5 1
15 2
```

## 설명

- `Calc.result` : 클래스 변수로 객체들이 공유한다.
- `self.result` : 각 객체가 개별적으로 갖는 인스턴스 변수
- `a.add()` : 3 + 2 = 5, 클래스 변수는 1
- `b.add()` : 5 + 10 = 15, 클래스 변수는 2
- `end=" "` : 줄바꿈 대신 공백 한 칸 출력

클래스 변수와 인스턴스 변수는 이름이 같아도 저장되는 위치가 다르다.

# 10. __init__과 self

## 문제

출력 결과가 `8.0`이 되도록 빈칸을 채우시오.

```python
class T:
    def ①(self, width, height):
        self.width = width
        self.height = height

    def area(②):
        a = this.width * this.height / 2
        return a

tt = T(4, 4)
print(tt.area())
```

## 정답

```text
① __init__
② this
```

완성 코드:

```python
class T:
    def __init__(self, width, height):
        self.width = width
        self.height = height

    def area(this):
        a = this.width * this.height / 2
        return a

tt = T(4, 4)
print(tt.area())
```

출력:

```text
8.0
```

## 설명

- `__init__()` : 객체 초기화 메서드
- `self` : 객체 자신을 참조하는 관례적인 매개변수 이름
- `this`도 일반 매개변수 이름으로 사용 가능하다.
- `area(this)`에서 this는 tt 객체를 가리킨다.
- `4 * 4 / 2 = 8.0`

파이썬에서는 일반적으로 `self`를 사용하지만 예약어는 아니다.

# 11. 중첩 반복문과 break

## 문제

```python
li = ['Apple', 'Banana', 'Cherry']
cnt = 0
str = ''

for i in li:
    for j in i:
        str += j[0]
        cnt = cnt + 1

        if cnt > 5:
            break

print('cnt : ', cnt, ', str : ', str)
```

## 정답

```text
cnt :  7 , str :  AppleBC
```

## 설명

- Apple의 5글자 처리 → cnt = 5
- Banana의 첫 글자 B 처리 → cnt = 6, break
- Cherry의 첫 글자 C 처리 → cnt = 7, break

`break`는 가장 가까운 안쪽 반복문만 종료한다.

문자열 `j`는 한 글자이므로 `j[0]`도 같은 글자이다.

`print()`에서 쉼표로 구분한 값 사이에는 기본적으로 공백이 한 칸 추가된다.

# 19. 중첩 반복문을 이용한 정렬

## 문제

```python
a = [3, 4, 10, 5, 1]

for i in range(0, 5):
    for j in range(i + 1, 5):
        if a[i] < a[j]:
            a[i], a[j] = a[j], a[i]

for k in a:
    print(k, end=" ")
```

## 정답

```text
10 5 4 3 1
```

## 설명

- `range(0, 5)` : 0부터 4까지 반복
- `range(i + 1, 5)` : 현재 위치 뒤의 요소들과 비교
- `a[i] < a[j]` : 뒤의 값이 더 크면 자리 교환
- `a[i], a[j] = a[j], a[i]` : 두 요소의 값을 교환

큰 값이 앞으로 이동하므로 내림차순으로 정렬된다.

마지막 `print(k, end=" ")`는 각 숫자 뒤에 공백 한 칸을 출력한다.

# 20. 상속, 생성자, 소멸자, 메서드 오버라이딩

## 문제

```python
class parent:
    def __init__(self):
        print("parent 생성자")

    def __del__(self):
        print("parent 소멸자")

    def show(self):
        print("sunny")


class child(parent):
    def show(self):
        print("snow")


a = child()
a.show()
del a
```

## 정답

일반적인 CPython 실행 결과:

```text
parent 생성자
snow
parent 소멸자
```

## 설명

1. `a = child()` : 자식 객체 생성, 상속받은 부모의 `__init__()` 실행
2. `a.show()` : 자식 클래스에서 재정의한 `show()` 실행 → snow
3. `del a` : 변수 a의 참조를 제거한다.
4. 객체가 실제로 소멸하면 부모에게서 상속받은 `__del__()`이 호출된다.

자식 클래스가 `show()`를 재정의했으므로 부모의 `sunny`는 출력되지 않는다.

단, `del`은 객체를 즉시 파괴하는 명령이 아니다. 다른 참조가 있거나 파이썬 구현 방식이 다르면 소멸자 호출 시점이 달라질 수 있다.
