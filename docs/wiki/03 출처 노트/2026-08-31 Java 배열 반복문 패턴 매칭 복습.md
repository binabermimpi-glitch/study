## 신뢰도와 주의점

- `instanceof` 패턴 매칭은 Java 16 이상, `switch`의 타입 패턴과 `when` 가드는 Java 21 이상 기준으로 표시했다.
- 향상된 `for` 반복 변수 재대입과 참조 대상 객체 상태 변경은 구분해야 한다.
- Java 2차원 배열은 직사각형 표가 아니라 배열의 배열이므로 행 길이가 다를 수 있다.

## 이해되지 않은 부분과 질문

- 향상된 `for` 반복 변수와 원본 배열 요소의 관계
- `while`에서 `continue`를 만났을 때 무한 반복이 생기는 과정
- `yield`와 `return`의 종료 범위
