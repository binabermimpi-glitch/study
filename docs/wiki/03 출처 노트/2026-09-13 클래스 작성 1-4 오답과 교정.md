# 2026-09-13 클래스 작성 1~4(2) 오답과 교정

## 자료 요약

Book 생성자, Counter 인스턴스 메서드, Account 캡슐화, Student의 static 공유 필드와 생성자 실행을 직접 작성한 연습이다.

## 학습 상태

- 생성자 구조와 `this`, getter/setter는 비교적 잘 이해했다.
- 일반 메서드의 반환형과 생성자·메서드 구분은 추가 연습이 필요하다.
- `static` 공유 상태와 객체 생성 시 자동 실행되는 생성자의 역할을 함께 조립하는 데 막혔다.
