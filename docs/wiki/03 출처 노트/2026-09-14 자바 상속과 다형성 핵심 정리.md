# 2026-09-14 자바 상속과 다형성 핵심 정리

## 자료 요약

인터페이스·추상 클래스·일반 클래스의 차이부터 상속, `this`와 `super`, 오버라이딩과 동적 바인딩, 업캐스팅·다운캐스팅을 정리한 자료다. 이어서 Object의 주요 메서드, 인터페이스 default 메서드, switch 타입 패턴, sealed와 record까지 연결한다.

## 이번 자료에서 확인한 연결

- 인터페이스의 기능 계약과 추상 클래스의 공통 상태·로직을 구분한다.
- 상위 타입 배열에서 같은 메서드를 호출해 실제 구현체마다 다른 동작이 실행되는 과정을 설명한다.
- 안전한 다운캐스팅에 `instanceof` 패턴 변수를 사용한다.
- 논리적 동등성을 정의하면 `equals()`와 `hashCode()`의 계약을 함께 지켜야 한다.
- Java 21 switch 패턴과 sealed 계층의 조합을 확인한다.
- record가 접근자, `equals()`, `hashCode()`, `toString()` 등을 제공한다는 점을 확인한다.
