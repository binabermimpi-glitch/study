## 신뢰도와 주의점

- COMMIT과 ROLLBACK의 DCL/TCL 분류는 시험 문구와 DB 교재의 분류가 다를 수 있다.
- REST는 HTTP 메서드와 CRUD 대응만으로 정의되지 않는다.
- SOAP·WSDL·UDDI와 RARP 같은 기술은 신규 일반 웹 개발보다 시험·레거시 환경에서 접할 가능성이 크다.
- `chmod`는 대상 파일과 권한을 확인한 뒤 사용해야 한다.

## 이해되지 않은 부분과 질문

- SOAP·WSDL·UDDI, AH·ESP, RTO·RPO를 서로 구분하는 복습이 필요하다.
- REST 제약과 Spring REST API 설계를 이후 국비수업에서 연결한다.
