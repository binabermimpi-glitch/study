## 신뢰도와 주의점

- `ALTER TABLE ... MODIFY` 등 구조 변경 문법은 DBMS마다 다르다.
- ICMP는 오류 보고를 돕지만 IP에 전달 보장 자체를 추가하는 프로토콜은 아니다.
- 코드 커버리지 수치가 높다고 테스트가 충분하거나 오류가 없다는 뜻은 아니다.
- C++와 Java 생성자의 공통점만 연결하고 객체 수명·메모리 관리 차이는 별도로 학습한다.

## 이해되지 않은 부분과 질문

- 커버리지 유형과 3단계 스키마는 실제 문제로 재풀이한다.
- GROUP BY·HAVING은 샘플 테이블 결과를 직접 계산한다.
