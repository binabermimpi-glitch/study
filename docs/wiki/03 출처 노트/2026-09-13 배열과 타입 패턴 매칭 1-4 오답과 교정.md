# 2026-09-13 배열과 타입 패턴 매칭 1~4(3)

## 자료 요약

Object로 받은 배열과 객체를 `instanceof` 및 switch 패턴 매칭으로 구분하고, 배열 요소를 순회해 조건에 맞는 값을 출력하는 연습이다.

## 학습 상태

- `instanceof 타입 변수`의 방향과 패턴 변수로 메서드를 호출하는 흐름은 이해했다.
- 배열 전체와 요소 하나, 배열의 `length`와 String의 `length()` 구분이 더 필요하다.
- switch 패턴과 if 문법을 분리해서 조립하는 연습이 필요하다.
