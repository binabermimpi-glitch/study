## 수록 상태

- 1~11번, 14번, 16번 수록
- 12번과 15번은 제공된 문제가 없다는 원문 표시 유지
- 13번은 테이블과 SQL문이 제공되지 않아 제외되었다는 원문 표시 유지
- 문제·정답·개념·코드·실행 과정을 생략하지 않고 보존

형상관리, Bridge·Observer 패턴, UML, 경계값 분석, SSO, ER 다이어그램, 프로세스 스케줄링, FLSM, 사회공학·다크 데이터, SIEM, TrustZone·Typosquatting, SQL DISTINCT·COUNT, C 배열 순위 계산과 관계대수.
