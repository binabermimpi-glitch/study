# main 메서드 학습 회고 — 출처 노트

## 확인된 이해

- `public`, `static`, `void`, `main`, `String[] args` 각각의 기본 역할을 구분할 수 있다.
- 해당 단원의 나머지 내용은 스스로 약 70% 이상 이해했다고 평가했다.

## 막힌 지점

각 요소의 이름은 알고 있지만, 요소들을 올바른 순서로 조립해 완전한 메서드와 실행 가능한 클래스를 작성하는 단계에서 막혔다.

## 진단

개념을 전혀 모르는 상태라기보다 **용어 인식 → 코드 생성**으로 넘어가는 인출 연습이 부족한 상태다. 완성 코드를 반복해서 읽는 것보다 빈칸 채우기, 오류 찾기, 처음부터 작성하기 순서의 연습이 적합하다.

## 후속 학습

- [main 메서드 선언 읽기](</wiki/01%20%EA%B0%9C%EB%85%90/Java/main%20%EB%A9%94%EC%84%9C%EB%93%9C%20%EC%84%A0%EC%96%B8%20%EC%9D%BD%EA%B8%B0>)의 3단계 연습 수행
- 다음 복습 때 정답을 보지 않고 실행 가능한 클래스 작성
- `String[] args`가 왜 문자열 배열인지 후속 확인
