# 나만의 자바 한두 줄 정리

> 내가 이해한 말로 빠르게 복습하는 문서입니다. 자세한 설명은 연결된 개념 문서에서 확인합니다.

## Java와 실행 구조

1. **Java** — 객체지향 프로그래밍 언어이며, JVM을 이용해 여러 운영체제에서 실행할 수 있는 크로스 플랫폼 언어다.
2. **플랫폼 독립성** — Java 프로그램은 특정 OS용 실행 파일에 직접 종속되지 않는다. 각 OS에 맞는 JVM이 같은 바이트코드를 실행한다.
3. **실행 과정** — 소스코드(.java) → 컴파일 → 바이트코드(.class) → JVM 실행

연결: [JDK JRE JVM](</wiki/01%20%EA%B0%9C%EB%85%90/Java/JDK%20JRE%20JVM>), [JVM 메모리와 가비지 컬렉션](</wiki/01%20%EA%B0%9C%EB%85%90/Java/JVM%20%EB%A9%94%EB%AA%A8%EB%A6%AC%EC%99%80%20%EA%B0%80%EB%B9%84%EC%A7%80%20%EC%BB%AC%EB%A0%89%EC%85%98>)

## 타입과 데이터

4. **Type** — 어떤 종류의 데이터를 저장하고 어떤 연산을 할 수 있는지 정하는 것이다.
5. **기본 타입** — 변수에 값을 직접 담는 타입이다. int, double, char, boolean 등이 있다.
6. **리터럴** — 코드에 직접 작성한 값이다. 30과 "홍길동" 등이 리터럴이며, 기본 타입 자체를 리터럴 타입이라고 부르지는 않는다.
7. **참조 타입** — 변수에는 객체 자체가 아니라 객체를 찾아가는 참조값이 들어간다. 클래스, 배열과 인터페이스 타입 등이 해당한다.
8. **String** — 편하게 선언할 수 있지만 기본 타입이 아니라 불변 객체를 사용하는 참조 타입이다.

## 클래스와 객체

9. **Class** — 상태와 동작을 묶은 사용자 정의 자료형이며 객체를 만들기 위한 설계도다.
10. **객체 생성** — 클래스를 정의한 뒤 new를 사용해 실제 객체를 생성한다. 예: Person p = new Person();
11. **Object와 Instance** — 객체는 실제로 만들어진 대상이고, 인스턴스는 어느 클래스에서 만들어졌는지를 강조한 표현이다.
12. **Array** — 같은 타입의 여러 값을 하나의 이름으로 묶어 인덱스로 관리하는 객체다.

연결: [클래스와 접근 제한자](</wiki/01%20%EA%B0%9C%EB%85%90/Java/%ED%81%B4%EB%9E%98%EC%8A%A4%EC%99%80%20%EC%A0%91%EA%B7%BC%20%EC%A0%9C%ED%95%9C%EC%9E%90>), [객체 생성과 초기화 순서](</wiki/01%20%EA%B0%9C%EB%85%90/Java/%EA%B0%9D%EC%B2%B4%20%EC%83%9D%EC%84%B1%EA%B3%BC%20%EC%B4%88%EA%B8%B0%ED%99%94%20%EC%88%9C%EC%84%9C>), [배열과 2차원 배열](</wiki/01%20%EA%B0%9C%EB%85%90/Java/%EB%B0%B0%EC%97%B4%EA%B3%BC%202%EC%B0%A8%EC%9B%90%20%EB%B0%B0%EC%97%B4>)

## 메서드와 Stack

13. **정적 메서드** — 특정 객체가 아니라 클래스에 속하므로 객체 없이 클래스 이름으로 호출할 수 있다.
14. **인스턴스 메서드** — 객체에 속한 동작이므로 객체를 만든 뒤 참조 변수로 호출한다.
15. **Stack과 스택 프레임** — 메서드가 호출될 때마다 매개변수와 지역 변수 등을 위한 스택 프레임이 호출 스택에 쌓인다.
16. **LIFO인 이유** — 나중에 호출된 메서드가 먼저 끝나야 호출한 메서드의 다음 코드로 돌아갈 수 있기 때문이다.

## 인터페이스

17. **Interface** — 구현 클래스가 제공해야 할 기능의 규칙이나 계약을 정의하는 타입이다.
18. **생성자가 없는 이유** — 인터페이스 자체의 객체를 직접 만들 수 없으므로 객체 초기화를 위한 생성자도 없다.

연결: [인터페이스](</wiki/01%20%EA%B0%9C%EB%85%90/Java/%EC%9D%B8%ED%84%B0%ED%8E%98%EC%9D%B4%EC%8A%A4>), [추상 클래스와 추상 메서드](</wiki/01%20%EA%B0%9C%EB%85%90/Java/%EC%B6%94%EC%83%81%20%ED%81%B4%EB%9E%98%EC%8A%A4%EC%99%80%20%EC%B6%94%EC%83%81%20%EB%A9%94%EC%84%9C%EB%93%9C>)

## 객체지향의 네 가지 핵심

19. **캡슐화** — 내부 상태를 숨기고 정해진 메서드를 통해 안전하게 사용하도록 만드는 것이다.
20. **상속** — 부모의 접근 가능한 멤버를 자식이 이어받아 확장하는 타입 관계다. 단순 코드 복사보다 is-a 관계가 중요하다.
21. **추상화** — 복잡한 대상에서 공통되고 중요한 특징과 동작을 뽑아 하나의 개념으로 표현하는 것이다.
22. **다형성** — 하나의 상위 타입으로 여러 하위 객체를 다루고, 실행 시 실제 객체에 맞는 동작을 호출하는 성질이다.

연결: [캡슐화와 Getter Setter](</wiki/01%20%EA%B0%9C%EB%85%90/Java/%EC%BA%A1%EC%8A%90%ED%99%94%EC%99%80%20Getter%20Setter>), [상속 오버라이딩 다형성](</wiki/01%20%EA%B0%9C%EB%85%90/Java/%EC%83%81%EC%86%8D%20%EC%98%A4%EB%B2%84%EB%9D%BC%EC%9D%B4%EB%94%A9%20%EB%8B%A4%ED%98%95%EC%84%B1>), [추상 클래스와 추상 메서드](</wiki/01%20%EA%B0%9C%EB%85%90/Java/%EC%B6%94%EC%83%81%20%ED%81%B4%EB%9E%98%EC%8A%A4%EC%99%80%20%EC%B6%94%EC%83%81%20%EB%A9%94%EC%84%9C%EB%93%9C>)

## 프로그램 흐름

23. **Condition** — 조건에 따라 실행할 코드를 선택하는 흐름이다. 대표 문법은 if와 switch다.
24. **Loop** — 같은 작업을 조건에 따라 반복하는 흐름이다. 대표 문법은 for와 while이다.

## 보충해서 기억할 부분

- “기본 타입은 값, 참조 타입은 주소”는 입문용 설명이다. Java 코드에서 실제 메모리 주소를 직접 다루는 것은 아니다.
- 인터페이스는 상태를 전혀 가질 수 없다는 뜻보다 인스턴스 상태와 생성자를 가질 수 없다고 이해한다. 선언한 필드는 상수다.
- 상속받는 것은 부모의 모든 멤버를 그대로 직접 조작한다는 뜻이 아니다. private 멤버에는 직접 접근할 수 없다.
