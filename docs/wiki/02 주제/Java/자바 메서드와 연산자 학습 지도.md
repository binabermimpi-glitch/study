## 구조를 먼저 읽는 법

```java
public static int add(int left, int right) {
    return left + right;
}
```

- `public`: 접근 가능 범위
- `static`: 클래스에 속한 메서드
- `int`: 반환형
- `add`: 메서드 이름
- `int left, int right`: 매개변수 목록
- `return`: 호출자에게 결과 전달

## 클래스 다이어그램과 연결

클래스 다이어그램은 클래스명, 필드와 메서드를 구획으로 나누어 보여준다. 메서드를 볼 때 이름뿐 아니라 접근 범위, static 여부, 매개변수와 반환형을 함께 확인한다. 다이어그램 표기법의 세부 기호는 UML 학습 단계에서 별도로 확장한다.
