# 자바 실행 구조와 기초 문법 학습 지도

## 이 주제에서 얻게 될 것

소스 코드가 실행되는 과정과 메소드·변수·객체가 언제 만들어지고 사라지는지를 하나의 흐름으로 이해한다.

1. [IntelliJ Java 프로젝트 구조](</wiki/01%20%EA%B0%9C%EB%85%90/Tools/IntelliJ%20Java%20%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8%20%EA%B5%AC%EC%A1%B0>)
2. [JDK·JRE·JVM](</wiki/01%20%EA%B0%9C%EB%85%90/Java/JDK%20JRE%20JVM>)

4. [JVM 메모리와 가비지 컬렉션](</wiki/01%20%EA%B0%9C%EB%85%90/Java/JVM%20%EB%A9%94%EB%AA%A8%EB%A6%AC%EC%99%80%20%EA%B0%80%EB%B9%84%EC%A7%80%20%EC%BB%AC%EB%A0%89%EC%85%98>)
5. [래퍼 클래스와 박싱](</wiki/01%20%EA%B0%9C%EB%85%90/Java/%EB%9E%98%ED%8D%BC%20%ED%81%B4%EB%9E%98%EC%8A%A4%EC%99%80%20%EB%B0%95%EC%8B%B1>)
6. [표준 입출력](</wiki/01%20%EA%B0%9C%EB%85%90/Java/%ED%91%9C%EC%A4%80%20%EC%9E%85%EC%B6%9C%EB%A0%A5>)

## 연결해서 이해하기

```text
IntelliJ에서 JDK 선택
  → javac가 .java를 .class로 컴파일
  → JVM이 클래스를 로딩하고 main 실행
  → 메소드 호출마다 지역 변수의 유효 범위 생성
  → new로 객체 생성
  → 도달할 수 없게 된 객체는 GC 회수 후보
```

## 복습 질문

1. JDK의 `bin`에는 어떤 명령이 있고 각각 무엇을 하는가?
2. 지역 변수와 필드는 초기화 규칙이 어떻게 다른가?
3. 참조가 사라진 객체가 즉시 삭제된다고 말하면 왜 부정확한가?
4. 프로젝트 SDK와 Language Level의 역할은 어떻게 다른가?
5. 기본형을 객체로 다뤄야 할 때 무엇을 사용하는가?
