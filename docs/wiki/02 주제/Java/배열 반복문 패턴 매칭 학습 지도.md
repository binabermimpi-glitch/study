# 배열 반복문 패턴 매칭 학습 지도

## 이 주제에서 얻게 될 것

- 배열 변수가 객체를 참조한다는 사실을 설명한다.
- 일반 `for`와 향상된 `for`를 상황에 맞게 선택한다.
- `continue`, `break`, `return`의 영향 범위를 구분한다.
- `instanceof`와 Java 21 `switch` 패턴 매칭을 읽는다.

## 전체 그림

```text
배열 객체와 참조
  → length와 인덱스
  → 일반 for / 향상된 for
  → continue / break / return
  → 실제 객체 타입 검사
  → switch 표현식과 패턴 매칭
```

3. [String과 참조 자료형](</wiki/01%20%EA%B0%9C%EB%85%90/Java/String%EA%B3%BC%20%EC%B0%B8%EC%A1%B0%20%EC%9E%90%EB%A3%8C%ED%98%95>)

## 실습

1. 정수 배열에서 홀수만 출력한다.
2. 일반 `for`로 배열의 모든 값을 두 배로 바꾼다.
3. 행 길이가 서로 다른 2차원 배열을 중첩 반복문으로 출력한다.
4. `Object` 값을 String·Integer·기타로 구분해 설명 문자열을 반환한다.

## 복습 질문

- 향상된 `for`의 반복 변수에 값을 대입해도 기본형 배열이 바뀌지 않는 이유는 무엇인가?
- `while`에서 `continue`가 무한 반복을 만들 수 있는 이유는 무엇인가?
- `grid.length`와 `grid[row].length`는 무엇이 다른가?
- `yield`와 `return`은 어디까지 종료하는가?
- `case String s when ...`에서 검사되는 순서를 말할 수 있는가?

## 실무 연결

배열보다 `List`를 자주 사용하더라도 순회와 참조 원리는 같다. 패턴 분기가 많아지면 다형성으로 바꿀 수 있는지 판단하는 연습까지 이어간다.
