# 자바 참조와 자료형 기초 학습 지도

## 추천 학습 순서

1. [JDK·JRE·JVM](</wiki/01%20%EA%B0%9C%EB%85%90/Java/JDK%20JRE%20JVM>)으로 코드가 실행되는 큰 흐름 이해
2. [기본 자료형과 리터럴](</wiki/01%20%EA%B0%9C%EB%85%90/Java/%EA%B8%B0%EB%B3%B8%20%EC%9E%90%EB%A3%8C%ED%98%95%EA%B3%BC%20%EB%A6%AC%ED%84%B0%EB%9F%B4>)로 값의 종류 이해
3. [형변환과 연산 프로모션](</wiki/01%20%EA%B0%9C%EB%85%90/Java/%ED%98%95%EB%B3%80%ED%99%98%EA%B3%BC%20%EC%97%B0%EC%82%B0%20%ED%94%84%EB%A1%9C%EB%AA%A8%EC%85%98>)으로 타입 사이의 변환 이해
4. [클래스와 접근 제한자](</wiki/01%20%EA%B0%9C%EB%85%90/Java/%ED%81%B4%EB%9E%98%EC%8A%A4%EC%99%80%20%EC%A0%91%EA%B7%BC%20%EC%A0%9C%ED%95%9C%EC%9E%90>)로 객체의 설계도 이해
5. [참조와 점 연산자](</wiki/01%20%EA%B0%9C%EB%85%90/Java/%EC%B0%B8%EC%A1%B0%EC%99%80%20%EC%A0%90%20%EC%97%B0%EC%82%B0%EC%9E%90>)로 객체에 접근하는 법 이해
6. [static과 인스턴스 멤버](</wiki/01%20%EA%B0%9C%EB%85%90/Java/static%EA%B3%BC%20%EC%9D%B8%EC%8A%A4%ED%84%B4%EC%8A%A4%20%EB%A9%A4%EB%B2%84>) 구분
7. [String과 참조 자료형](</wiki/01%20%EA%B0%9C%EB%85%90/Java/String%EA%B3%BC%20%EC%B0%B8%EC%A1%B0%20%EC%9E%90%EB%A3%8C%ED%98%95>)으로 기본형과 객체의 차이 확장

## 먼저 확실히 구분할 것

| 구분 | 핵심 질문 |
|---|---|
| 값과 변수 | 어떤 값을 어디에 저장하는가? |
| 기본형과 참조형 | 값을 직접 다루는가, 객체를 가리키는 참조를 다루는가? |
| 클래스와 객체 | 설계도인가, 실제로 생성된 대상인가? |
| static과 인스턴스 | 클래스에 속하는가, 각 객체에 속하는가? |
| 컴파일과 실행 | 소스가 언제 바이트코드가 되고 누가 실행하는가? |

## 복습 질문

1. `String`은 왜 기본 자료형이 아닌가?
2. `Test.staticMethod()`와 `new Test().instanceMethod()`의 차이는 무엇인가?
3. `double`을 `int`로 바꾸면 어떤 정보가 사라질 수 있는가?
4. `System.out.println()`의 각 점은 무엇을 찾아가는가?
5. `.java`, `.class`, JVM의 관계를 설명할 수 있는가?
