# 배열 복사와 객체지향 학습 지도

## 이 주제에서 얻게 될 것

- 배열 참조의 재대입과 배열 내용 복사의 차이를 설명한다.
- 객체 배열에서 얕은 복사와 깊은 복사를 그림으로 설명한다.
- 부모 타입 변수와 실제 자식 객체의 역할을 구분한다.
- 오버라이딩·동적 바인딩·추상 클래스의 관계를 설명한다.

## 전체 그림

```text
배열도 객체다
  → 참조값이 복사될 수 있다
  → 객체 배열은 내부 객체를 공유할 수 있다
  → 안전한 상태 관리를 위해 캡슐화·방어적 복사가 필요하다

부모 타입으로 자식 객체를 참조한다
  → 오버라이딩된 메서드는 실제 객체 기준으로 실행된다
  → 추상 클래스가 공통 구조와 구현할 동작을 정의한다
```

## 실습

1. `int[]`를 `System.arraycopy()`로 복사한 뒤 원본과 복사본이 독립적인지 확인한다.
2. `Person[]`을 `clone()`하고 요소 객체가 공유되는지 `==`로 확인한다.
3. `Person` 부모 타입 배열에 `Student` 객체를 넣고 오버라이딩 메서드를 호출한다.
4. 추상 `Animal`과 두 개의 구체 동물 클래스를 만든다.
