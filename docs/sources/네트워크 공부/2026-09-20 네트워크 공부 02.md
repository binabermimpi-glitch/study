# 네트워크 공부 02 이더넷 NIC와 케이블

이 자료는 유선 LAN의 대표 기술인 이더넷, 이더넷 프레임, NIC와 케이블을 정리하고 정보처리기사에서 함께 알아둘 핵심 개념을 보충한다.

## 1 이더넷이란

이더넷 Ethernet은 현대 LAN, 특히 유선 LAN에서 가장 널리 사용되는 기술이다. 통신 매체의 규격, 전송 속도, 프레임 형식과 프레임을 주고받는 방법 등을 정의한다.

- 물리 계층 관련 기술: 케이블, 신호, 전송 속도
- 데이터 링크 계층 관련 기술: 이더넷 프레임, MAC 주소, 오류 검출

## 2 이더넷 표준

이더넷은 IEEE 802.3으로 표준화되어 있다. IEEE 802.3은 하나의 규격이 아니라 이더넷과 관련된 여러 표준의 모음이다. 표준에 따라 지원 속도, 케이블, 최대 거리와 장비가 달라진다.

예: IEEE 802.3u, IEEE 802.3ab, IEEE 802.3ae

## 3 이더넷 표준 이름 해석

대표적인 표준 이름은 전송 속도 + BASE + 추가 특성으로 읽는다.

| 표기 | 의미 | 예 |
| --- | --- | --- |
| 전송 속도 | 숫자만 있으면 Mbps, G가 붙으면 Gbps | 100BASE-TX는 100Mbps, 10GBASE-T는 10Gbps |
| BASE | 베이스밴드 방식 | 통신 매체 대역을 신호 전송에 사용 |
| 추가 특성 | 매체 또는 세부 규격 | T 트위스티드 페어, S 단파장 광섬유, L 장파장 광섬유 |

| 표준 | 속도 | 주요 매체 |
| --- | --- | --- |
| 10BASE-T | 10Mbps | 트위스티드 페어 |
| 100BASE-TX | 100Mbps | 트위스티드 페어 |
| 1000BASE-T | 1Gbps | 트위스티드 페어 |
| 1000BASE-SX | 1Gbps | 단파장 광섬유 |
| 1000BASE-LX | 1Gbps | 장파장 광섬유 |
| 10GBASE-T | 10Gbps | 트위스티드 페어 |

## 4 속도에 따른 분류

고속 이더넷 Fast Ethernet은 약 100Mbps, 기가비트 이더넷은 약 1Gbps, 10기가비트 이더넷은 약 10Gbps를 지원한다.

## 5 이더넷 프레임

데이터 링크 계층의 이더넷 네트워크에서 송수신되는 PDU는 프레임이다. 송신 측은 상위 계층 데이터에 헤더와 트레일러를 붙여 캡슐화하고, 수신 측은 이를 확인하고 제거하여 역캡슐화한다.

### 그림 1 이더넷 프레임의 구성

```text
헤더                                      페이로드             트레일러
┌────────┬──────────────┬──────────────┬─────────┬──────────────┬─────┐
│프리앰블│수신지 MAC 주소│송신지 MAC 주소│타입/길이│데이터        │ FCS │
└────────┴──────────────┴──────────────┴─────────┴──────────────┴─────┘
 8바이트     6바이트         6바이트       2바이트   46~1500바이트  4바이트
```

| 구성 요소 | 크기 | 역할 |
| --- | --- | --- |
| 프리앰블과 SFD | 7바이트 + 1바이트 | 동기화와 프레임 시작 표시 |
| 수신지 MAC 주소 | 6바이트 | 프레임을 받을 인터페이스 식별 |
| 송신지 MAC 주소 | 6바이트 | 프레임을 보낸 인터페이스 식별 |
| 타입 또는 길이 | 2바이트 | 상위 프로토콜 또는 데이터 길이 표시 |
| 데이터 | 46~1500바이트 | 상위 계층에서 받은 페이로드 |
| FCS | 4바이트 | CRC를 이용한 오류 검출 |

## 6 프리앰블과 SFD

프리앰블은 송수신 장치의 신호 동기화를 돕는 7바이트 정보이고, SFD Start Frame Delimiter는 실제 프레임 시작을 표시하는 1바이트 정보이다. 두 부분을 합쳐 8바이트 프리앰블이라고 설명하기도 한다.

- 프리앰블 7바이트: 10101010 반복
- SFD 1바이트: 마지막이 10101011
- 일반적인 프레임 크기 계산에서는 프리앰블과 SFD를 제외

## 7 MAC 주소

MAC 주소는 네트워크 인터페이스를 식별하는 6바이트 48비트 주소이다. 물리적 주소 또는 하드웨어 주소라고도 하며 같은 LAN 안에서 송수신지를 구분한다. 한 컴퓨터에 유선, 무선, 가상 어댑터가 있으면 MAC 주소도 여러 개 존재할 수 있다.

- 앞 24비트: OUI, 제조업체 식별
- 뒤 24비트: 제조업체가 인터페이스를 식별하기 위해 부여
- Windows 확인: `getmac /v` 또는 `ipconfig /all`
- Linux 확인: `ip link` 또는 `ip addr`

## 8 타입 또는 길이와 이더타입

2바이트 필드 값이 1500 이하이면 데이터 길이, 1536 이상이면 이더타입으로 해석한다. 1501~1535는 구분을 위해 예약된 범위이다.

| 이더타입 | 프로토콜 |
| --- | --- |
| 0x0800 | IPv4 |
| 0x0806 | ARP |
| 0x86DD | IPv6 |

## 9 데이터와 패딩

데이터 필드는 상위 계층에서 전달받은 페이로드이다. 최소 46바이트, 최대 1500바이트이다. 46바이트보다 작으면 최소 크기를 맞추기 위해 패딩을 추가한다. 일반적인 이더넷 MTU는 1500바이트이다.

## 10 이더넷 프레임 크기

프리앰블과 SFD를 제외한 일반 이더넷 프레임은 최소 64바이트, 최대 1518바이트이다. VLAN 태그가 포함되면 보통 1522바이트가 된다.

| 구분 | 계산 | 크기 |
| --- | --- | --- |
| 최소 | 6+6+2+46+4 | 64바이트 |
| 최대 | 6+6+2+1500+4 | 1518바이트 |

## 11 FCS와 CRC

FCS Frame Check Sequence는 프레임 마지막에 있는 4바이트 오류 검출 필드이다. 송수신 측이 CRC 값을 계산해 비교하고 값이 다르면 오류가 발생한 프레임으로 판단하여 폐기한다. CRC는 오류를 검출하지만 오류 자체를 수정하지는 않는다.

## 12 CSMA CD

CSMA CD는 전통적인 공유형 반이중 이더넷에서 충돌을 처리하는 방식이다. 통신 매체가 비었는지 확인하고 전송한 뒤 충돌을 감지하면 전송을 멈추고 임의의 시간 후 재전송한다.

- Carrier Sense: 매체 사용 여부 확인
- Multiple Access: 여러 장치가 매체 공유
- Collision Detection: 충돌 감지
- 현대의 스위치 기반 전이중 이더넷에서는 충돌이 없어 사실상 사용하지 않음

## 13 이더넷 외의 기술 토큰링

토큰링은 IEEE 802.5 표준으로, 링을 순환하는 토큰을 가진 호스트만 데이터를 전송한다. 충돌을 예방할 수 있지만 현재는 대부분 이더넷으로 대체되었다.

# 02-2 NIC와 케이블

## 14 NIC

NIC Network Interface Controller는 호스트와 유무선 통신 매체를 연결하는 장비이다. 네트워크 인터페이스 카드, 네트워크 어댑터, LAN 카드 등으로도 부른다.

- 통신 매체의 신호와 컴퓨터 데이터 상호 변환
- MAC 주소 인식
- 관련 없는 수신지 MAC 프레임 폐기
- FCS를 이용해 오류 프레임 폐기
- NIC마다 지원 속도가 다름

실제 연결 속도는 NIC뿐 아니라 케이블, 스위치, 라우터와 상대 장치가 함께 지원하는 범위에서 결정된다.

## 15 트위스티드 페어 케이블

구리선을 꼬아 전기 신호를 전달하는 유선 LAN의 대표 통신 매체이다. 선을 꼬아 외부 전자기 간섭과 내부 신호 간섭을 줄인다.

| 종류 | 특징 |
| --- | --- |
| UTP | 차폐되지 않음, 저렴하고 설치가 쉬워 일반 LAN에 많이 사용 |
| STP | 차폐 처리되어 간섭에 강하지만 상대적으로 비싸고 설치가 복잡 |

| 분류 | 대표 지원 성능 |
| --- | --- |
| Cat5 | 주로 100Mbps |
| Cat5e | 최대 1Gbps |
| Cat6 | 1Gbps, 짧은 거리에서 10Gbps 가능 |
| Cat6a | 최대 10Gbps |

트위스티드 페어 케이블은 일반적으로 8개의 접점을 가진 RJ-45 형태의 커넥터를 사용한다.

## 16 다이렉트 케이블과 크로스 케이블

과거에는 다른 종류의 장비를 연결할 때 다이렉트 케이블, 같은 종류의 장비를 연결할 때 크로스 케이블을 사용했다. 현대 장비는 Auto MDI-X로 선 배열을 자동 인식하는 경우가 많다.

## 17 광섬유 케이블

광섬유 케이블은 빛을 이용해 정보를 전송한다. 구리선보다 빠르고 장거리 전송에 유리하며 전자기 간섭의 영향을 적게 받는다.

| 구조 | 역할 |
| --- | --- |
| 코어 | 빛이 실제로 흐르는 중심 부분 |
| 클래딩 | 빛이 코어 안에 머물도록 전반사를 돕는 부분 |

| 종류 | 특징 |
| --- | --- |
| 싱글 모드 | 코어가 가늘고 하나의 빛 경로 사용, 장거리와 높은 대역폭에 유리 |
| 멀티 모드 | 코어가 비교적 굵고 여러 경로 사용, 건물 내부 등 비교적 단거리에 사용 |

## 정보처리기사 핵심 암기

- IEEE 802.3 = 이더넷, IEEE 802.5 = 토큰링, IEEE 802.11 = 무선 LAN
- MAC 주소 = 6바이트 48비트 물리적 주소
- 데이터 필드 = 46~1500바이트
- 일반 이더넷 프레임 = 최소 64바이트, 최대 1518바이트
- FCS = 4바이트 오류 검출 필드, CRC 사용
- CSMA/CD = 충돌 감지 후 임의 시간 대기하고 재전송
- 현대 스위치 기반 전이중 이더넷에서는 CSMA/CD를 사용하지 않음
- NIC = 호스트와 매체 연결, 신호와 데이터 변환
- 코어 = 빛이 흐르는 부분, 클래딩 = 빛을 코어 안에 가두는 부분
