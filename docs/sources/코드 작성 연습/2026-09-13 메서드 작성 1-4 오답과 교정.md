# 1~4(1) 오답 + 교정 정리

## 1번

문제: 정수 하나를 받아 8의 배수인지 판별하는 static boolean 메서드를 작성한다.

내가 쓴 코드:

```java
public static boolean isMultipleOf8(int a) {
    return a % 8 == 0
}
```

부족했던 점: 세미콜론이 빠졌다. 조건식을 바로 반환한 방향은 맞았다.

정답:

```java
public static boolean isMultipleOf8(int a) {
    return a % 8 == 0;
}
```

## 2번

문제: String, int, double을 받는 show() 메서드를 오버로딩한다. double은 printf로 소수점 둘째 자리와 %를 출력한다.

내가 쓴 코드:

```java
show(String name) {
    System.out.println("이름 :" = name)
}

show(int score) {
    System.out.prinln("점수 :" = score)
}

show(double understand) {
    System.out.printf("이해도 : %d.2f%%", double, understand)
}
```

부족했던 점: void 누락, 문자열 연결에 = 사용, println 오타, printf 형식 지정자 오류, 타입 이름 double을 인수로 전달했다.

정답:

```java
public static void show(String name) {
    System.out.println("이름 : " + name);
}

public static void show(int score) {
    System.out.println("점수 : " + score);
}

public static void show(double understand) {
    System.out.printf("이해도 : %.2f%%%n", understand);
}
```

## 3번

문제: 문자열을 받아 대문자로 변환하여 반환하는 static 메서드를 작성한다.

내가 쓴 코드:

```java
public String changeUpper(String a) {
    return a.UpperCase();
}
```

부족했던 점: static 누락, 존재하지 않는 UpperCase() 사용. 정확한 API는 toUpperCase()다.

정답:

```java
public static String changeUpper(String a) {
    return a.toUpperCase();
}
```

## 4번

문제: 정수 두 개 중 큰 값을 삼항 연산자로 출력하는 non-static compare() 메서드를 작성한다.

내가 쓴 코드:

```java
public int compare(int a, int b) {
    return a > b ? a : b
}
```

부족했던 점: 삼항 연산자는 맞았지만 문제는 반환이 아니라 출력을 요구했다. 결과 변수 저장과 세미콜론이 빠졌다.

정답:

```java
public void compare(int a, int b) {
    int result = a > b ? a : b;
    System.out.println(result);
}
```

## 이번에 특히 부족했던 부분

- 반환형과 처리 방법 연결
- 오른쪽 계산 결과를 변수에 저장하는 흐름
- 문자열 연결에는 =가 아니라 + 사용
- 메서드 호출에는 괄호 사용
- printf의 %.2f, %%, %n 형식
- 문제에서 출력과 반환을 먼저 구분하기

문제를 보면 무엇을 받는지, 무엇을 계산하는지, 결과 타입이 무엇인지, 출력인지 반환인지 순서로 생각한다.
