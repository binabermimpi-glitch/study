# 1~4(2) 오답 + 교정 정리

## 1번 Book 클래스

### 문제

`String title`, `int price` 필드를 가진 Book 클래스를 만들고 생성자로 제목과 가격을 저장한다.

### 내가 쓴 코드

```java
class Book {
    String title;
    int price;

    Book(String s, int b) {
        this.title = s;
        this.price = b;
    }
```

### 부족했던 점

- 생성자 구조는 잘 작성했다.
- 클래스 닫는 중괄호만 마무리하면 된다.
- 생성자에 반환형을 쓰지 않는 점은 잘 적용했다.

### 정답

```java
class Book {
    String title;
    int price;

    Book(String s, int b) {
        this.title = s;
        this.price = b;
    }
}
```

## 2번 Counter 클래스

### 문제

`add()`를 호출할 때마다 `count`가 1씩 증가하는 Counter 클래스를 만든다.

### 내가 쓴 코드

```java
class Counter {
    int count;

    add() {
        count++;
    }
}
```

### 부족했던 점

- `add()`는 생성자가 아니라 일반 메서드이므로 반환형 자리가 필요하다.
- 반환값이 없으므로 `void`를 사용해야 한다.

### 정답

```java
class Counter {
    int count;

    public void add() {
        count++;
    }
}
```

## 3번 Account 클래스

### 문제

`money`를 private 필드로 만들고 `setMoney()`로 변경하며 `getMoney()`로 반환한다.

### 내가 쓴 코드

```java
class Account {
    private int money;

    public void setMoney(int c) {
        this.money = c;
    }

    public int getMoney() {
        return money;
    }
}
```

### 부족했던 점

- 거의 없음. setter와 getter의 역할을 잘 구분했다.

### 정답

```java
class Account {
    private int money;

    public void setMoney(int c) {
        this.money = c;
    }

    public int getMoney() {
        return money;
    }
}
```

## 4번 Student 클래스

### 문제

모든 객체가 공유하는 학생 수를 두고 `new Student()`가 실행될 때마다 1씩 증가시킨다.

### 내가 쓴 코드

```java
class Student {
    int count;

    public static studentCount() {
        count++;
    }
}
```

### 부족했던 점

- 공유하는 값은 일반 필드가 아니라 `static int studentCount`여야 한다.
- `studentCount`는 메서드가 아니라 학생 수를 저장하는 변수다.
- 객체 생성 순간 실행되어야 하므로 증가 코드는 생성자 안에 둔다.

### 정답

```java
class Student {
    public static int studentCount;

    public Student() {
        studentCount++;
    }
}
```

## 이번 연습의 핵심

- 생성자는 클래스 이름과 같고 반환형이 없으며 객체 생성 시 자동 실행된다.
- 일반 메서드는 반환형 자리가 필요하다. 반환값이 없으면 `void`를 쓴다.
- 객체별 값은 인스턴스 필드, 모든 객체가 공유하는 값은 `static` 필드로 둔다.
- 기능만 보지 말고 언제 실행되어야 하는지도 확인한다.
