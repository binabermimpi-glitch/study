# 1. AAA 🔥🔥 매우 중요

## 문제

AAA, Triple-A라고 읽는 이 용어는 보안의 세 가지를 합쳐 축약한 용어이다. 다음 (1)~(3)에 해당하는 용어를 `<보기>`에서 찾아 쓰시오.

보기:

```text
Authentication
Application
Accounting
Ascii
Avalanche
Authorization
```

(1) 보안 기능에서 사람이나 프로세스의 신분을 확인하는 것

(2) 검증된 사용자에게 어떤 수준의 권한과 서비스를 허용하는 것

(3) 사용자의 자원 사용 정보를 모아서 과금, 감사, 용량 증설, 리포팅 등을 실시하는 것

## 정답

(1) **Authentication**

(2) **Authorization**

(3) **Accounting**

---

# AAA 개념

## Authentication - 인증

사용자가 누구인지 확인한다.

```text
너 누구야?
→ Authentication
```

예:

* ID / Password
* 인증서
* OTP
* 생체인증

## Authorization - 인가

인증된 사용자가 어떤 기능이나 자원까지 사용할 수 있는지 결정한다.

```text
무엇까지 할 수 있어?
→ Authorization
```

## Accounting - 사용 기록

사용자가 어떤 자원을 얼마나 사용했는지 기록한다.

```text
무엇을 얼마나 사용했어?
→ Accounting
```

## AAA 초압축

```text
Authentication
→ 신원 확인

Authorization
→ 권한 부여

Accounting
→ 사용 기록 / 과금
```

# 6. 색인 🔥

## 문제

다음은 파일 구조에 대한 설명이다. 빈 칸에 알맞은 답을 작성하시오.

* 파일의 구조는 파일을 구성하는 레코드들이 보조기억장치에 편성되는 방식을 의미하는 것으로, 편성 방법에 따라 순차, (   ), 랜덤, 해싱 등이 있다.
* (   )은 순차 처리와 랜덤 처리가 모두 가능하도록 레코드들을 키 값 순으로 정렬하여 기록하여 데이터에 접근한다. 자기 디스크에서 주로 사용된다.

## 정답

**색인**

## 관련 개념

문제의 전체 개념은 **색인 순차 파일(Indexed Sequential File)**이다.

색인을 이용하면서 레코드를 키 값 순서로 저장하여 순차 접근과 직접 접근을 모두 지원하는 방식이다.

### 순차 파일

레코드를 논리적인 순서대로 연속 저장한다.

```text
A → B → C → D
```

### 직접 파일

키를 이용해 레코드가 저장된 위치에 직접 접근한다.

### 색인 순차 파일

순차 파일과 직접 파일의 장점을 결합한다.

```text
순차 처리 가능
+
직접 접근 가능
+
Index 사용
→ 색인 순차 파일
```

### 시험에서는

```text
빈칸 정답
→ 색인

전체 파일 구조 명칭
→ 색인 순차 파일
```

로 구분해서 기억한다.

# 14. Cause-Effect Graphing 🔥

## 문제

입력 데이터 간의 관계와 출력에 영향을 미치는 상황을 체계적으로 분석하여 효용성이 높은 검사 사례를 선정하는 테스트 기법

## 정답

**Cause-Effect Graphing**

또는

**원인-효과 그래프 검사**

## 개념

입력 조건과 출력 결과 사이의 관계를 그래프로 표현하여 테스트 케이스를 설계하는 블랙박스 테스트 기법이다.

```text
입력 조건
→ Cause

출력 결과
→ Effect
```

## 블랙박스 테스트 기법

```text
동등 분할
→ 유효/무효 영역

경계값 분석
→ 경계 근처

원인-효과 그래프
→ 입력/출력 관계

오류 예측
→ 경험에 의한 오류 예상

비교 검사
→ 여러 버전 결과 비교

결정 테이블
→ 조건 조합과 결과를 표로 표현
```
