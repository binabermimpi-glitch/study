
# Java 코드 문제 정리

## 1. 추상 클래스 + 인터페이스 + 형변환

### 문제

```java
abstract class Shape {
    static int count = 0;
    String name;

    Shape(String name) {
        this.name = name;
        count++;
    }

    abstract int area();
}

interface Printable {
    String format();
}

class Rect extends Shape implements Printable {
    int w, h;

    Rect(int w, int h) {
        super("R");
        this.w = w;
        this.h = h;
    }

    int area() {
        return w * h;
    }

    public String format() {
        return name + "=" + area();
    }
}

class Circle extends Shape implements Printable {
    int r;

    Circle(int r) {
        super("C");
        this.r = r;
    }

    int area() {
        return r * r * 3;
    }

    public String format() {
        return name + "=" + area();
    }
}

public class Main {
    public static void main(String[] args) {
        Printable[] arr = {
            new Rect(3, 4),
            new Circle(5)
        };

        int sum = 0;

        for (Printable p : arr) {
            System.out.println(p.format());
            sum += ((Shape) p).area();
        }

        System.out.println(sum + "/" + Shape.count);
    }
}
```

### 정답

```text
R=12
C=75
87/2
```

### 해설

- `Rect(3,4)` → 3 × 4 = 12
- `Circle(5)` → 5 × 5 × 3 = 75
- `sum` → 12 + 75 = 87
- `Shape.count` → 객체가 2개 생성되어 2
- `((Shape) p)` → Printable 타입 참조를 Shape 타입으로 형변환
- `format()` → 실제 객체의 오버라이딩된 메서드 실행

**주의:** 출력 문자열은 대소문자를 정확히 구분해야 한다. `R`과 `r`은 다르다.

## 2. static 변수와 인스턴스 변수

### 문제

```java
class Counter {
    static int count = 0;
    int id;

    Counter() {
        count++;
        id = count;
    }

    static int getCount() {
        return count;
    }
}

public class Main {
    public static void main(String[] args) {
        Counter c1 = new Counter();
        Counter c2 = new Counter();
        Counter c3 = new Counter();

        System.out.println(c1.id);
        System.out.println(c2.id);
        System.out.println(Counter.getCount());
    }
}
```

### 정답

```text
1
2
3
```

### 해설

- `static count` → 모든 객체가 공유하는 변수
- `id` → 객체마다 별도로 존재하는 변수
- 객체를 생성할 때마다 count가 1씩 증가한다.
- c1.id = 1, c2.id = 2, c3.id = 3
- 최종 count = 3

## 3. protected 접근 제어자와 상속

### 문제

```java
class Parent {
    protected int n = 2;
}

class Child extends Parent {
    int calc() {
        return n * 3;
    }
}

public class Main {
    public static void main(String[] args) {
        Child c = new Child();
        System.out.print(c.calc());
    }
}
```

### 정답

```text
6
```

### 해설

- `protected` → 자식 클래스에서 접근 가능
- Child는 Parent를 상속하므로 n을 사용할 수 있다.
- `n = 2`
- `2 * 3 = 6`

## 4. 문자열 결합과 char 연산

### 문제

```java
public class Main {
    public static void main(String[] args) {
        int a = 7;
        char c = 'A';

        System.out.println(a + 3 + "감자");
        System.out.println("점수:" + a + c);
        System.out.println(c + 1);
    }
}
```

### 정답

```text
10감자
점수:7A
66
```

### 해설

**① `a + 3 + "감자"`**

- 7 + 3 = 10
- 10 + "감자" = "10감자"

**② `"점수:" + a + c`**

- 문자열이 먼저 등장하므로 문자열 결합으로 처리된다.
- "점수:" + 7 = "점수:7"
- "점수:7" + 'A' = "점수:7A"

**③ `c + 1`**

- 'A'의 문자 코드는 65
- 65 + 1 = 66

**핵심**

- 문자열 + 숫자 → 문자열 결합
- char + int → 숫자 연산
- 덧셈은 왼쪽부터 계산한다.

## 5. 배열 참조와 String 재할당

### 문제

```java
public class Main {
    public static void change(String[] data, String s) {
        data[0] = s;
        s = "Z";
    }

    public static void main(String[] args) {
        String data[] = {"A"};
        String s = "B";

        change(data, s);

        System.out.print(data[0] + s);
    }
}
```

### 정답

```text
BB
```

### 해설

1. 처음 data[0] = "A", s = "B"
2. `data[0] = s` → 배열 요소가 "B"로 변경
3. `s = "Z"` → 메서드 내부의 지역 변수만 변경
4. main의 s는 여전히 "B"

**핵심**

- 배열 요소 수정 → 원본 배열에 반영
- 매개변수 재할당 → 호출한 쪽 변수에는 영향 없음

## 6. 다형성과 메서드 오버라이딩

### 문제

```java
class Animal {
    String name;
    int energy;

    Animal(String name, int energy) {
        this.name = name;
        this.energy = energy;
    }

    String act() {
        energy -= 10;
        return name + ":" + energy;
    }
}

class Dog extends Animal {
    Dog(String name) {
        super(name, 50);
    }

    String act() {
        energy -= 20;
        return name + "!" + energy;
    }
}

class Cat extends Animal {
    Cat(String name) {
        super(name, 30);
    }
}

public class Main {
    public static void main(String[] args) {
        Animal[] pets = {
            new Dog("멍이"),
            new Cat("냥이"),
            new Dog("바둑이")
        };

        for (Animal p : pets) {
            p.act();

            if (p.energy > 20) {
                System.out.println(p.act());
            } else {
                System.out.println(p.name);
            }
        }
    }
}
```

### 정답

```text
멍이!10
냥이
바둑이!10
```

### 해설

**Dog(멍이)**

- 초기 energy = 50
- 첫 번째 act() → 30
- 30 > 20 → true
- 두 번째 act() → 10
- 출력: 멍이!10

**Cat(냥이)**

- 초기 energy = 30
- 첫 번째 act() → 20
- 20 > 20 → false
- 출력: 냥이

**Dog(바둑이)**

- 멍이와 동일한 과정
- 출력: 바둑이!10

**핵심**

- 오버라이딩된 메서드는 실제 객체 타입을 기준으로 호출된다.
- 메서드를 호출할 때마다 energy가 변경된다.
- Cat은 act()를 재정의하지 않았으므로 부모 메서드를 사용한다.

## 7. 인터페이스와 논리 연산자

### 문제

```java
interface A {
    int sum(int[] a, boolean odd);
}

class B implements A {
    public int sum(int[] a, boolean odd) {
        int result = 0;

        for (int i = 0; i < a.length; i++) {
            if ((odd && a[i] % 2 != 0) ||
                (!odd && a[i] % 2 == 0)) {
                result += a[i];
            }
        }

        return result;
    }
}

class Gamja {
    public static void main(String[] args) {
        int a[] = {1, 2, 3, 4, 5, 6, 7, 8, 9};

        B x = new B();

        System.out.print(
            x.sum(a, true) + ", " + x.sum(a, false)
        );
    }
}
```

### 정답

```text
25, 20
```

### 해설

**odd = true**

- 홀수만 더한다.
- 1 + 3 + 5 + 7 + 9 = 25

**odd = false**

- 짝수만 더한다.
- 2 + 4 + 6 + 8 = 20

**연산자**

- `&&` → AND
- `||` → OR
- `!` → NOT
- `% 2 != 0` → 홀수 판별
- `% 2 == 0` → 짝수 판별

**주의:** `", "`에는 쉼표와 공백 한 칸이 포함되어 있다. 따라서 `25,20`이 아니라 `25, 20`이다.

## 8. 객체 배열과 참조값 교환

### 문제

```java
public class Main {
    public static class BO {
        public int v;

        public BO(int v) {
            this.v = v;
        }
    }

    public static void main(String[] args) {
        BO a = new BO(1);
        BO b = new BO(2);
        BO c = new BO(3);

        BO[] arr = {a, b, c};

        BO t = arr[0];
        arr[0] = arr[2];
        arr[2] = t;

        arr[1].v = arr[0].v;

        System.out.println(a.v + "a" + b.v + "b" + c.v);
    }
}
```

### 정답

```text
1a3b3
```

### 해설

**초기 상태**

- a.v = 1
- b.v = 2
- c.v = 3
- arr = [a, b, c]

**참조값 교환**

```java
BO t = arr[0];
arr[0] = arr[2];
arr[2] = t;
```

- 배열 요소가 가리키는 객체의 순서만 변경된다.
- arr = [c, b, a]

**값 변경**

```java
arr[1].v = arr[0].v;
```

- arr[1]은 b 객체
- arr[0]은 c 객체
- b.v = c.v = 3

**최종 상태**

- a.v = 1
- b.v = 3
- c.v = 3

**핵심**

- 배열의 참조값을 교환해도 객체 내부 값은 변경되지 않는다.
- 객체 필드에 직접 대입하면 같은 객체를 참조하는 변수에서도 변경된 값이 보인다.

## 9. 메서드 오버로딩과 재귀 함수

### 문제

```java
public class Gamja {
    public static void main(String[] args) {
        System.out.println(calc("5"));
    }

    static int calc(int value) {
        if (value <= 1) return value;

        return calc(value - 1) + calc(value - 2);
    }

    static int calc(String str) {
        int value = Integer.valueOf(str);

        if (value <= 1) return value;

        return calc(value - 1) + calc(value - 3);
    }
}
```

### 정답

```text
4
```

### 해설

**① `calc("5")` 호출**

- "5"는 String 타입이다.
- 따라서 `calc(String str)` 실행
- `Integer.valueOf("5")` → 5

**② 재귀 호출**

```java
return calc(4) + calc(2);
```

- `calc(4)`와 `calc(2)`는 int 타입이므로 `calc(int)` 실행

**③ calc(int) 계산**

| 호출 | 반환값 |
|---|---|
| calc(0) | 0 |
| calc(1) | 1 |
| calc(2) | 1 |
| calc(3) | 2 |
| calc(4) | 3 |

최종 계산:

```text
calc("5")
= calc(4) + calc(2)
= 3 + 1
= 4
```

**핵심**

- 메서드 오버로딩은 전달하는 인수 타입에 따라 선택된다.
- `calc("5")` → String 버전
- `calc(5)` → int 버전
- 재귀 함수는 종료 조건까지 계산한 후 결과를 반환한다.

## 10. try-catch-finally 실행 순서

### 문제

```java
public class Main {
    static void check(int x) throws Exception {
        if (x < 0) {
            throw new Exception();
        }

        System.out.print(x);
    }

    public static void main(String[] args) {
        try {
            check(5);
            check(-1);
            check(10);
        } catch (Exception e) {
            System.out.print("X");
        } finally {
            System.out.print("Y");
        }

        System.out.print("Z");
    }
}
```

### 정답

```text
5XYZ
```

### 해설

1. `check(5)` → 5 출력
2. `check(-1)` → 예외 발생
3. `check(10)` → 실행되지 않음
4. catch → X 출력
5. finally → Y 출력
6. try-catch-finally 이후 → Z 출력

**핵심**

- try에서 예외 발생 시 남은 try 코드를 건너뛴다.
- 일치하는 catch 블록을 실행한다.
- finally 블록을 실행한다.
- 예외가 처리되었다면 이후 코드가 정상 진행된다.

## 11. 예외 클래스 상속 관계와 catch 순서

### 문제

```java
public class Main {
    static String test(int x) {
        try {
            if (x == 1) {
                throw new ArithmeticException();
            } else if (x == 2) {
                throw new NullPointerException();
            } else if (x == 3) {
                throw new RuntimeException();
            }

            return "OK";

        } catch (NullPointerException e) {
            return "NPE";

        } catch (RuntimeException e) {
            return "RE";

        } catch (Exception e) {
            return "EX";
        }
    }

    public static void main(String[] args) {
        System.out.println(test(1));
        System.out.println(test(2));
        System.out.println(test(3));
        System.out.println(test(0));
    }
}
```

### 정답

```text
RE
NPE
RE
OK
```

### 해설

**test(1)**

- ArithmeticException 발생
- RuntimeException을 상속하는 예외
- RuntimeException catch 실행 → RE

**test(2)**

- NullPointerException 발생
- 첫 번째 catch에서 처리 → NPE

**test(3)**

- RuntimeException 발생
- 두 번째 catch에서 처리 → RE

**test(0)**

- 예외 발생하지 않음
- return "OK"

### 예외 상속 관계

```text
Exception
  └── RuntimeException
        ├── ArithmeticException
        └── NullPointerException
```

**핵심**

- catch는 위에서 아래로 검사한다.
- 자식 예외부터 부모 예외 순서로 작성해야 한다.
- 부모 예외를 먼저 작성하면 뒤쪽 자식 예외 catch가 도달 불가능해져 컴파일 오류가 발생할 수 있다.
- RuntimeException은 ArithmeticException과 NullPointerException을 모두 처리할 수 있다.
