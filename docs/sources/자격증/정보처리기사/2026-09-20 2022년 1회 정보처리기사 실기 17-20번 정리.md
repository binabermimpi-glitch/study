# 17. Java 객체 참조와 메서드 호출 🔥🔥

## 문제 코드

```java
class A {
    int a;
    int b;
}

public class Main {

    static void func1(A a) {
        a.a *= 10;
    }

    static void func2(A a) {
        a.a += a.b;
    }

    public static void main(String[] args) {

        A a = new A();
        a.a = 100;

        func1(m);

        a.b = a.a;

        func2(a);

        System.out.println(a.a);
    }
}
```

## 중요 확인

이미지에는 분명히 다음과 같이 되어 있다.

```java
func1(m);
```

따라서 `func1(a)`로 바꾸어 보면 안 된다.

다만 현재 보이는 코드 안에서는 `m`이라는 변수가 선언되어 있지 않다.

즉, 이미지에 보이는 코드가 전부라면:

```text
m이라는 변수를 찾을 수 없음
→ 컴파일 오류
```

가 발생한다.

예:

```text
cannot find symbol
symbol: variable m
```

---

# 만약 앞부분에 `m` 선언이 있었다면?

예를 들어 다음과 같은 코드가 생략되어 있었다고 가정하면:

```java
A m = a;
```

`a`와 `m`은 같은 객체를 가리킨다.

```text
a ─────┐
       ↓
     A 객체
     a = 100
     b = 0
       ↑
m ─────┘
```

그 상태에서:

```java
func1(m);
```

을 호출하면 `func1()`의 매개변수 역시 같은 객체를 가리킨다.

```java
static void func1(A a) {
    a.a *= 10;
}
```

현재 필드값은:

```text
a.a = 100
```

이므로:

```text
100 × 10
= 1000
```

객체:

```text
a = 1000
b = 0
```

다음:

```java
a.b = a.a;
```

따라서:

```text
a = 1000
b = 1000
```

다음:

```java
func2(a);
```

```java
static void func2(A a) {
    a.a += a.b;
}
```

즉:

```text
a.a = a.a + a.b

= 1000 + 1000
= 2000
```

따라서 `m`이 `a`와 같은 객체를 참조하도록 선언되어 있었다면:

```text
출력 = 2000
```

---

# 17번 핵심 개념

Java에서 객체를 메서드에 전달하면 객체 자체가 복사되는 것이 아니라 **참조값이 복사**된다.

```text
main의 참조변수
       ↓
      객체
       ↑
메서드의 매개변수
```

따라서 두 참조변수가 같은 객체를 가리킨다면:

```java
a.a = 1000;
```

처럼 객체의 필드를 변경한 내용은 다른 참조변수에서도 그대로 보인다.

## 핵심

```text
객체 전달
→ 참조값 복사
→ 같은 객체 참조 가능
→ 객체 필드 변경 내용 공유
```

## 17번 결론

```text
현재 이미지 그대로라면
→ m 선언이 보이지 않으므로 컴파일 오류

만약 m = a 등의 선언이 생략되어 있고
m과 a가 같은 객체를 참조한다면
→ 출력 2000
```

# 18. C언어 재귀함수 / 팩토리얼 🔥🔥

## 문제

입력값은 `5`라고 가정한다.

```c
#include <stdio.h>

int func(int i) {
    if(i <= 1)
        return 1;

    return i * func(i - 1);
}

int main() {
    int in;

    scanf("%d", &in);

    printf("%d", func(in));
}
```

## 정답

```text
120
```

---

# 실행 과정

입력:

```text
5
```

따라서:

```c
func(5)
```

가 호출된다.

`func()`를 보면:

```c
if(i <= 1)
    return 1;
```

`i`가 1 이하이면 재귀 호출을 종료한다.

그렇지 않으면:

```c
return i * func(i - 1);
```

을 수행한다.

---

# 재귀 호출 과정

```text
func(5)
= 5 × func(4)

func(4)
= 4 × func(3)

func(3)
= 3 × func(2)

func(2)
= 2 × func(1)

func(1)
= 1
```

이제 거꾸로 돌아온다.

```text
func(2)
= 2 × 1
= 2

func(3)
= 3 × 2
= 6

func(4)
= 4 × 6
= 24

func(5)
= 5 × 24
= 120
```

---

# 팩토리얼

이 함수는 결국:

```text
5 × 4 × 3 × 2 × 1
```

을 계산한다.

즉:

```text
5! = 120
```

이다.

---

# 재귀함수 핵심

재귀함수는 자기 자신을 다시 호출하는 함수이다.

```c
func(i - 1)
```

그리고 반드시 **종료 조건**이 필요하다.

이 코드의 종료 조건:

```c
if(i <= 1)
    return 1;
```

## 핵심

```text
자기 자신 호출
→ 재귀함수

재귀 종료 조건
→ if(i <= 1)
```

# 19. C언어 숫자 뒤집기 / 나머지 연산 🔥🔥

## 문제

```c
#include <stdio.h>

int main() {

    int num = 1234;
    int div = 10;
    int res = 0;

    while(num ① 0) {

        res = res * div;

        res = res + num ② div;

        num = num ③ div;
    }

    printf("%d", res);
}
```

## 정답

```text
① >
② %
③ /
```

완성:

```c
while(num > 0) {

    res = res * div;

    res = res + num % div;

    num = num / div;
}
```

---

# 20. C언어 소수 판별 + 최대 소수 약수 🔥🔥

## 문제

```c
int isPrime(int number) {

    int i;

    for(i = 2; i < number; i++) {

        if(number % i == 0)
            return 0;
    }

    return 1;
}

int main(void) {

    int number = 13195;
    int max_div = 0;
    int i;

    for(i = 2; i < number; i++)

        if(isPrime(i) == 1 && number % i == 0)

            max_div = i;

    printf("%d", max_div);

    return 0;
}
```

## 정답

```text
29
```

---

# 1. isPrime() 함수

```c
int isPrime(int number)
```

숫자가 소수인지 검사하는 함수이다.

---

## 예: `isPrime(5)`

반복:

```c
for(i = 2; i < 5; i++)
```

따라서:

```text
5 % 2 != 0
5 % 3 != 0
5 % 4 != 0
```

어떤 숫자로도 나누어떨어지지 않는다.

따라서:

```c
return 1;
```

즉:

```text
1
→ 소수
```

---

## 예: `isPrime(6)`

```text
6 % 2
= 0
```

2로 나누어떨어진다.

따라서:

```c
return 0;
```

즉:

```text
0
→ 소수가 아님
```

## 기억

```text
isPrime() 결과

1
→ 소수

0
→ 소수 아님
```

---

# 2. main()의 핵심 조건

```c
if(isPrime(i) == 1 && number % i == 0)
```

두 조건을 나누어서 보면 쉽다.

## 첫 번째

```c
isPrime(i) == 1
```

뜻:

```text
i가 소수인가?
```

## 두 번째

```c
number % i == 0
```

뜻:

```text
13195가 i로 나누어떨어지는가?
```

즉:

```text
i가 13195의 약수인가?
```

따라서 전체 조건은:

```text
i가 소수이고
AND
i가 13195의 약수인가?
```

이다.

---

# 13195의 소인수분해

```text
13195 ÷ 5
= 2639
```

```text
2639 ÷ 7
= 377
```

```text
377
= 13 × 29
```

따라서:

```text
13195
= 5 × 7 × 13 × 29
```

소수이면서 13195의 약수인 수는:

```text
5
7
13
29
```

이다.

---

# 왜 최종값이 29인가?

for문은:

```c
for(i = 2; i < number; i++)
```

작은 수부터 큰 수까지 올라간다.

조건을 만족할 때마다:

```c
max_div = i;
```

를 실행한다.

따라서:

```text
i = 5
→ max_div = 5

i = 7
→ max_div = 7

i = 13
→ max_div = 13

i = 29
→ max_div = 29
```

계속 기존 값이 새로운 값으로 덮어써진다.

---

# 29보다 큰 소수는 없나?

29보다 큰 소수는 많다.

예:

```text
31
37
41
43
47
...
```

하지만 중요한 것은:

```text
소수이면서
13195의 약수
```

여야 한다는 것이다.

예를 들어 31은 소수이지만:

```text
13195 % 31 != 0
```

이므로 13195의 약수가 아니다.

따라서 조건:

```c
isPrime(31) == 1
&&
13195 % 31 == 0
```

에서 두 번째가 거짓이다.

그래서:

```c
max_div = 31;
```

은 실행되지 않는다.

결국 **13195의 가장 큰 소수 약수는 29**이다.
