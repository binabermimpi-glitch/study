## 핵심 내용

- 저장장치 핵심 암기: `PV → VG → LV`, RAID 0은 스트라이핑, RAID 1은 미러링, RAID 5는 패리티를 사용한다.
- 사용자 정보는 `/etc/passwd`, 암호 관련 정보는 `/etc/shadow`, 그룹 정보는 `/etc/group`에 연결된다.
- 표준 스트림 번호는 입력 0, 출력 1, 오류 2이며 리다이렉션과 파이프의 용도가 다르다.
- 이후 파일 권한, 디렉터리 구조, 파일 시스템, 프로세스와 패키지 관리 학습이 필요하다.

## 실무 관련성

- Linux 명령어와 표준 입출력은 서버 로그·배포 결과·오류를 확인하는 기본 도구다.
- 환경 변수, 사용자 권한, 프로세스, systemd는 Java/Spring Boot 애플리케이션 운영과 직접 연결된다.
- Linux 역사와 일부 라이선스 세부 구분은 시험 비중이 더 크지만, 라이선스 의무 확인은 실무에서도 중요하다.

## 신뢰도와 주의점

- CentOS의 현재 배포 방식, 부팅 방식, 명령 옵션 등은 환경과 버전에 따라 달라질 수 있다.
- 라이선스는 단순 암기표만으로 실제 배포 의무를 판단하지 말고 해당 버전의 원문을 확인해야 한다.
- `rm`, 사용자 삭제, 파티션·RAID 명령은 실제 시스템에서 데이터 손실 위험이 있으므로 실습 환경에서 주의한다.

## 이해되지 않은 부분과 질문

- 파일 권한의 숫자 표기(`755`, `644`)와 `umask` 계산을 다음 순서로 학습한다.
- 프로세스·서비스·패키지 관리 명령을 Java 애플리케이션 배포 실습과 연결한다.
