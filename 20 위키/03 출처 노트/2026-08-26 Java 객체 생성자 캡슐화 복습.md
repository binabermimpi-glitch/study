# Java 객체·생성자·캡슐화 복습 — 출처 노트

## 세 줄 요약

1. 클래스·객체·참조 변수의 차이와 객체 생성 및 초기화 흐름을 복습했다.
2. 생성자 오버로딩, `this`, 캡슐화와 Getter/Setter를 연결했다.
3. `instanceof`, 가변·불변 객체, identity hash와 실제 주소의 차이를 정리했다.

## 이해가 잘 잡힌 부분

- 클래스와 객체, 참조 변수를 구분한다.
- static과 인스턴스 소속의 차이를 안다.
- String 재대입이 문자열 객체의 내부 변경이 아니라는 점을 안다.
- GC 대상이 즉시 삭제를 의미하지 않음을 안다.

## 보강할 정확한 규칙

- 매개변수 없는 기본 생성자는 **클래스에 생성자를 하나도 선언하지 않았을 때만** 컴파일러가 제공한다.
- 상속이 있으면 부모 클래스 부분의 초기화와 부모 생성자 호출이 자식 생성자 본문보다 먼저 진행된다.
- `this`는 인스턴스 메소드와 생성자의 현재 객체 참조이며 static 문맥에서는 사용할 수 없다.
- Getter와 Setter를 무조건 모두 만드는 것이 캡슐화는 아니다. 필요한 동작만 공개하고 유효한 상태를 지키는 것이 핵심이다.
- `null instanceof SomeType`의 결과는 `false`다.
- `System.identityHashCode()`는 주소가 아니며 서로 다른 객체에서 같은 값이 나올 가능성도 있다.
