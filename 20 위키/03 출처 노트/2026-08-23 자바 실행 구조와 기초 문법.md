## 신뢰도와 주의점

- JVM 메모리 영역은 학습용 모델과 JVM 명세·구현의 실제 구성을 구분해야 한다.
- 객체가 힙에, 모든 지역 변수가 스택에 있다는 설명은 일반적인 입문 모델이며 최적화된 실제 배치는 달라질 수 있다.
- GC의 세대와 영역 이름은 선택한 가비지 컬렉터와 JVM 버전에 따라 달라질 수 있다.
- Oracle JDK와 OpenJDK 계열 배포판은 라이선스와 지원 정책을 사용 시점에 다시 확인해야 한다.
- Java 25의 간소화된 `IO` API는 해당 JDK에서 사용 가능 조건과 언어 모드를 공식 문서로 확인하기 전까지 일반 Java 코드의 기본 방식으로 간주하지 않는다.
- 경로에 공백이나 한글이 있다고 항상 오류가 발생하는 것은 아니다. 호환성이 낮은 일부 도구를 피하기 위한 예방적 권장사항으로 이해한다.
