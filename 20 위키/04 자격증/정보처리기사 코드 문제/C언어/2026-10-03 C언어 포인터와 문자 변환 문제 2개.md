# C언어 포인터 + 문자 변환 문제 2문제 정리

# 1. 대소문자 반전 + 숫자 변환

## 문제

다음 C 프로그램의 실행 결과를 작성하시오.

```c
#include <stdio.h>
#include <string.h>

void change(char *p) {

    if (*p >= 'A' && *p <= 'Z') {
        *p = *p + ('a' - 'A');
    }
    else if (*p >= 'a' && *p <= 'z') {
        *p = *p - ('a' - 'A');
    }
    else if (*p >= '0' && *p <= '9') {
        *p = '9' - (*p - '0');
    }
}

int main() {

    char str[] = "Ab3xY8";
    int i = 0;

    while (i < strlen(str)) {
        change(&str[i]);
        i++;
    }

    printf("%s", str);

    return 0;
}
```

## 핵심 개념

```c
change(&str[i]);
```

`str[i]`
→ 현재 문자 값

`&str[i]`
→ 현재 문자가 저장된 주소

예를 들어

```c
str[0]
```

은

```text
'A'
```

이고,

```c
&str[0]
```

은

```text
str 배열의 0번째 요소 'A'가 저장된 주소
```

이다.

따라서

```c
change(&str[0]);
```

은

```text
0의 주소를 넘기는 것이 아니다.

str[0]이라는 첫 번째 문자의 주소를 넘기는 것이다.
```

함수에서는

```c
void change(char *p)
```

로 주소를 받는다.

여기서

```text
p  → 주소
*p → 그 주소에 저장된 실제 값
```

이다.

# 2. 문자 위치에 따른 이동

## 문제

다음 C 프로그램의 실행 결과를 작성하시오.

```c
#include <stdio.h>
#include <string.h>

void convert(char *p, int n) {

    if (*p >= 'A' && *p <= 'Z') {
        *p = (*p - 'A' + n) % 26 + 'A';
    }
    else if (*p >= '0' && *p <= '9') {
        *p = (*p - '0' + n) % 10 + '0';
    }
}

int main() {

    char str[] = "A7C8Z";
    int i = 0;

    while (i < strlen(str)) {

        convert(&str[i], i);

        i++;
    }

    printf("%s", str);

    return 0;
}
```

## 핵심 개념

```c
convert(&str[i], i);
```

여기서는 두 개의 값을 전달한다.

```text
&str[i]
→ 현재 문자의 주소

i
→ 현재 배열의 위치 번호
```

즉,

```text
i = 0 → 0칸 이동
i = 1 → 1칸 이동
i = 2 → 2칸 이동
i = 3 → 3칸 이동
i = 4 → 4칸 이동
```

한다.

초기 문자열

```text
A 7 C 8 Z
```

---

## 실행 과정

### i = 0

```c
convert(&str[0], 0);
```

```text
str[0] = 'A'
```

계산

```c
(*p - 'A' + n) % 26 + 'A'
```

대입하면

```c
('A' - 'A' + 0) % 26 + 'A'
```

```text
'A' - 'A' = 0

0 + 0 = 0

0 % 26 = 0
```

따라서

```text
A → A
```

현재 문자열

```text
A 7 C 8 Z
```

---

### i = 1

```c
convert(&str[1], 1);
```

```text
str[1] = '7'
```

숫자이므로

```c
(*p - '0' + n) % 10 + '0'
```

계산

```c
('7' - '0' + 1) % 10 + '0'
```

```text
'7' - '0' = 7

7 + 1 = 8

8 % 10 = 8
```

따라서

```text
7 → 8
```

현재 문자열

```text
A 8 C 8 Z
```

---

### i = 2

```c
convert(&str[2], 2);
```

```text
str[2] = 'C'
```

계산

```c
('C' - 'A' + 2) % 26 + 'A'
```

알파벳을 숫자로 생각하면

```text
A = 0
B = 1
C = 2
D = 3
E = 4
```

따라서

```text
'C' - 'A' = 2

2 + 2 = 4

4 % 26 = 4
```

결과

```text
C → E
```

현재 문자열

```text
A 8 E 8 Z
```

---

```c
convert(&str[3], 3);
```

```text
str[3] = '8'
```

계산

```c
('8' - '0' + 3) % 10 + '0'
```

```text
'8' - '0' = 8

```

따라서

```text
8 → 1
```

현재 문자열


결과

# 포인터 핵심 정리

```c
char ch = 'A';
char *p = &ch;
```

의미

```text
ch
→ 문자 값 'A'

&ch
→ ch의 주소

p
→ ch의 주소를 저장

*p
→ p가 가리키는 주소에 저장된 실제 값 'A'
```

따라서

```c
char *p
```

는

```text
p는 char형 데이터를 가리키는 포인터 변수
```

라고 해석한다.

또한

```c
change(&str[0]);
```

에서

```text
str[0]
→ 첫 번째 문자의 값

&str[0]
→ 첫 번째 문자가 저장된 주소
```

이다.

절대로

```text
&str[0] = 숫자 0의 주소
```

가 아니다.

정확하게는

```text
&str[0]
= str 배열의 0번째 요소의 주소
```

이다.

시험에서 기억할 핵심

```text
& = 주소를 구한다.

* = 그 주소에 저장된 값을 가져온다.

주소를 함수에 넘기면
함수 내부에서 원본 값을 직접 변경할 수 있다.
```
