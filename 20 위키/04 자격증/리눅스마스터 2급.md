# 4. 오픈소스 라이선스

대표적인 오픈소스 라이선스

* GPL
* LGPL
* MPL
* BSD License
* Apache License

오픈소스 라이선스는 일반적으로 소스코드를 이용, 수정, 배포할 수 있다.

주의:
오픈소스라고 해서 반드시 무료라는 의미는 아니다.
오픈소스 소프트웨어도 판매할 수 있다.

## GPL

강한 Copyleft 라이선스

GPL 코드로 만든 파생 저작물을 배포할 경우 GPL 조건을 따라야 한다.

독점 소프트웨어와 결합할 때 제약이 크다.

## LGPL

GPL보다 약한 Copyleft 라이선스

주로 라이브러리에 사용된다.

일정 조건에서 상용 또는 독점 소프트웨어와 결합할 수 있다.

## MPL

파일 단위 Copyleft 라이선스

MPL이 적용된 파일을 수정하면 해당 파일에 MPL 조건이 적용된다.

다른 파일까지 전부 공개하도록 요구하는 방식은 아니다.

## BSD License

허용적인 라이선스

수정, 배포, 상업적 이용, 독점 소프트웨어와 결합 가능

## Apache License

허용적인 라이선스

수정, 배포, 상업적 이용, 독점 소프트웨어와 결합 가능

특허 관련 조항이 포함되어 있다는 특징이 있다.

### 정리

| 라이선스   | Copyleft | 독점 SW 결합 |
| ------ | -------- | -------- |
| GPL    | 강함       | 제한적      |
| LGPL   | 약함       | 가능       |
| MPL    | 파일 단위    | 가능       |
| BSD    | 거의 없음    | 가능       |
| Apache | 거의 없음    | 가능       |

# 5. 파티션

파티션은 하나의 물리적인 디스크를 논리적으로 나누는 것이다.

MBR 방식에서는 다음과 같은 파티션이 있다.

* Primary Partition(주 파티션)
* Extended Partition(확장 파티션)
* Logical Partition(논리 파티션)

## Primary Partition

주 파티션

MBR에서는 최대 4개의 Primary Partition을 만들 수 있다.

## Extended Partition

논리 파티션을 만들기 위한 확장 영역

## Logical Partition

Extended Partition 내부에 생성하는 파티션

예:

/dev/sda
→ 디스크

/dev/sda1
→ 첫 번째 파티션

/dev/sda2
→ 두 번째 파티션

# 7. RAID

RAID는 여러 디스크를 묶어서 성능 또는 안정성을 높이는 기술이다.

## RAID 0

Striping

데이터를 여러 디스크에 나누어 저장

### 장점

* 속도가 빠름
* 디스크 공간 활용도가 높음

### 단점

* 하나의 디스크가 고장 나면 전체 데이터 손실 가능

## RAID 1

Mirroring

같은 데이터를 여러 디스크에 복제해서 저장

### 장점

* 안정성이 높음

### 단점

* 저장 공간 효율이 낮음

## RAID 5

Striping + Parity

최소 3개의 디스크 필요

하나의 디스크가 고장 나더라도 Parity 정보를 이용하여 복구 가능

### 암기

RAID 0 → Striping
RAID 1 → Mirroring
RAID 5 → Parity

# 20. 리다이렉션

리다이렉션은 명령어의 입력 또는 출력을 파일과 연결하는 기능이다.

## >

표준 출력을 파일에 저장

기존 파일 내용은 덮어쓴다.

예:

ls > list.txt

ls 출력 결과가 list.txt에 저장된다.

## >>

표준 출력을 파일 뒤에 추가

예:

ls >> list.txt

기존 내용을 유지하면서 새로운 결과가 추가된다.

## <

파일 내용을 명령어의 입력으로 사용

예:

sort < list.txt

## 2>

표준 오류를 파일에 저장

예:

find /test 2> error.txt

## 2>>

표준 오류를 기존 파일 뒤에 추가

## /dev/null

출력을 버릴 때 사용

예:

command > /dev/null

에러 출력만 버리기

command 2> /dev/null

### 리다이렉션 정리

| 기호        | 의미          |
| --------- | ----------- |
| >         | 출력 덮어쓰기     |
| >>        | 출력 추가       |
| <         | 파일을 입력으로 사용 |
| 2>        | 오류 출력 저장    |
| 2>>       | 오류 출력 추가    |
| /dev/null | 출력 폐기       |

# 22. 정규표현식

grep 등과 함께 자주 사용된다.

| 표현    | 의미             |
| ----- | -------------- |
| .     | 임의의 한 문자       |
| ^     | 행의 시작          |
| $     | 행의 끝           |
| *     | 앞 문자의 0회 이상 반복 |
| []    | 문자 집합          |
| [^]   | 지정 문자 제외       |
| [0-9] | 숫자             |
| [a-z] | 소문자            |
| [A-Z] | 대문자            |

## 예제

grep '^root' /etc/passwd

→ root로 시작하는 줄 검색

grep 'bash$' /etc/passwd

→ bash로 끝나는 줄 검색

grep '[0-9]' file.txt

→ 숫자가 포함된 줄 검색

grep '^$' file.txt

→ 빈 줄 검색

이유:

^ = 행의 시작
$ = 행의 끝

시작과 끝 사이에 아무 문자도 없으므로 빈 줄을 의미한다.

## 국비수업·백엔드 연결

- 기본 명령어, 파일 검색, 리다이렉션과 파이프는 서버 로그 확인과 장애 분석의 기초다.
- 사용자·그룹 관리는 애플리케이션 실행 계정과 파일 접근 권한을 이해하는 데 연결된다.
- 환경 변수는 Java 및 Spring Boot 설정값, 데이터베이스 접속 정보, 실행 프로필을 외부에서 주입할 때 사용한다.
- 프로세스·패키지·네트워크·systemd는 이후 Java 애플리케이션을 Linux 서버에 배포하고 운영할 때 실무 핵심이 된다.
