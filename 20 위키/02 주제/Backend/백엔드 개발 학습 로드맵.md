# 백엔드 개발 학습 로드맵

## 이 주제에서 얻게 될 것

지금 배우는 기술이 전체 백엔드 개발 과정에서 어디에 위치하고 다음에 무엇으로 이어지는지 파악한다.

## 전체 그림

1. **Java 기초**: 문법, 자료형, 객체지향과 표준 라이브러리
2. **Database**: SQL, 데이터 모델링, 트랜잭션
3. **Web**: HTTP, REST, 요청과 응답, 인증과 인가
4. **Spring**: Spring Boot, MVC, 데이터 접근, 테스트
5. **Backend 통합**: API와 데이터베이스를 연결한 프로젝트
6. **운영**: Linux, Git, 빌드, Docker, CI/CD, 모니터링

## 현재 위치

현재 자료는 1단계인 Java 기초에 해당한다. [[20 위키/02 주제/Java/자바 참조와 자료형 기초 학습 지도]]부터 학습한다.

## AI를 사용할 때의 원칙

- 먼저 입력, 출력, 예외 상황과 완료 조건을 설명한다.
- 생성된 코드를 직접 실행하고 결과를 확인한다.
- 이해하지 못한 코드는 그대로 제출하거나 프로젝트에 넣지 않는다.
- 오류의 원인, 시도, 해결과 검증 결과를 기록한다.
- 정확성뿐 아니라 보안, 예외 처리와 유지보수 가능성도 확인한다.

## 취업을 위한 기록

- 학습 기록: 핵심 개념, 헷갈린 점, 질문과 답
- 실습 기록: 목표, 코드, 실행 결과, 오류와 해결 과정
- 프로젝트 기록: 역할, 기술 선택 이유, 기여 기능, 문제 해결과 결과
- 채용공고 분석: 반복해서 등장하는 기술과 자신의 프로젝트 경험을 연결

## 실무 연결

Java나 Spring 문법을 아는 것만으로는 부족하다. 요구사항을 데이터 모델과 API로 바꾸고, 테스트·배포·운영까지 연결하는 능력이 백엔드 실무의 목표다.
