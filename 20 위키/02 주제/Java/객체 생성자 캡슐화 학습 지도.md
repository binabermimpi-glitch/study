## 하나의 코드로 연결하기

```java
public class Person {
    private String name;
    private int age;

    public Person(String name, int age) {
        this.name = name;
        changeAge(age);
    }

    public void changeAge(int age) {
        if (age < 0) {
            throw new IllegalArgumentException("나이는 음수일 수 없습니다.");
        }
        this.age = age;
    }

    public int getAge() {
        return age;
    }
}
```

## 복습 문제

1. 생성자를 하나 선언하면 컴파일러가 `Person()`을 자동으로 추가하는가?
2. `this.name = name`에서 양쪽 `name`은 각각 무엇인가?
3. Setter 대신 `changeAge()` 같은 이름을 사용하면 어떤 장점이 있는가?
4. `String` 재대입과 Mutable 객체의 필드 변경은 어떻게 다른가?
5. `null instanceof Person`의 결과는 무엇인가?
