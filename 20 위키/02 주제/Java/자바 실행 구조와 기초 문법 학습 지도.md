## 연결해서 이해하기

```text
IntelliJ에서 JDK 선택
  → javac가 .java를 .class로 컴파일
  → JVM이 클래스를 로딩하고 main 실행
  → 메소드 호출마다 지역 변수의 유효 범위 생성
  → new로 객체 생성
  → 도달할 수 없게 된 객체는 GC 회수 후보
```

## 복습 질문

1. JDK의 `bin`에는 어떤 명령이 있고 각각 무엇을 하는가?

3. 참조가 사라진 객체가 즉시 삭제된다고 말하면 왜 부정확한가?
4. 프로젝트 SDK와 Language Level의 역할은 어떻게 다른가?
5. 기본형을 객체로 다뤄야 할 때 무엇을 사용하는가?
