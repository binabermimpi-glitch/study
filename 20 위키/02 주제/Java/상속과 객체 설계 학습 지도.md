# 상속과 객체 설계 학습 지도

## 학습 흐름

1. 가변 배열과 복사를 통해 참조 객체의 연결과 변경 영향을 이해한다.
2. String Pool과 ==·equals()의 역할을 구분한다.
3. 절차 순서가 아니라 객체의 책임을 기준으로 클래스를 나눈다.
4. 인터페이스의 규약과 추상 클래스의 공통 구현을 구분한다.
5. 상속·구현·다형성을 연결하고 상속과 합성을 선택한다.
6. final·sealed와 중첩 클래스로 타입 구조와 사용 범위를 제어한다.

## 꼭 설명할 수 있어야 하는 것

- 가변 배열 생성 직후 각 행이 왜 null인지
- 배열 참조 대입과 Arrays.copyOf()의 차이
- 문자열 내용 비교에 equals()를 쓰는 이유
- 클래스 단일 상속과 인터페이스 다중 구현의 차이
- 인터페이스와 추상 클래스를 선택하는 기준
- is-a 관계에는 상속, has-a 관계에는 합성을 검토하는 이유

## 국비수업 연결

가위바위보 예제의 입력·선택 생성·판정·실행을 Player, Computer, Referee, GameMain 책임으로 나눈다. 하나의 클래스가 모든 일을 처리하면 변경 이유가 많아지므로 단일 책임 원칙을 검토한다.
