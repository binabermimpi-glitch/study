## 국비수업과 연결

- SQL의 `CREATE TABLE`, 기본키와 외래키를 배울 때 키·무결성 문서를 실습과 연결한다.
- 테이블 설계 실습에서는 ER 다이어그램 → 관계 스키마 → SQL 생성 순서로 적용한다.
- Spring Data JPA에서는 엔터티와 관계 매핑이 데이터 모델과 어떻게 대응하는지 연결한다.

## 시험과 실무의 차이

- 시험: 용어 정의, 정규형 판별, 관계대수 기호와 기출 표현을 정확히 암기
- 실무: 요구사항을 빠뜨리지 않고 모델링하며 무결성·성능·변경 가능성을 함께 판단

## 다음 실습

쇼핑몰의 `고객`, `상품`, `주문`, `주문항목`을 ER 모델로 그리고 기본키·외래키를 표시한다.
