# 개념 문서

하나의 용어나 원리를 영역별로 저장합니다.

- `Java/`: 문법, 객체지향, 컬렉션, 예외, 제네릭, 스트림, JVM
- `Spring/`: IoC·DI, Spring Boot, MVC, JPA, Security, Spring 테스트
- `Web/`: HTTP, REST, 쿠키, 세션, 인증과 인가
- `Database/`: SQL, 데이터 모델링, 정규화, 인덱스, 트랜잭션
- `CS/`: 자료구조, 알고리즘, 운영체제, 네트워크
- `Tools/`: Git, Gradle, IntelliJ, Docker와 개발 도구

여러 영역과 관련된 개념은 중심 영역에 한 번만 만들고 다른 문서에서 링크합니다.
