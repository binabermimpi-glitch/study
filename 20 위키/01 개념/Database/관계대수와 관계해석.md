# 관계대수와 관계해석

## 차이

- 관계대수: 원하는 결과를 얻는 처리 절차를 연산으로 표현하는 절차적 방식
- 관계해석: 원하는 결과의 조건을 선언하는 비절차적 방식

## 관계대수 연산

| 구분 | 연산 |
|---|---|
| 일반 집합 연산 | 합집합, 교집합, 차집합, 카티션 프로덕트 |
| 순수 관계 연산 | 셀렉트, 프로젝트, 조인, 디비전 |

- 셀렉트: 조건을 만족하는 튜플 선택
- 프로젝트: 지정한 속성 선택
- 조인: 관련 조건으로 릴레이션 결합
- 디비전: `모든` 조건을 만족하는 대상을 찾는 유형

## 국비수업 연결

SQL에서 `WHERE`는 셀렉트, 조회 칼럼 목록은 프로젝트, `JOIN`은 관계대수의 조인과 연결해 이해할 수 있다.
