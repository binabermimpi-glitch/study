# 관계 데이터 모델 기본 용어

| 용어 | 뜻 | 테이블 관점의 비유 |
|---|---|---|
| 릴레이션 | 관계 데이터의 구조 | 테이블 |
| 튜플 | 하나의 데이터 묶음 | 행 |
| 속성 | 데이터의 항목 | 열 |
| 도메인 | 속성이 가질 수 있는 값의 집합 | 타입과 허용 범위 |
| 차수 | 속성의 개수 | 열 개수 |
| 카디널리티 | 튜플의 개수 | 행 개수 |

## 릴레이션의 이론적 특성

- 튜플은 중복되지 않는다.
- 튜플과 속성의 순서에는 의미가 없다.
- 속성 값은 관계 모델 관점에서 원자값을 가진다.

실제 SQL 테이블은 중복 행을 허용할 수 있고 출력 순서도 `ORDER BY` 없이는 보장되지 않으므로 이론적 릴레이션과 SQL 구현을 구분한다.

## 시험 암기

- 차수 = 열의 수
- 카디널리티 = 행의 수
