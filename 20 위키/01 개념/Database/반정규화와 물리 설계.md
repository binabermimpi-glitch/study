# 반정규화와 물리 설계

## 반정규화

정규화된 모델에서 측정된 성능 문제를 해결하기 위해 데이터 중복, 테이블 통합이나 계산값 저장 등을 의도적으로 허용하는 설계다. 무조건 빠르게 만드는 기법이 아니며 무결성 유지 비용과 데이터 불일치 위험이 증가한다.

## 인덱스

검색을 빠르게 할 수 있는 보조 자료구조다. 읽기 성능을 높일 수 있지만 저장 공간과 쓰기 작업의 유지 비용이 생긴다. 테이블 크기, 선택도, 데이터 분포와 실제 실행 계획을 보고 결정한다.

## 뷰

질의를 이름 붙여 테이블처럼 사용할 수 있게 한 논리적 객체다. 보안, 질의 단순화와 호환성에 활용한다. 생성 옵션은 DBMS마다 다르므로 제품 문서를 확인한다.

## 국비수업 연결

SQL 실행 계획과 실제 측정을 배우기 전에는 `인덱스가 있으면 항상 빠르다`, `정규화를 낮추면 항상 빠르다`처럼 단정하지 않는다.
