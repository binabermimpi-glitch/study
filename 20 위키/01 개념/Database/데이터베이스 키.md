# 데이터베이스 키

## 핵심 특성

- 유일성: 각 튜플을 서로 구별할 수 있다.
- 최소성: 식별에 불필요한 속성을 제거해도 유일성이 유지되면 안 된다.

| 종류 | 조건 |
|---|---|
| 슈퍼키 | 유일성 만족 |
| 후보키 | 유일성과 최소성 만족 |
| 기본키 | 후보키 중 대표로 선택 |
| 대체키 | 기본키로 선택하지 않은 후보키 |
| 외래키 | 다른 릴레이션의 키를 참조해 관계 표현 |

## 주의할 예시

고객 이름이나 주소는 중복될 수 있으므로 그 자체로 후보키라고 가정하면 안 된다. 실제 데이터 규칙에서 유일성과 최소성을 보장하는지 확인해야 한다.

## 국비수업 연결

SQL의 `PRIMARY KEY`, `UNIQUE`, `FOREIGN KEY` 제약과 Spring/JPA의 식별자 매핑에서 직접 사용한다.
