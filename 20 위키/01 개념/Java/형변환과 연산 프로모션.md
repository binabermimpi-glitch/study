# 형변환과 연산 프로모션

## 한 문장 설명

형변환은 값을 다른 타입으로 바꾸는 것이고, 연산 프로모션은 Java가 연산을 위해 작은 숫자 타입을 더 큰 타입으로 올리는 규칙이다.

```java
int number = 10;
double widened = number;       // 자동 변환

double decimal = 123.45;
int narrowed = (int) decimal;  // 명시적 변환, 소수 부분 손실
```

## 흔한 실수

- 강제 형변환이 값을 안전하게 만들어 준다고 생각한다.
- `byte`와 `short`의 산술 연산 결과가 일반적으로 `int`로 승격되는 점을 놓친다.
- 큰 값이나 소수 값을 작은 타입으로 바꿀 때 생기는 손실을 확인하지 않는다.

## 실무에서는 어떻게 쓰이나

API 입력값, 계산, 데이터베이스 값 변환에서 계속 등장한다. 금액처럼 정확성이 중요한 계산은 부동소수점 타입 대신 별도의 적절한 타입을 검토한다.
