# 클래스와 접근 제한자

## 한 문장 설명

클래스는 객체가 가질 상태와 동작을 정의하며, 접근 제한자는 그 구성요소를 어디에서 사용할 수 있는지 정한다.

## 구성요소

- 필드: 객체의 상태
- 메소드: 객체의 동작
- 생성자: 객체 생성 시 초기화

## 접근 범위

| 제한자 | 접근 가능 범위 |
|---|---|
| `public` | 모든 위치 |
| `protected` | 같은 패키지 및 상속 관계의 하위 클래스 |
| 제한자 없음 | 같은 패키지 |
| `private` | 선언한 클래스 내부 |

## 주의할 점

제한자를 생략한 상태를 흔히 `default` 접근이라고 부르지만 `default`라는 키워드를 적는 것은 아니다.

다른 패키지의 하위 클래스에서 `protected` 멤버에 접근하는 규칙에는 제약이 있다. 단순히 “상속 관계이면 어디서나 접근 가능”으로 외우지 말고 상속받은 자기 객체를 통한 접근인지 확인한다.

## 실무에서는 어떻게 쓰이나

필요한 기능만 공개하고 내부 구현을 감추는 캡슐화의 기본 도구다. Spring의 Controller, Service, Repository 클래스 구조를 읽기 전 반드시 익혀야 한다.
