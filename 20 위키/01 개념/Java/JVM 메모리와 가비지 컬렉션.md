# JVM 메모리와 가비지 컬렉션

## 자바 실행 구조와 기초 문법

### 힙과 가비지 컬렉션

> 힙은 객체가 동적으로 생성되는 메모리 영역이며, 가비지 컬렉터는 더 이상 사용되지 않는 객체를 식별하고 회수합니다.

스택은 메서드 호출에 따라 생성되고 종료되는 고정적인 호출 영역입니다. 반면 힙은 객체 생성과 사용량 변화에 대응하는 동적 메모리 영역으로, 프로그램 실행 중 객체가 생성되는 주요 공간입니다.

객체를 `new`로 생성하면 객체 본체는 힙에 생성되고, 객체를 가리키는 참조값은 변수의 위치에 저장됩니다. 지역 참조 변수는 대체로 스택 프레임에서 관리되며, 객체가 더 이상 참조되지 않으면 가비지 컬렉션 대상이 됩니다.

가비지 컬렉션은 객체를 즉시 완전 삭제하는 단순 동작이 아니라, 객체 생명주기와 메모리 세대별 상태를 고려하여 회수합니다. 객체 생성 직후의 영역과 오래 유지된 객체 영역을 구분하는 개념이 대표적입니다.

- `Eden` 영역은 새로 생성된 객체가 우선 배치되는 영역입니다.
- `Old` 영역은 장기간 생존한 객체가 관리되는 영역입니다.
- 가비지 컬렉터는 참조되지 않는 객체를 찾아 메모리 회수 후보로 처리합니다.
- 프로그램 종료 시 JVM 자체의 실행 메모리도 운영체제에 반환됩니다.

메모리 누수는 더 이상 필요하지 않은 객체가 참조를 유지하여 회수되지 못하는 상황과 관련됩니다. 서버처럼 장시간 실행되고 동시 요청이 많은 환경에서는 힙 사용량과 가비지 컬렉션 동작을 관찰하는 것이 성능 관리의 핵심이 됩니다.


## 자바 메서드와 연산자 기초

### JVM과 정적 영역
JVM은 운영체제가 제공하는 가상 주소 공간에서 자바 실행 환경을 구성하며, 클래스와 static 멤버는 클래스 로딩 시점에 정적 영역과 연관되어 관리됩니다.

자바 프로그램은 운영체제 위에서 JVM을 실행 환경으로 사용합니다. JVM은 물리 메모리를 직접 관리하는 주체가 아니라, 운영체제가 제공하는 가상 메모리와 프로세스 실행 환경을 바탕으로 자바 애플리케이션의 메모리 구조를 구성합니다.

운영체제는 프로세스의 가상 주소 공간, 실제 RAM과 페이지 파일의 매핑, 프로세스별 실행 공간 등을 관리합니다. 따라서 가상 메모리 부족이나 페이지 파일 설정은 JVM만의 문제가 아니라 운영체제 메모리 관리와 관련된 문제입니다.

자바 학습 단계에서는 JVM 메모리를 크게 정적 영역, 스택 영역, 힙 영역으로 구분해 이해할 수 있습니다. 실제 JVM 명세와 구현은 더 복잡하지만, 클래스와 정적 멤버의 공용성 및 객체의 동적 생성 구조를 파악하는 데 이 구분이 유용합니다.

static 멤버는 클래스에 소속되며, 인스턴스를 생성하지 않아도 클래스 이름을 통해 접근할 수 있습니다.
힙 영역은 객체와 배열처럼 실행 중 생성되는 데이터를 저장하는 영역으로 이해할 수 있습니다.
스택 영역은 메서드 호출 흐름과 지역 변수의 생명 주기를 이해하는 데 사용하는 영역입니다.
메서드 실행이 끝난 뒤 더 이상 참조되지 않는 객체는 가비지 컬렉션의 대상이 될 수 있습니다.
static 멤버를 선언과 동시에 주소가 연결된 상태라고 설명할 때 바인드라는 표현을 사용합니다. 이러한 정적 멤버는 클래스 차원에서 공용으로 사용되며, 호출 시 해당 멤버의 주소를 찾아 실행하는 과정을 바인딩으로 이해할 수 있습니다.



## 자바 메소드와 객체 생성

### JVM 가상 메모리와 프로세스

> JVM은 물리 RAM을 직접 점유, 관리하지 않으며, 운영체제가 각 JVM 프로세스에 할당한 독립적 가상 주소 공간에서 실행됩니다.

운영체제는 물리 메모리와 페이지 파일의 매핑을 관리합니다. JVM은 운영체제로부터 확보한 가상 주소 공간을 힙, 스택, 클래스 관련 영역 등 실행 메모리 용도로 사용합니다. 따라서 JVM이 실행될 때마다 실제 RAM 영역을 별도로 생성한다는 표현은 정확하지 않습니다.

하나의 자바 클래스를 실행하면 하나의 JVM 프로세스가 동작하며, 여러 프로그램을 실행하면 각각 별도의 JVM 프로세스와 가상 주소 공간이 만들어집니다. 각 프로세스의 주소는 서로 독립적이며, 이 실행 상태는 운영체제가 관리합니다.

| 구분 | 관리 주체 | 역할 |
|---|---|---|
| 물리 메모리(RAM) | 운영체제 | 실제 메모리 자원을 관리합니다. |
| 페이지 파일 | 운영체제 | 물리 메모리 부족 상황에서 보조 공간으로 활용됩니다. |
| JVM 가상 주소 공간 | 운영체제 할당, JVM 사용 | JVM별 힙, 스택 등의 실행 공간으로 사용됩니다. |
| JVM 프로세스 | 운영체제 | 실행 중인 자바 프로그램 단위로 관리됩니다. |

JVM 메모리 구조를 이해할 때는 “RAM은 OS가 관리하고, JVM은 OS가 제공한 독립적 가상 공간을 사용한다”는 관점이 핵심입니다. JVM 내부에는 힙, 스택, 클래스 관련 영역, 문자열 풀 등 다양한 세부 구조가 존재합니다.
