# 래퍼 클래스와 박싱

## 자바 실행 구조와 기초 문법

### 자료형과 형 변환

> 자바 자료형은 값 자체를 저장하는 기본형과 객체 주소를 저장하는 참조형으로 나뉘며, 타입 크기에 따라 묵시적 또는 명시적 형 변환이 발생합니다.

기본형은 논리형, 문자형, 정수형, 실수형으로 구성됩니다. 참조형은 배열, 클래스, 문자열 객체 등 객체의 주소를 저장하는 타입입니다. `String`은 클래스이므로 참조형이지만 리터럴 형태로 편리하게 사용할 수 있습니다.

| 분류 | 주요 타입 | 크기 또는 특성 |
|---|---|---|
| 정수형 | `byte`, `short`, `int`, `long` | 각각 1, 2, 4, 8바이트를 사용합니다. |
| 실수형 | `float`, `double` | 각각 4, 8바이트를 사용합니다. |
| 논리, 문자형 | `boolean`, `char` | 논리값과 유니코드 문자 값을 표현합니다. |
| 참조형 | 배열, 클래스, `String` | 객체가 저장된 메모리 위치를 참조합니다. |

작은 범위의 타입에서 큰 범위의 타입으로 변환하는 과정은 프로모션 또는 업캐스팅입니다. 예를 들어 `byte` 값을 `int` 변수에 대입하는 경우 값 표현 범위가 넓어지므로 일반적으로 자동 변환이 가능합니다.

큰 범위의 타입을 작은 범위로 변환하는 과정은 디모션 또는 다운캐스팅입니다. 데이터 손실 가능성이 있으므로 개발자가 변환 의도를 명시해야 합니다.

```java
byte small = 10;
int promoted = small;

int number = 100;
byte demoted = (byte) number;
```

래퍼 클래스는 기본형 값을 객체로 다룰 수 있게 하는 클래스입니다. `int`에는 `Integer`, `double`에는 `Double`, `boolean`에는 `Boolean` 등이 대응합니다. 기본형을 래퍼 객체로 바꾸는 과정을 박싱, 반대 과정을 언박싱이라고 합니다.
