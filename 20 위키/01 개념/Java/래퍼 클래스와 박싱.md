# 래퍼 클래스와 박싱

## 한 문장 설명

래퍼 클래스는 기본형 값을 객체 형태로 다루게 하며, 기본형에서 래퍼 객체로 바꾸는 것을 박싱, 반대를 언박싱이라고 한다.

| 기본형 | 래퍼 클래스 |
|---|---|
| `int` | `Integer` |
| `long` | `Long` |
| `double` | `Double` |
| `boolean` | `Boolean` |
| `char` | `Character` |

```java
Integer boxed = 10; // 오토박싱
int value = boxed;  // 오토언박싱
```

## 왜 필요한가

제네릭과 컬렉션에는 기본형을 타입 인자로 직접 사용할 수 없으므로 `List<Integer>`처럼 래퍼 클래스를 사용한다. 래퍼 객체는 기본형과 달리 `null`일 수도 있다.

## 흔한 실수

- `null`인 래퍼 객체를 자동 언박싱하여 예외가 발생한다.
- 래퍼 객체의 동일성을 `==`로 비교한다.
- 반복 계산에서 불필요한 박싱과 언박싱 비용을 만든다.
