# 가변 객체와 불변 객체

## 차이

- 가변 객체: 생성 후 내부 상태가 바뀔 수 있다.
- 불변 객체: 생성 후 관찰 가능한 내부 상태가 바뀌지 않는다.

```java
Human human = new Human("hong");
human.setName("홍길동"); // 같은 Human의 상태 변경

String text = "hello";
text = "bye"; // 기존 String 수정이 아니라 다른 String 참조
```

## 왜 중요한가

불변 객체는 공유해도 상태가 예상치 못하게 바뀌지 않아 추론과 동시성 관리가 쉬워진다. 가변 객체는 상태 변경이 필요할 때 유용하지만 변경 규칙을 캡슐화해야 한다.

## identity와 주소

`System.identityHashCode(object)`는 객체 identity 기반 해시 코드이지 메모리 주소가 아니다. 동일 객체에는 같은 실행 중 같은 값이 반환되지만, 서로 다른 객체가 같은 정수 값을 가질 가능성은 있다. 두 참조가 같은 객체를 가리키는지는 `==`로 비교한다.
