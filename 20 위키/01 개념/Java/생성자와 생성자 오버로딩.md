# 생성자와 생성자 오버로딩

## 핵심 규칙

- 생성자 이름은 클래스 이름과 같다.
- 반환형을 적지 않는다. `void`도 적지 않는다.
- 매개변수 목록을 다르게 하여 오버로딩할 수 있다.
- 생성자는 상속되지 않는다.
- 생성자의 첫 문장에는 다른 생성자를 호출하는 `this(...)` 또는 부모 생성자를 호출하는 `super(...)`가 올 수 있다.

## 기본 생성자 주의

클래스에 생성자를 **하나도 선언하지 않았을 때만** 컴파일러가 매개변수 없는 기본 생성자를 제공한다.

```java
class Person {
    Person(String name) {}
}

// new Person(); // 컴파일 오류: 자동 기본 생성자가 생기지 않음
```

## 실무 연결

생성자는 객체가 처음부터 유효한 상태를 갖게 만드는 장소다. Spring에서도 생성자 주입을 통해 객체가 필요한 의존성을 전달받는다.
