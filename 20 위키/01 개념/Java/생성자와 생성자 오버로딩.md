# 생성자와 생성자 오버로딩

## Java 객체 생성자 캡슐화 복습

### 3. 생성자와 생성자 오버로딩

```java
class Person {
    Person() { }
    Person(String name) { }
    Person(String name, int age) { }
}
```

- 생성자는 클래스 이름과 같고 반환형을 적지 않는다.
- 객체 생성 과정에서 호출된다.
- 같은 클래스 안에 생성자를 여러 개 선언할 수 있다.
- 생성자 오버로딩은 매개변수의 개수·타입·순서가 달라야 한다.
- 호출할 때 전달한 인자에 맞는 생성자를 Java가 선택한다.

```java
new Person();
new Person("철수");
new Person("철수", 20);
```
