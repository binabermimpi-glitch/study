# 참조와 점 연산자

## 2026-08-23 자바 참조와 자료형 기초

### 참조와 점 연산자

> 자바의 점 연산자는 소속된 영역을 따라 대상의 주소를 참조하며, `System.out.println()`은 시스템의 표준 출력 장치에 속한 메소드를 호출하는 표현식입니다. 
> 참조 변수는 객체를 가리키는 참조값을 가지고 있으며, 점 연산자를 통해 해당 객체의 필드나 메소드에 접근할 수 있습니다.

객체지향 프로그램은 사람의 주소 표기처럼 상위 영역에서 하위 영역으로 대상을 찾아갑니다. `System.out.println()`에서는 `System`이 가장 상위 영역이며, `out`은 표준 출력 장치이고, `println()`은 실제 출력 기능을 수행하는 최종 메소드입니다.

점 연산자가 많아질수록 참조 경로의 깊이가 깊어집니다. 따라서 표현식을 읽을 때는 가장 왼쪽의 소속 영역부터 시작해 점을 따라 최종 대상까지 내려가는 방식으로 해석하는 것이 중요합니다.

| 표현 형태 | 의미 | 예시 |
|---|---|---|
| 이름만 존재하는 형태 | 값을 보관하거나 반환하는 변수 또는 필드입니다. | `out` |
| 괄호가 붙은 이름 | 메소드를 호출하는 형태입니다. | `test()` |
| 점 뒤에 괄호가 붙은 형태 | 클래스나 객체에 귀속된 메소드 호출 형태입니다. | `System.out.println()` |

참조 관계는 대상의 주소를 이용해 연결한 뒤 데이터를 조회, 생성, 수정, 삭제하는 관계로 이해할 수 있습니다. 웹 환경에서는 URL을 통해 서버에 연결하고, 연결된 자원에 CRUD 작업을 수행하는 구조가 대표적인 예입니다.

- 참조 관계는 대상의 위치 또는 주소를 통해 연결을 형성하는 구조입니다.
- 연결된 대상은 조회, 생성, 수정, 삭제와 같은 관리 작업의 대상이 됩니다.
- 연결이 가능하다면 연결 종료 또는 해제도 가능한 구조로 설계됩니다.
- 자바에서는 주로 점 연산자로 클래스와 객체의 멤버를 참조합니다.
