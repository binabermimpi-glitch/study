# 참조와 점 연산자

## 한 문장 설명

참조 변수는 객체를 가리키는 값을 담고, 점 연산자 `.`는 클래스나 객체가 제공하는 멤버를 선택한다.

```java
String message = "hello";
int length = message.length();
```

여기서 `message`는 `String` 객체를 참조하고, `.length()`는 그 객체가 제공하는 메소드를 호출한다.

## `System.out.println()` 읽기

1. `System`: 클래스
2. `out`: `System` 클래스의 정적 필드
3. `println()`: `out`이 참조하는 객체의 인스턴스 메소드

점이 많다고 단순히 주소 경로라고만 이해하면 부족하다. 각 단계에서 선택되는 것이 클래스인지 객체인지, 필드인지 메소드인지 확인한다.

## 흔한 실수

- 참조 변수가 객체 자체를 담는다고 단순화한다.
- `null`인 참조에서 멤버를 호출한다.
- 괄호가 있는 메소드 호출과 필드 접근을 구분하지 않는다.
