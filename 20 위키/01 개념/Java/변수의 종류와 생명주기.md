# 변수의 종류와 생명주기

## 한 문장 설명

변수는 선언 위치에 따라 사용할 수 있는 범위와 살아 있는 기간, 초기화 규칙이 달라진다.

```java
class User {
    static int count; // 클래스 변수
    String name;      // 인스턴스 필드

    void rename(String newName) { // 매개변수
        String oldName = name;    // 지역 변수
        name = newName;
    }
}
```

## 구분

| 종류 | 선언 위치 | 핵심 특징 |
|---|---|---|
| 클래스 변수 | 클래스 내부, `static` 사용 | 클래스 차원에서 공유 |
| 인스턴스 필드 | 클래스 내부, `static` 없음 | 객체마다 별도 상태 |
| 매개변수 | 메소드 선언부 | 호출 시 전달받은 값 |
| 지역 변수 | 메소드나 블록 내부 | 선언된 블록 안에서만 사용 |

필드에는 타입별 기본값이 적용되지만, 지역 변수는 사용하기 전에 코드에서 반드시 초기화해야 한다.

매개변수는 호출 시 전달된 인수로 초기화되는 지역 변수다. 서로 다른 메서드에 이름이 같은 지역 변수가 있어도 각 호출 범위는 서로 독립적이다.

중괄호로 만든 블록도 지역 변수의 사용 범위를 제한한다.

```java
{
    int number = 10;
    System.out.println(number);
}
// System.out.println(number); // 컴파일 오류
```

서로 범위가 겹치지 않는 별도 블록에서는 같은 이름을 다시 선언할 수 있다. 하지만 바깥 지역 변수의 범위 안에 있는 안쪽 블록에서는 같은 이름으로 지역 변수를 다시 선언할 수 없다.

## 용어 주의

Java에서는 클래스 필드나 인스턴스 필드를 묶어 무조건 `전역 변수`라고 부르기보다 `필드`, `클래스 변수`, `인스턴스 변수`라고 구체적으로 표현하는 편이 정확하다.
