# main 메서드 선언 읽기

## 2026-08-24 main 메서드 학습 회고

### main 메서드 학습 회고

### 이해한 요소

1. `public` → 접근 제한자
2. `static` → 정적
3. `void` → 반환형
4. `main` → 메서드 이름
5. `(String[] args)` → 매개변수

### 어려웠던 점

이 요소들을 이용해서 예시를 들고 코드를 만들어 보라는 문제에 제대로 답하지 못했다. 기본 부분에서 막혀서 아쉬웠지만 나머지 공부를 통해 전체 내용의 70% 이상은 이해하게 되었다.
