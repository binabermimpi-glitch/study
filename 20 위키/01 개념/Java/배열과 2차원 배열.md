# 배열과 2차원 배열

## 한 문장 설명

배열은 같은 타입의 값을 정해진 개수만큼 저장하는 객체이며, 배열 변수는 배열 객체를 가리키는 참조 변수다.

## 선언·생성·초기화

```java
int[] numbers;                    // 지역 변수 선언: 아직 값이 없어 사용 불가
numbers = new int[5];             // 배열 생성, 요소는 0으로 초기화
numbers = new int[]{10, 20, 30};  // 새 배열 생성 후 참조 재대입
```

필드로 선언된 배열 참조는 자동으로 `null` 초기화될 수 있지만, 지역 변수는 사용 전에 직접 초기화해야 한다. 따라서 `int[] numbers;`를 무조건 `null 상태`라고 표현하면 부정확하다. 명시적으로 `int[] numbers = null;`이라고 해야 지역 변수 값이 `null`이다.

배열 리터럴 `{10, 20, 30}`은 선언과 동시에 초기화할 때 사용할 수 있다. 이미 선언된 변수에 새 배열을 대입하려면 `new int[]{10, 20, 30}` 형태를 사용한다.

유효 인덱스는 `0`부터 `length - 1`까지다.

## 핵심 원리

```java
int[] a = {10, 20, 30};
int[] b = a;

b[0] = 100;
System.out.println(a[0]); // 100
```

`a`와 `b`는 별도 배열이 아니라 같은 배열 객체를 참조한다. 복사본이 필요하면 `Arrays.copyOf()` 같은 방법을 사용해야 한다.

## 2차원 배열

```java
int[][] grid = new int[3][4];

System.out.println(grid.length);    // 행 개수: 3
System.out.println(grid[0].length); // 0번 행의 열 개수: 4
```

Java의 2차원 배열은 실제로 배열 안에 배열이 들어 있는 구조다. 따라서 행마다 길이가 다른 가변 배열도 만들 수 있다.

```java
int[][] arr = new int[3][];
arr[0] = new int[2];
arr[1] = new int[4];
arr[2] = new int[1];
```

## 배열 `length`와 String `length()`

- 배열의 `length`는 배열이 가진 특별한 길이 값이므로 괄호가 없다.
- `String.length()`는 메서드이므로 괄호가 있다.

## 흔한 실수

- `grid[0].length`가 모든 행의 길이라고 단정한다. 가변 배열에서는 `grid[row].length`를 사용한다.
- 비어 있는 2차원 배열에서 `grid[0]`에 접근한다.
- 배열 변수를 다른 변수에 대입하면 배열까지 복사된다고 생각한다.
- 배열 크기를 만든 뒤 변경하려고 한다. 배열 길이는 생성 후 바뀌지 않는다.

## 실무에서는 어떻게 쓰이나

배열은 파일 바이트, 고정 길이 데이터와 알고리즘에서 사용된다. 일반적인 백엔드 데이터 목록에는 크기 변경이 쉬운 `List`가 더 자주 사용되지만, 참조와 반복 원리를 이해하는 토대다.
