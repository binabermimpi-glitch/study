# 객체 생성과 초기화 순서

## 한 문장 설명

`new` 표현식은 객체의 메모리를 마련하고 필드를 초기화하며 생성자를 실행한 뒤 완성된 객체의 참조값을 결과로 돌려준다.

```java
Person p1 = new Person("철수", 20);
```

## 단순화한 순서

1. 객체 공간 마련
2. 인스턴스 필드를 타입 기본값으로 초기화
3. 필드 초기화식과 인스턴스 초기화 블록 실행
4. 생성자 본문 실행
5. 생성이 정상 완료되면 `new` 표현식이 참조값을 반환하고 `p1`에 대입

상속이 있으면 부모 클래스 초기화와 부모 생성자 호출이 자식 생성자 본문보다 먼저 진행된다. 실제 JVM 최적화와 메모리 배치는 입문용 그림보다 복잡할 수 있다.

## 흔한 실수

- `p1`을 객체 자체라고 생각한다.
- 생성자가 객체 메모리를 직접 만든다고 단순화한다.
- 생성자 실행 전에 필드가 기본값으로 초기화된다는 점을 놓친다.
- 생성자에서 예외가 발생해도 참조 대입이 완료된다고 생각한다.

## 참조값 주의

참조 변수가 객체를 가리킨다고 설명할 수 있지만 Java 언어가 실제 물리 메모리 주소를 일반 코드에 그대로 공개한다고 단정하면 안 된다. JVM은 구현에 맞는 참조 표현을 사용하고 객체를 이동시킬 수도 있다.
