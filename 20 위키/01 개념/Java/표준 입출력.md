# 표준 입출력

## 자바 실행 구조와 기초 문법

### 표준 입출력과 연산자

> 표준 출력은 `System.out`, 표준 입력은 `System.in`을 기반으로 하며, 연산자는 우선순위와 전위, 후위 실행 시점에 따라 결과가 달라집니다.

`System.out.print()`는 줄 바꿈 없이 출력하고, `System.out.println()`은 출력 후 줄을 바꿉니다. `printf()`는 서식 지정자를 사용하여 숫자 폭, 정렬, 소수점 자릿수 등을 제어할 수 있습니다.

```java
String name = "동훈";
double pi = 3.141592;

System.out.printf("이름: %s%n원주율: %.2f%n", name, pi);
```

이스케이프 시퀀스는 문자열에서 특수 동작을 표현합니다. `\n`은 줄 바꿈, `\t`는 탭 공백을 의미합니다. 서식 지정자와 문자열 처리 기능은 Java API 문서의 `Formatter`, `String.format()` 설명에서 확인할 수 있습니다.

키보드 입력은 `Scanner`와 `System.in` 조합으로 처리할 수 있습니다. Java 25에서는 `IO.readln()`과 `IO.println()`처럼 표준 입출력을 간소화한 API도 사용할 수 있습니다.

```java
Scanner scanner = new Scanner(System.in);
String input = scanner.nextLine();
System.out.println(input);
```

`var`는 지역 변수 타입 추론 기능입니다. 선언과 동시에 초기화해야 하며, 컴파일 시 초기값의 타입이 결정됩니다. `var` 자체는 동적 타입이 아니므로 초기화 뒤에 다른 타입의 값을 대입할 수 없습니다.

- 산술 연산자는 덧셈, 뺄셈, 곱셈, 나눗셈, 나머지 계산에 사용됩니다.
- 증감 연산자는 전위형과 후위형에 따라 값 증가와 반환의 순서가 달라집니다.
- 논리 부정 연산자 `!`는 `true`와 `false`를 반전합니다.
- 시프트 연산자는 비트를 좌우로 이동하며 정수 연산과 메모리 표현을 이해하는 데 사용됩니다.

괄호는 연산자 우선순위를 명시적으로 변경합니다. 또한 `++value`는 값을 먼저 변경한 뒤 사용하고, `value++`는 현재 값을 먼저 사용한 뒤 증가시키므로 복합 수식에서는 실행 순서를 단계적으로 추적해야 합니다.
