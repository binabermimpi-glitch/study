# 표준 입출력

## 한 문장 설명

Java의 기본 콘솔 프로그램은 `System.out`으로 출력하고 `System.in`에서 입력을 받는다.

```java
import java.util.Scanner;

Scanner scanner = new Scanner(System.in);
System.out.print("이름: ");
String name = scanner.nextLine();
System.out.printf("안녕하세요, %s%n", name);
```

## 출력 메소드

| 메소드 | 특징 |
|---|---|
| `print()` | 출력 후 줄을 바꾸지 않음 |
| `println()` | 출력 후 줄을 바꿈 |
| `printf()` | 서식 지정자를 적용해 출력 |

## 실무에서는 어떻게 쓰이나

콘솔 실습에서는 중요하지만 Spring 백엔드의 운영 로그에 `System.out.println()`을 사용하는 것은 일반적인 최종 형태가 아니다. 이후 로깅 프레임워크를 배운다.

## 버전 주의

특정 최신 JDK가 제공하는 간소화된 입출력 API는 사용 가능한 언어 모드와 버전을 공식 문서로 확인한 뒤 별도로 기록한다.
