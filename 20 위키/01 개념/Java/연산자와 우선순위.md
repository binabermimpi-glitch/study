# 연산자와 우선순위

## 자바 메서드와 연산자 기초

### 연산자와 우선순위
연산자는 피연산자에 대해 계산을 수행하는 기호이며, 자바는 산술·관계·논리·비트·시프트 연산자와 우선순위 규칙을 제공합니다.

연산식은 피연산자와 연산자로 구성됩니다. 피연산자는 연산 대상 데이터이며, 연산자는 데이터를 계산하거나 비교하기 위한 기호입니다. 피연산자 수에 따라 단항, 이항, 삼항 연산자로 분류합니다.

구분	피연산자 수	대표 예시
단항 연산자	1개	++x, --x, !flag
이항 연산자	2개	a + b, a > b, a && b
삼항 연산자	3개	condition ? a : b
증감 연산자는 변수 값을 1씩 증가 또는 감소시킵니다. 전위 연산은 값을 먼저 변경한 뒤 사용하고, 후위 연산은 현재 값을 먼저 사용한 뒤 값을 변경합니다.

int x = 5;
int y = x++;
// y는 5이고, x는 6입니다.
연산식에 여러 연산자가 포함되면 우선순위가 적용됩니다. 일반적으로 괄호를 가장 먼저 계산하고, 이후 단항 연산, 곱셈·나눗셈·나머지 연산, 덧셈·뺄셈 순서로 계산합니다. 복잡한 식은 괄호를 명시해 의도를 분명히 하는 것이 안전합니다.

논리 연산자는 boolean 값의 참과 거짓을 조합합니다. 논리 AND는 양쪽 조건이 모두 참일 때 참이며, 논리 OR는 한쪽 조건만 참이어도 참입니다. 논리 NOT은 참과 거짓을 반전합니다.

비트 연산자는 정수 값을 이진수 비트 단위로 처리합니다. AND, OR, XOR, NOT 연산은 각 비트의 조합에 따라 결과 비트를 만들며, 비트 시프트 연산은 비트를 좌우로 이동시켜 곱셈이나 나눗셈과 유사한 효과를 만들 수 있습니다.

왼쪽 시프트는 비트를 왼쪽으로 이동시키며 일반적으로 2의 거듭제곱 곱셈과 관련됩니다.
오른쪽 시프트는 비트를 오른쪽으로 이동시키며 일반적으로 2의 거듭제곱 나눗셈과 관련됩니다.
시프트 연산은 정수 계열인 byte, short, int, long, char에 적용됩니다.
부동소수점형과 boolean에는 시프트 연산을 적용할 수 없습니다.
