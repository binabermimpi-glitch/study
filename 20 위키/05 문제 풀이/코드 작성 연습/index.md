## 반복되는 약점

- 문법 기억: 세미콜론, API 이름, println 철자와 printf 형식
- 문제 해석: 출력과 반환 구분
- 코드 조립: 반환형·매개변수·계산·출력 순서 연결
- 개념 구분: 생성자와 일반 메서드, 인스턴스 필드와 static 공유 필드
- 대상 구분: 배열 전체와 요소 하나, 배열 길이와 문자열 길이
- 문법 조립: if 패턴과 switch 패턴을 섞지 않고 괄호를 끝까지 닫기
