## 1. Book 클래스와 생성자

### 문제

`String title`, `int price` 필드를 가진 Book 클래스를 만들고 생성자로 제목과 가격을 저장한다.

### 첫 시도 — 그대로 보존

```java
class Book {
    String title;
    int price;

    Book(String s, int b) {
        this.title = s;
        this.price = b;
    }
```

### 진단

- 오류 유형: 단순 실수
- 생성자 이름, 매개변수, `this`를 이용한 필드 저장은 정확하다.
- 마지막 클래스 닫는 중괄호 `}`가 빠졌다.

### 정답

```java
class Book {
    String title;
    int price;

    Book(String s, int b) {
        this.title = s;
        this.price = b;
    }
}
```

## 2. Counter 클래스의 add 메서드

### 문제

`add()`를 호출할 때마다 `count`가 1씩 증가하도록 작성한다.

### 첫 시도 — 그대로 보존

```java
class Counter {
    int count;

    add() {
        count++;
    }
}
```

### 진단

- 오류 유형: 문법 기억
- `count++`로 상태를 바꾸는 부분은 정확하다.
- `add()`는 생성자가 아니라 일반 메서드이므로 반환형이 필요하다.
- 돌려주는 값이 없으므로 `void`를 쓴다.

### 정답

```java
class Counter {
    int count;

    public void add() {
        count++;
    }
}
```

## 3. Account 클래스의 캡슐화

### 문제

`money`를 외부에서 직접 접근하지 못하게 하고 setter로 변경하며 getter로 반환한다.

### 첫 시도 — 그대로 보존

```java
class Account {
    private int money;

    public void setMoney(int c) {
        this.money = c;
    }

    public int getMoney() {
        return money;
    }
}
```

### 진단

- 오류 유형: 없음
- `private` 필드, 값을 변경하는 setter, 값을 반환하는 getter를 정확히 구분했다.
- `this.money = c`로 현재 객체의 필드에 매개변수 값을 저장했다.

### 정답

```java
class Account {
    private int money;

    public void setMoney(int c) {
        this.money = c;
    }

    public int getMoney() {
        return money;
    }
}
```

## 4. Student 객체 수 세기

### 문제

학생 수를 모든 객체가 공유하고, 객체가 생성될 때 자동으로 1씩 증가시킨다.

### 첫 시도 — 그대로 보존

```java
class Student {
    int count;

    public static studentCount() {
        count++;
    }
}
```

### 진단

- 오류 유형: 개념 부족, 코드 조립
- 모든 객체가 공유하는 값은 `static` 필드여야 한다.
- `studentCount`는 호출할 기능이 아니라 현재 학생 수를 보관할 변수다.
- `new Student()` 순간 자동 실행되는 것은 일반 메서드가 아니라 생성자다.
- 판단 순서는 `공유 대상인가? → static`, `언제 실행되는가? → 생성자`다.

### 정답

```java
class Student {
    public static int studentCount;

    public Student() {
        studentCount++;
    }
}
```

### 실행 흐름

```text
new Student() → 생성자 실행 → studentCount = 1
new Student() → 생성자 실행 → studentCount = 2
new Student() → 생성자 실행 → studentCount = 3
```

## 이번 연습에서 드러난 핵심

1. 클래스 이름과 같은 `Book(...)`, `Student()`는 생성자이며 반환형이 없다.
2. 일반 메서드인 `add()`에는 반환형 자리가 필요하며 반환값이 없으면 `void`다.
3. 객체마다 따로 가져야 하는 값과 모든 객체가 공유할 값을 구분한다.
4. “객체를 만들 때 자동 실행”이라는 조건을 보면 생성자를 떠올린다.
5. Account 문제처럼 맞게 작성한 코드도 정답 없이 한 번 더 재현해 확실히 익힌다.
